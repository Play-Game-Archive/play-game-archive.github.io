Steps towards a Generic Interface between Interactive Storytelling Applications and Character Animation Engines

迈向交互讲故事应用与人物动画引擎之间的通用接口

Sebastian A. Weiß 塞巴斯蒂安·A. 魏斯 / Florian Berger 弗洛里安·贝格尔 / Alexander Marbach 亚历山大·马尔巴赫 / Wolfgang Müller 沃尔夫冈·米勒 · 2008 · 2026汉译

简介

本文提出CharanisML，用通用命令接口连接交互讲故事系统与人物动画引擎，将控制分为系统、场景和人物三个层次。作者以Ogre3D和二维漫画客户端进行概念验证，讨论内容跨表示复用的可能性，也说明二维客户端仍忽略三维骨骼控制、细微动作可能无法映射等限制。
