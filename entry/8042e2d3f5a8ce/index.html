作品

Baba Is You

巴巴是你

Arvi Teikari 阿尔维·泰卡里 / Hempuli Oy 亨普利公司 · 2019

简介

Baba Is You是Arvi Teikari以Hempuli名义创作的解谜游戏，商业版于2019年3月13日发行。作品把规则写成关卡中可以移动的词块，玩家通过推开、重组和重新连接这些词块，改变对象的属性、控制关系与胜利条件。它将推箱子的空间约束与规则系统结合，使理解游戏怎样成立本身成为解谜的主要内容。[1][2]

从游戏创作活动到商业版本

Baba Is You最早是2017年Nordic Game Jam的作品，作者在itch.io保留了可以下载的Windows原型，并将它与后来的完整商业版分别列出。原型已经提供移动、撤销和重开的控制，展现了把语言规则当成物件推动的基本构想。商业发行版在2019年发布前经历了持续扩充与关卡制作。[1][3]

作者使用Hempuli这一创作名，正式开发者与发行者为Hempuli Oy。2019年访谈说明，作品使用Clickteam的Multimedia Fusion 2，并通过Lua插件实现核心逻辑；MP2 Games参与移植，帮助这套制作方式进入其他平台。游戏的个人设计路线，与工具开发和平台适配中的合作共同推动了商业版本。[1][2]

其公开认可也有明确的时间层次。作品获得2017年Nordic Game Jam奖项，随后在2018年Independent Games Festival获得设计与学生游戏奖项，而商业版到2019年才发行。这样的顺序说明，获奖所对应的是发展中的作品，并非所有奖项都是对首发成品的事后评价。2019年版、2017年原型与2021年编辑器更新，应当作为相互关联的不同阶段理解。[1][3][4]

商业版提供大量由作者安排的谜题，官方介绍将其规模概括为二百多个关卡。不同词汇与空间限制，使各关卡要求玩家不断修改对规则的理解。它的变化主要来自手工构造的情境与机制组合，而不是每次重开都重新随机生成整套谜题。[1][2]

词块怎样成为规则

在通常的推箱子游戏中，箱子和墙的作用由程序预先规定，玩家主要寻找移动次序。Baba Is You则把部分规定暴露在同一个空间里：对象名称、连接词和属性词可以排成句子，成立的句子立即影响关卡。玩家既要处理某个物件挡住道路的问题，也可以尝试改变这个物件为什么能够挡路，从而把操作对象与操作规则连接起来。[1][2]

例如，ROCK IS PUSH使岩石具有可推动的属性。把其中一个词移走，原来的句子不再成立，效果也随之改变。词块不是一条只需阅读一次的教程说明，而是持续参与系统状态的材料；其位置、朝向与周围空间都影响哪些规则能够存在。解谜因此需要把句子的意义和词块能够移动到哪里同时考虑。[2]

BABA IS YOU指定哪些对象响应玩家输入。“你”在这里是一种可以重新分配的控制关系，而不是始终固定在一个角色身上的身份。如果关卡允许把其他对象与YOU连接，控制就可能转向它们；如果同时存在多个相应对象，输入也可能对它们共同生效。这种设计使角色、输入与世界之间的关系成为玩家可以研究的结构。[1][2]

控制关系与对象转换还需区分。把一个名称与另一个对象名称连接，涉及对象类别的变化；把名称与YOU、PUSH等属性连接，则涉及对象如何行动或与其他东西互动。两者都采用简短句式，但后果并不相同。玩家不能只凭一个词“看起来应该怎样”就确定结果，而需要理解作品规定的语法和语义，并检查当前同时成立的其他规则。[1][2]

胜利条件同样可以进入这一体系。目标不必永远是某个固定物件，相关词块允许玩家重新安排什么对象具有WIN属性。于是，通往终点的路径与终点究竟是什么，可以成为同一个谜题的两个部分。作品要求玩家在常见游戏习惯与当前规则之间作出区分：一面看起来像旗帜的图形，只有在相应规则成立时才承担既定目标的功能。[1][2]

空间约束与行动顺序

玩家通过移动现有词块来改变有效规则。玩家必须通过关卡允许的移动接近词块，给它留出推动空间，并避免把关键部分推入无法取回的位置。一条逻辑上有效的句子，可能在当前地形中根本无法排列出来；一种理想属性也可能需要先放弃现有能力，才能获得制作它的空间条件。[1][2]

这使解谜包含不同时间尺度。眼前一步决定对象怎样移动，若干步以后则可能形成一条新规则；新规则成立后，先前看似没有作用的布局又可能取得意义。玩家需要预测规则变化之后世界如何回应，再倒推必须先保留哪些位置和物件。困难来自多个层次相互制约，而不仅是把更多箱子塞进更大的地图。[1][2]

撤销与重开为这种探索提供条件。2017年原型就明确列出撤销操作，商业版访谈也把失去YOU规则之后的恢复作为理解游戏的基本方式。玩家可以试验一个假设，看它带来什么后果，再返回先前状态。失败因而不仅是一次通关尝试的终止，也可以成为识别规则边界的信息；这种低成本回退尤其适合需要改变概念预期的谜题。[2][3]

不过，可撤销不等于每个试验都容易理解。一次变化可能同时改变多个对象，玩家仍需判断效果来自哪条规则、哪些词已不再相连，以及原先的行动能力是否已经消失。因此，系统提供恢复能力以后，还必须让变化保持一定可读性。字词数量、可见布局和效果之间的对应关系，直接影响玩家能否从试验中取得有效知识。[1][2]

固定语法中的系统深度

作品使用可读的词汇，却不是一个接受任意自然语言的开放解释器。Teikari在2019年访谈中介绍，规则更新由词块移动或变化触发，程序先识别可能开头的词，再检查它右侧或下方的组合是否满足语法，随后整理并加入规则列表。游戏的表现由这套作者定义的计算系统实现，玩家活动则是在其允许的词汇与结构中寻找可能性。[2]

这一区分说明，规则与软件并不处于完全相同的层次。玩家可以改变关卡中的许多规定，却没有因此得到任意修改游戏程序的能力。哪些句式有效、词汇具有什么含义、不同规则如何处理冲突，仍由实现决定。Baba Is You的设计力量来自把一部分决定权转为可操作对象，同时维持足够稳定的底层关系，让玩家能够学习和推理。[1][2]

规则之间还可能产生冲突。作者举例说明，如果BABA IS NOT YOU成立，系统会使BABA IS YOU失效。否定词因此不是装饰性语言，而会进入实际的有效性判断。玩家需要关注的不仅是某个希望成立的句子，还包括是否有其他规则取消或限制它；单独阅读一条规则，不能总是解释当前对象的全部行为。[2]

有些词把关系带到更高层次。SINK、PULL等借用已有解谜行为，LONELY一类条件词则让效果取决于对象所处情境；TEXT允许规则作用于词块本身。由此，原本用于说明世界的材料也能成为被说明、被改变的对象。作品的层次感来自这些明确机制的组合，而不是只用故事告诉玩家“世界规则已经被打破”。[2]

开发过程中，词块重叠还迫使作者重做部分规则系统。原先实现假设一个格子只有一个词，测试却暴露了多个词可以位于同一位置的可能；系统随后需要考虑这些词组成句子时的不同排列。这个例子说明，看似简洁的规则游戏也有复杂实现工作。玩家看到的开放结果，依赖设计者认真处理边缘情况，而不是单纯允许程序任意出错。[2]

谜题如何被构造出来

Teikari介绍自己的关卡设计时，强调先寻找某个词或某组规则之间令人意外的作用，再反向制作需要这种作用才能解决的局面。设计的核心由此是一种发现与约束之间的配合：先找到值得体验的相互作用，再控制其他路径，使玩家有机会认识它。关卡并非把词块随机撒进地图，等待组合数量自然形成优质谜题。[2]

这种方法也需要删减。有些词虽然概念有趣，却不能产生足够多值得保留的关卡；有些谜底需要太多辅助规则，初始画面会变得难以理解。作者因此放弃过词汇与关卡，限制不能只由技术能否实现来判断。一个效果能运行、能制造惊讶，与玩家能够在合理信息下认识它，是相关而不同的设计标准。[2]

测试者发现的非预期解法，则可能改变关卡的发展方向。作者说，一些变体关卡来自原关卡中被发现的其他解法：原先有效的技巧被关闭，玩家必须重新审视非常相近的布局。变化可以很小，却足以使已经形成的解释失效。这种安排训练玩家辨认关键条件，也让重复的视觉构图承载新的推理工作。[2]

非预期解法不必一律保留，也不应一律当作错误。若它使关卡绕过希望展示的机制，作者可能修改原布局；若它本身具有趣味，又可能被发展成另一个谜题。Baba Is You因而同时具有系统开放性和作者取舍，测试过程不是只检查答案是否唯一，也包括判断一种发现应该在作品的哪个位置出现。[2]

关卡组织还要处理难度与探索自由的张力。作者按新词汇划分区域，试图让玩家在一道题停滞时转向其他题；但连续编号又容易让人认为必须先完成眼前全部内容。2019年访谈中，他承认这一结构仍可改善，并通过把部分题目标记为额外关卡、调整其所在区域来传达难度差异。作品的学习顺序因此也是经过修改的设计对象。[2]

表现形式与更高层的地图

游戏画面把词块、可移动对象与地形保持在同一平面上。简洁的图形将注意引向对象关系：每个词可能参与多个潜在句子，周围空间又限制其可达位置。审美形式与逻辑设计在这里直接相关，图形首先承担让规则看得见、让变化可追踪的任务。[1][2]

角色形象还与YOU这一属性形成有趣关系。名称和外观鼓励玩家把Baba当作自己，但规则可以把这种控制转移出去；解谜时，熟悉形象与实际行动资格便可能分开。作品因此借简单的称谓提出关于身份的形式问题：在这一局面中，谁响应我的动作，谁只是世界中的对象？问题由操作关系产生，而不依赖长篇背景故事。[1][2]

世界地图的处理进一步延伸了这一方向。作者回忆，地图最初位于普通关卡逻辑之外，后来逐渐形成把地图本身作为关卡处理的想法，并花费时间把代码组织到能够支持这种层次的状态。它不是仅在结尾增加一个惊奇画面，而是让组织内容的外层结构也与内部规则发生联系，使玩家对游戏边界的理解需要再次调整。[2]

开发中曾考虑的某些界面恶作剧则没有成为同样深度的方案。作者认为，单独让某个按键产生意外后果，可能只是一次性噱头；更值得发展的方向应能继续探索规则系统本身。这种自我取舍说明，其元层设计的目标不只是让玩家吃惊，还包括使惊讶之后仍存在可操作、可学习和可继续发现的结构。[2]

编辑器与2021年的扩展

2021年11月，作者公布Baba Make Level更新，加入正式关卡编辑器、教程、在线分享与精选关卡列表，同时提供逾一百五十个新关卡，以及逾一百个此前未采用的关卡，其中部分附有开发者评论。它把原来主要由作者提供谜题的产品，扩展为也可供玩家制作和交流谜题的工具；这些内容应与2019年首发范围分别叙述。[4]

编辑器改变的是创作位置，不只是谜题数量。玩家可以从寻找既有答案转向安排词汇、空间与限制，尝试让别人发现某种作用。这与作者描述的反向关卡构造方法形成联系：一个自己知道的有趣组合，需要怎样布置才能让别人既能接近，又不被无关复杂性淹没？制作与试玩在这里可以相互检验，对规则的理解也由此进入表达和教学。[2][4]

精选列表与在线分享则承担不同作用。分享让玩家发布自制关卡，精选列表帮助其他人找到值得尝试的作品。一个规则丰富的编辑器会扩大创作空间，也使版本兼容、关卡可读性与作品筛选成为持续工作。原作的价值不因此只转化为用户产量，作者设计的关卡与社群创作仍提供不同的体验入口。[2][4]

贡献、争论与解释边界

Baba Is You最有辨识度的贡献，是把“规则决定行动”这一通常隐蔽的关系放进可移动空间，使玩家既依据规则思考，也把规则当成手段。它可以成为研究游戏语言、程序约束与玩家能动性的具体对象，但不宜被简化为没有限制的自由：有效词汇、语法、冲突处理和关卡边界，始终规定着这种自由能够怎样发生。[1][2]

这也形成一种难度争论。作品希望鼓励玩家修改思维定式，较难关卡却可能让人难以分清自己缺少的是规则知识、空间计划还是对某个边缘情况的认识。作者对额外关卡与区域安排的反思，表明困难并非只由玩家愿不愿思考决定。理解提示、发现路径和保持惊喜之间，需要持续的设计判断，不能用谜底巧妙这一项标准包办全部体验评价。[2]

开发过程还显示，系统一致性和意外发现并非天然相反。处理重叠词块、修正规则冲突和调整关卡，能够让玩家的大胆试验得到更稳定的回应；另一方面，过多补充规定又可能增加理解负担。作品因此把一个重要设计问题具体化：怎样在足够可靠的语义之上，保留足够多尚未被玩家预先想到的作用，而不把不可预测本身误当成深度。[2]

从2017年原型到2019年商业作品，再到2021年正式编辑器，Baba Is You的发展围绕同一核心持续扩大：让可读语言成为可行动的世界材料。它的历史既包括鲜明的机制构想，也包括测试、删减、工具选择、移植和内容组织。只有把这些工作与具体规则共同说明，才能解释其创新怎样转化为一部能够被反复研究、制作和体验的完整游戏。[1][2][3][4]
