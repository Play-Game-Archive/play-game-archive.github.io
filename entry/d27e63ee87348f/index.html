档案卡片

Albrecht Schmidt

阿尔布雷希特·施密特

简介

阿尔布雷希特·施密特（Albrecht Schmidt）是研究人机交互、泛在计算与媒体技术的德国计算机科学家，自2017年起任慕尼黑大学计算机科学教授，领导Human-Centered Ubiquitous Media教席。他的研究围绕数字技术怎样扩展人的感知、记忆和理解，以及人在自动化系统中怎样保持控制展开。LMU官方人员档案

他于1997年在曼彻斯特城市大学获得计算硕士学位，1998年取得乌尔姆大学计算机科学文凭，2003年获得兰卡斯特大学计算机科学博士学位。随后在LMU从事博士后研究并领导青年研究组，2006至2007年在波恩大学任教授、在Fraunhofer IAIS任部门负责人，2007至2010年任教于杜伊斯堡—埃森大学，2010至2017年任斯图加特大学人机交互与认知系统教授。这段经历贯穿移动、嵌入式与泛在系统逐步进入日常生活的时期。

情境与隐式交互

《Implicit Human Computer Interaction through Context》（2000）是其早期代表作。文章将人的活动与环境信息纳入输入设计：某个动作的主要目的可能是完成现实任务，计算机则通过位置、活动等线索取得与交互有关的信息。这个思路使交互的研究单位从一次按钮操作延展到行动发生的情境。KIT官方出版记录

情境感知系统需要把传感器记录解释为任务状态。例如，系统既要观察行动，也要决定什么时候适合改变反馈。由此，输入设计同时涉及识别与交互：传感器提供信息，模型解释信息，使用者承受解释带来的后果。隐式交互研究所提出的核心问题，是怎样减少明确输入的步骤，同时使系统响应符合当前活动。

这种问题在移动和可穿戴设备中格外突出。用户的注意常在现实任务上，身体姿态和环境持续变化，传统桌面操作所依赖的稳定屏幕与连续注视难以维持。Schmidt的研究将感测、适应和反馈放进同一个过程，追求能够嵌入活动的交互方式。

放大感知与认知

《Technologies to Amplify the Mind》（2017）进一步讨论数字技术如何支持感知、记忆与意义建构。文章承接人机共生与认知扩展的思想，将工具视为认知活动的一部分。眼镜、望远镜、数字记录与信息可视化分别展示了技术介入感知和思考的不同方式。研究关心人怎样通过工具取得新能力，以及这种能力需要怎样的输入、反馈和学习过程。论文原件

ERC项目AMPLIFY将感知增强落实为四类目标：创造新的感知通道，增强既有感知，设计显式与隐式控制，以及建立测量增强效果的方法。项目将原型、用户研究与感知评价连接起来。CORDIS记录的项目编号为683008，执行时间为2016年7月1日至2022年9月30日。CORDIS项目记录、项目科学背景

感知放大包括一系列相连的设计决定。首先要确定人当前难以取得哪类信息，再选择传感方式，将数据转成视觉、声音或触觉反馈，并安排反馈的时机。最后需要观察它是否帮助任务、怎样影响注意，以及用户如何学习。传感器性能、反馈形式与人的实际表现，在这个过程里各有作用。

Schmidt的LMU人员页将有限记忆、信息摄入速度和复杂关系的视觉识别列为具体研究问题。团队结合机器学习与输入输出技术，使用眼动、脑电、虚拟现实等手段构建实验软件和硬件，再从实验中概括模型、框架和设计原则。这条路径使原型承担双重任务：提供可使用的功能，也让抽象交互问题获得可观察的形式。

自动化中的干预界面

与Thomas Herrmann合作的《Intervention User Interfaces: a New Interaction Paradigm for Automated Systems》（2017），讨论自动化持续执行任务时的共同控制。作者将干预定义为使用过程中改变系统既定行为的行动，强调系统应让人察觉干预机会，并能迅速改变运行过程。文章据此讨论控制粒度、反馈与恢复自动化之间的关系。论文原件

自动泊车是文中的解释案例：传统驾驶需要连续调节转向、油门和刹车；泊车辅助将操作转为选择位置并启动程序；更自主的车辆又能自己寻找车位。控制粒度随之改变，界面需要表达用户仍能改变什么。另一个案例是感应灯：延长照明、提前关闭和永久修改设置，是时间效力不同的操作。

这类研究把自动化之后的人的工作具体化为了解状态、发现例外、表达临时需求和恢复常规运行。它也延续了早期情境交互的问题：系统可以主动行动，人的目标与情境仍会变化。界面因此需要协调平常的低注意运行与例外时清楚、及时的控制。

HCUM的实验方法与应用

Schmidt领导的HCUM位于人机交互、媒体技术与泛在计算的交叉处。官方研究页面列有认知负荷自适应界面、生理数据、可穿戴系统、AR与VR、触觉及自动化交互等主题。研究通常从任务中的困难出发，设计一种可比较的干预，再通过用户行为和主观经验评价它。HCUM研究说明

眼动、脑电和肌电提供不同的身体信号，也承担不同的交互任务。它们既能成为主动输入，也能支持系统了解注意或负担。触觉和显示技术则将系统状态送回用户。把输入、推断与反馈连接起来，能够解释同一种传感器为什么会形成不同的界面：眼动可以指向一个对象，也可以帮助系统调整信息呈现。

车载交互与VR是这一方法的两个应用环境。前者需要协调系统主动性、驾驶者注意和接管过程；后者需要把动作、空间与身体反馈配合起来。两类研究都要求在具体任务中观察人的表现。原型所用的传感位置、反馈时机与任务安排，是理解实验结果的重要条件。

他的官方履历还列有用户自适应混合现实、为年龄相关黄斑变性患者设计的诊断与电子辅助系统，以及情境感知学习环境等项目。这些方向把能力放大的问题落在视觉、学习与活动支持上，连接基础交互概念与实际使用者的需求。项目清单也显示，研究依靠大学、公共资助与不同合作者形成的网络推进。

研究议题与学术共同体

隐式交互与能力放大引出的持续议题，是技术支持怎样与人的自主性协调。系统根据身体和环境信息改变反馈，会影响用户注意什么、记住什么以及采取哪些行动。因此，识别精度之外还需要解释适应机制，提供纠正方式，并让用户了解自己可以控制的环节。Schmidt关于干预界面的工作，为这一问题提供了明确的设计语言。

另一条讨论涉及认知活动怎样被评价。完成任务的速度、对内容的理解、长期记忆和主观负担，反映不同的结果。增强感知的技术需要选择与目的相应的指标，并观察学习设备所需的成本。此处的研究难点在于把新信息转化为可用能力，使技术进入任务之后仍能帮助使用者理解与行动。

Schmidt是Automotive User Interfaces及Tangible and Embedded Interaction会议的共同创办者，2018年成为ACM SIGCHI Academy成员，2020年成为德国国家科学院Leopoldina成员。他的研究组织与教学活动，连接了车载界面、实体交互和泛在计算等共同体。在这些领域之间，其工作保持了鲜明的问题连续性：从环境里取得信息，通过合适的交互让人使用信息，并在系统更自主时保留人的行动空间。官方履历
