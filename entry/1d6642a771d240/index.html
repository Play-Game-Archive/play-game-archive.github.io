档案卡片

Edward Berman

爱德华·伯曼

简介

Edward Berman，也使用 Eddie Berman 署名，是研究几何机器学习、科学计算与模型不确定性的研究者。其公开工作涵盖等变函数的置信度校准、动力学模型中的平滑性、天文成像点扩散函数、Julia 科学计算，以及代码编辑和语言智能体。Northeastern 的 Geometric Learning Lab 将其列为本科阶段校友，并在2026年资料中记为 Harvard 博士生及 NSF GRFP Fellow；Harvard 几何机器学习组也列有其成员记录。原研究组名录，Harvard研究组

理解其研究，关键是把“结构”与“证据”相联系：对称性能够限制模型，却需要符合实际数据；动力学模型需要适当改变空间中的平滑性；观测图像又必须结合仪器响应才能解释。语言代理的试错反馈属于其合作谱系中的一部分，不足以代替这些主要问题。

一、研究位置与共同署名

Berman 的个人网站把几何学习、宇宙学及 Harvard—Smithsonian 天体物理研究环境联系起来，其论文页列出的近期主题包括动力学、不确定性和计算成像。不同页面的更新时点并不一致，因此机构历程应结合研究组当前名录，而不从较旧的个人首页推断固定任职。个人论文目录

其工作多由跨领域团队完成：几何学习论文与 Robin Walters、Jacob Ginesin、Marco Pacini 等合作，成像论文与 Jacqueline McCleary 及 COSMOS-Web 研究团队合作。Berman在作者表中署名首位，与合作者共同完成这项研究。

这些合作并非一套统一模型在不同领域的简单应用。天文仪器、图上的物理过程与语言模型各有不同数据和误差。人物研究应说明问题如何变化，并在能够找到原始证据时讨论联系，避免用抽象“跨学科”遮蔽具体方法。

二、等变性：让模型尊重变换

等变性要求输入发生某类变换时，输出按相应规则变化。例如旋转物体以后，预测的方向也应相应旋转；某些分类结果则应保持不变，这称为不变性。把这种结构放入模型，可以减少重新学习每种等价情形的负担。

但结构假定必须符合任务。若旋转会改变照明、边界或标签含义，强制完全相同的行为可能错误；现实数据也可能只近似满足对称。等变结构的作用取决于所设对称性与任务条件的匹配。

Berman 与合作者在《On Uncertainty Calibration for Equivariant Functions》中，将这一问题进一步联系到模型如何表达自己的不确定性。论文2025年公开，2026年形成 TMLR 发表版本，题名与日期应按所用稿件区分。原始论文

三、准确率与置信度校准

预测正确率与置信度是否可信，是两项不同性质。一个模型可以在多数样本上正确，却对少数错误过度确信；另一个模型可能没有最佳准确率，却更能识别自己不确定的情形。校准研究关注预测信心与实际误差之间的对应。

等变网络可以共享变换相关的知识，但这种共享是否使信心更可靠，需要另行证明。该论文从理论上研究不同等变条件下的校准误差界，并通过真实及模拟资料考察对称不匹配、群结构和不同不确定性来源。作者代码

这一研究的意义在于把结构与风险陈述连起来。模型不只要输出答案，还要让使用者知道答案在何种条件下值得依赖；对称性如果与真实任务错位，模型可能把错误推广到整类变换情形。检查精度之外的信心，有助于发现这种系统性问题。

四、不确定性的不同来源

数据本身的噪声与模型知识不足并不相同。前者可能来自观测限制或随机过程，后者可能因样本不足、模型选择或分布变化而出现。研究常将它们称为 aleatoric 与 epistemic uncertainty，但在实际任务中需要说明如何估计和区分。

如果一个变换只改变了模型不熟悉的外观，增加训练覆盖可能有帮助；若传感器已经丢失必要信息，仅增加同类样本未必消除不确定性。把二者混成一个信心数值，会使人难以判断应该继续收集数据、改变模型还是承认观测边界。

对于游戏代理，这类研究能够启发置信度测试，但不能从数学结果直接推出某个角色已经可靠。物体识别、动作预测和语言判断具有不同结构，必须确认所用对称假设与评价条件。论文提供的是研究关系，而不是通用安全证书。

五、动力学模型中的平滑性

《Smoothness Errors in Dynamics Models and How to Avoid Them》由 Berman、Luisa Li、Jung Yeon Park 与 Walters 共同完成，2026年发表于 ICML。论文研究图和网格模型中的平滑作用，指出阻止过度平滑的某些结构，也可能对本来就会变平滑的物理过程施加过强约束。论文

图神经网络中的过度平滑通常被视为问题，因为节点表示逐渐相似以后，重要差别可能消失。但热扩散等物理过程本身就会使局部差异随时间减少。模型既需要保留有用结构，也需要允许目标系统的真实变化，不能用一个不变原则解决全部任务。

该研究提出 relaxed unitary convolutions，在保持结构与允许自然平滑之间作调整，并将相关方法扩展到网格。实验涉及热、波等偏微分方程及天气预测。这里讨论的是论文所列条件下的建模效果，不将其概括为所有动力学系统的统一解法。

六、从静态识别到长期预测

动力学模型的错误不仅表现为某一时刻预测偏差，还可能在多次滚动预测中积累。模型若过早抹去细节，会失去后续演化所需的信息；若不允许应当发生的耗散，又可能持续保留物理上不再存在的结构。

因此，评价需要观察时间尺度、空间分辨率和守恒或耗散特性。一步预测准确，不保证长期轨迹正确；漂亮的动画也可能隐藏错误物理。研究者应将数值指标与系统结构相互核对，并说明测试是否改变了初始条件或几何形状。

这一问题与游戏中的世界模型有可比较之处：代理根据模型规划时，微小预测误差可能改变后续选择。但科学模拟的目标通常是物理逼近，游戏世界还可能具有故意设计的非现实规则。采用相关方法前，应确定要学习的是哪一种环境规律。

七、ShOpt.jl 与天文观测

Berman 与 McCleary 开发 ShOpt.jl，用 Julia 对 JWST NIRCam 等成像资料的点扩散函数进行经验建模。相关软件论文于2024年发表于 Journal of Open Source Software，正式记录同时公开代码、审查与软件存档。JOSS论文记录

点扩散函数描述理想点源经光学系统后形成的图像。观测中的天体形状不只由天体自身决定，也受到仪器响应影响；若要比较细微形态，就需要理解并估计这种响应。它是科学解释的基础条件，而非事后修饰图片的滤镜。

软件贡献因此需要同时考虑数值方法与使用条件。可复现安装、资料输入、诊断与文档决定其他研究者能否把方法用于自己的图像；软件论文的公开审查又为这些环节提供独立记录。工具可运行与所有科学结论正确仍然不同，需要各自验证。

八、模型保真度与计算效率

2024年另一篇成像论文将 ShOpt 与 PSFEx、PIFF 比较，使用真实及模拟 COSMOS-Web 图像，考察拟合保真度、诊断统计与处理效率。它与简短软件论文承担不同功能：一项介绍工具，一项检验具体成像任务中的表现。原始研究

成像模型可能在某个总体误差上看似接近，却在局部形状或空间变化中保留系统偏差。因此，诊断需要对应科学问题，而不能只用一幅观感平滑的拟合图作判断。真实资料与模拟资料又各有价值：前者保留复杂仪器条件，后者提供可控制的已知关系。

效率同样有条件。较快计算能够支持大图像和多次比较，但应同时保留模型复杂度、资料规模与硬件条件。研究成果应在所报告范围中评价，不用一次运行时间推断所有未来资料的成本，也不以速度替代精度。

九、Julia 与科学机器学习生态

Berman 与 Ginesin 的《The State of Julia for Scientific Machine Learning》于2024年在 NeurIPS 的 Machine Learning and the Physical Sciences 工作坊发表，讨论 Julia 的语言与生态条件。它是一项观点和生态评估工作，不是 NeurIPS 主会算法论文。原文记录

科学软件的采用不仅取决于理论运行速度，也取决于自动微分、数值库、依赖稳定性、文档与社区经验。使用者需要在现有工作流中取得可靠结果，语言设计上的优点只有通过这些条件才能转化为实际便利。

这项讨论与 ShOpt 的制作构成不同证据：一个实际工具显示可以如何使用语言，一篇观点文则讨论更广泛的采用障碍。两者可以互相支持，但不能以某个工具成功证明语言适合所有任务，也不能以生态困难否认所有具体研究价值。

十、语言模型合作：编辑与反思

Berman 还参与《Can It Edit?》代码编辑研究，并在 Reflexion 的2023年 arXiv v4 中列第三位作者、单位为 Northeastern。后者的六人署名版本需要与作者网站或会议版的其他名单分别引用，不能擅自补齐或合并。代码编辑论文，Reflexion v4

这些合作关注修改指令、执行反馈与跨尝试经验，和几何论文所处理的置信度有不同对象。语言反思是一项系统机制，不是数学上的校准；模型说“我不确定”也不自动等于其概率估计已经可靠。并置研究需要先保留这种差别。

它们共同提示一种评价习惯：模型应依据外部证据接受检查。代码要看执行和测试，成像要看仪器与资料，动力学要看时间演化，置信度要看实际误差。把证据与所宣称的能力对应，是理解其跨领域工作更稳妥的方式。

十一、研究意义与资料范围

Berman 的公开研究显示，机器学习中的结构约束既能帮助泛化，也可能因与目标不匹配而产生新的错误。对称、平滑与置信度都不能被当作无条件优点；它们需要在具体任务和数据中获得定义。

其人物资料仍以公开学术记录为主，不据有限履历补造完整生平。相关论文的理论主张、软件贡献与实例实验也分别保留。游戏与AI4PG研究可以借此建立更精确的模型测试，但应在自己的环境重新检查结构假设、反馈与实际体验，而不把跨领域联系当成已验证的应用。
