Reflexion: Language Agents with Verbal Reinforcement Learning

Reflexion：基于语言强化学习的语言智能体

Noah Shinn 诺亚·希恩 / Federico Cassano 费代里科·卡萨诺 / Edward Berman 爱德华·伯曼 / Ashwin Gopinath 阿什温·戈皮纳特 / Karthik Narasimhan 卡尔蒂克·纳拉西姆汉 / Shunyu Yao 姚顺雨 · 2023 · 2026汉译

简介

Reflexion把任务反馈写成下一次尝试可用的文字经验。文章区分行动生成、结果评估与自我反思三个模块，讨论怎样保存反馈、怎样发现测试本身的错误，并在家务任务、问答与程序生成中比较这种做法的效果。

Abstract 摘要

Large language models (LLMs) have been increasingly used to interact with external environments (e.g., games, compilers, APIs) as goal-driven agents. However, it remains challenging for these language agents to quickly and efficiently learn from trial-and-error as traditional reinforcement learning methods require extensive training samples and expensive model fine-tuning. We propose Reflexion, a novel framework to reinforce language agents not by updating weights, but instead through linguistic feedback. Concretely, Reflexion agents verbally reflect on task feedback signals, then maintain their own reflective text in an episodic memory buffer to induce better decision-making in subsequent trials. Reflexion is flexible enough to incorporate various types (scalar values or free-form language) and sources (external or internally simulated) of feedback signals, and obtains significant improvements over a baseline agent across diverse tasks (sequential decision-making, coding, language reasoning). For example, Reflexion achieves a 91% pass@1 accuracy on the HumanEval coding benchmark, surpassing the previous state-of-the-art GPT-4 that achieves 80%. We also conduct ablation and analysis studies using different feedback signals, feedback incorporation methods, and agent types, and provide insights into how they affect performance. We release all code, demos, and datasets at https://github.com/noahshinn024/reflexion.

大语言模型（LLM）越来越多地被用作目标驱动的智能体，与外部环境（如游戏、编译器和API）交互。然而，让这些语言智能体迅速而高效地从试错中学习，仍然是一项挑战，因为传统强化学习方法需要大量训练样本和代价高昂的模型微调。我们提出Reflexion，一种通过语言反馈而非更新权重来强化语言智能体的新框架。具体而言，Reflexion智能体以语言反思任务反馈信号，随后将自身生成的反思文本保存在情景记忆缓冲区中，以促使后续尝试作出更好的决策。Reflexion十分灵活，能够纳入不同类型（标量或自由形式语言）和不同来源（外部或内部模拟）的反馈信号，并在多种任务（序列决策、编程、语言推理）中相较基线智能体取得显著提升。例如，Reflexion在HumanEval编程基准上的pass@1准确率达到91%，超过此前达到80%的最先进模型GPT-4。我们还使用不同的反馈信号、反馈纳入方式和智能体类型进行消融与分析研究，探讨它们如何影响表现。全部代码、演示和数据集发布于https://github.com/noahshinn024/reflexion。

1 Introduction 1 引言

Recent works such as ReAct [30], SayCan [1], Toolformer [22], HuggingGPT [23], generative agents [19], and WebGPT [17] have demonstrated the feasibility of autonomous decision-making agents that are built on top of a large language model (LLM) core. These methods use LLMs to generate text and actions that can be used in API calls and executed in an environment. Since they rely on massive models with an enormous number of parameters, such approaches have been so far limited to using in-context examples as a way of teaching the agents, since more traditional optimization schemes like reinforcement learning with gradient descent require substantial amounts of compute and time.

ReAct [30]、SayCan [1]、Toolformer [22]、HuggingGPT [23]、生成式智能体 [19]和WebGPT [17]等近期工作，已展示了以大语言模型（LLM）为核心构建自主决策智能体的可行性。这些方法使用LLM生成文本和“行动”，后者可以用于API调用并在环境中执行。由于依赖参数数量极其庞大的巨型模型，这些方法迄今主要只能通过上下文示例来教导智能体，因为使用梯度下降的强化学习等更传统的优化方案，需要大量算力和时间。

In this paper, we propose an alternative approach called Reflexion that uses verbal reinforcement to help agents learn from prior failings. Reflexion converts binary or scalar feedback from the environment into verbal feedback in the form of a textual summary, which is then added as additional context for the LLM agent in the next episode. This self-reflective feedback acts as a `semantic' gradient signal by providing the agent with a concrete direction to improve upon, helping it learn from prior mistakes to perform better on the task. This is akin to how humans iteratively learn to accomplish complex tasks in a few-shot manner -- by reflecting on their previous failures in order to form an improved plan of attack for the next attempt. For example, in figure 1, a Reflexion agent learns to optimize its own behavior to solve decision-making, programming, and reasoning tasks through trial, error, and self-reflection.

本文提出一种名为Reflexion的替代方法，利用言语强化帮助智能体从以往的失败中学习。Reflexion将环境给出的二元或标量反馈转换为文本摘要形式的言语反馈，随后在下一个回合中将其作为额外上下文提供给LLM智能体。这种自我反思反馈为智能体指出具体的改进方向，起到“语义”梯度信号的作用，帮助它从以往错误中学习，从而更好地完成任务。这类似于人类以少样本的方式迭代学习复杂任务：通过反思先前的失败，为下一次尝试制定改进后的行动方案。例如，在图1中，Reflexion智能体通过尝试、出错和自我反思，学会优化自身行为，以解决决策、编程和推理任务。

Generating useful reflective feedback is challenging since it requires a good understanding of where the model made mistakes (i.e. the credit assignment problem [25]) as well as the ability to generate a summary containing actionable insights for improvement. We explore three ways for doing this -- simple binary environment feedback, pre-defined heuristics for common failure cases, and self-evaluation such as binary classification using LLMs (decision-making) or self-written unit tests (programming). In all implementations, the evaluation signal is amplified to natural language experience summaries which can be stored in long-term memory.

生成有用的反思反馈并不容易，因为这既需要充分理解模型在哪些地方犯了错（即信用分配问题 [25]），也需要能够生成包含可付诸行动的改进见解的摘要。我们探索了三种实现途径：简单的二元环境反馈、针对常见失败情形预先定义的启发式方法，以及自我评估，例如利用LLM进行二元分类（决策任务），或自行编写单元测试（编程任务）。在所有实现中，评估信号都被扩展为能够存入长期记忆的自然语言经验摘要。

Reflexion has several advantages compared to more traditional RL approaches like policy or value-based learning: 1) it is lightweight and doesn't require finetuning the LLM, 2) it allows for more nuanced forms of feedback (e.g. targeted changes in actions), compared to scalar or vector rewards that are challenging to perform accurate credit assignment with, 3) it allows for a more explicit and interpretable form of episodic memory over prior experiences, and 4) it provides more explicit hints for actions in future episodes. At the same time, it does have the disadvantages of relying on the power of the LLM's self-evaluation capabilities (or heuristics) and not having a formal guarantee for success. However, as LLM capabilities improve, we only expect this paradigm to get better over time.

相较于基于策略或价值学习等更传统的强化学习方法，Reflexion具有几项优势：1）它较为轻量，不需要微调LLM；2）相较于难以据之进行精确信用分配的标量或向量奖励，它能够提供更细致的反馈形式（例如有针对性地改变行动）；3）它能以更明确、可解释的情景记忆形式保存以往经验；4）它为未来回合中的行动提供更明确的提示。同时，它也存在不足：依赖LLM的自我评估能力（或启发式方法），而且没有成功的形式化保证。不过，随着LLM能力的增强，我们预期这一范式只会随时间进一步改善。

We perform experiments on (1) decision-making tasks to test sequential action choices over long trajectories, (2) reasoning tasks to test knowledge-intensive, single-step generation improvement, and (3) programming tasks to teach the agent to effectively use external tools such as compilers and interpreters. Across all three types of tasks, we observe Reflexion agents are better decision-makers, reasoners, and programmers. More concretely, Reflexion agents improve on decision-making AlfWorld [24] tasks over strong baseline approaches by an absolute 22% in 12 iterative learning steps, and on reasoning questions in HotPotQA [28] by 20%, and Python programming tasks on HumanEval [6] by as much as 11%.

我们在三类任务上开展实验：（1）决策任务，用于测试长轨迹中的序列行动选择；（2）推理任务，用于测试知识密集型单次生成的改进；（3）编程任务，用于教导智能体有效使用编译器、解释器等外部工具。在这三类任务中，我们观察到Reflexion智能体都能作出更好的决策、推理和编程。更具体地说，经过12步迭代学习，Reflexion智能体在AlfWorld [24]决策任务上相较强基线的表现绝对提高22个百分点；在HotPotQA [28]推理问题上提高20%；在HumanEval [6]的Python编程任务上，提升幅度最高达11%。

Reasoning and decision-making 推理与决策

Self-Refine [15] employs an iterative framework for self-refinement to autonomously improve generation through self-evaluation. These self-evaluation and self-improvement steps are conditioned on given task constraints, such as "How can this generation be written in a more positive way". Self-Refine is effective but is limited to single-generation reasoning tasks. Pryzant et al. [21] performs a similar semantic prompt-writing optimization, but is also limited to single-generation tasks. Paul et al. [20] fine-tune critic models to provide intermediate feedback within trajectories to improve reasoning responses. Xie et al. [27] use stochastic beam search over actions to perform a more efficient decision-making search strategy which allows the agent to use foresight advantage due to its self-evaluation component. Yoran et al. [31] and Nair et al. 3 [16] use decider models to reason over several generations. Kim et al. [10] use a retry pattern over a fixed number of steps without an evaluation step. Goodman [9] perform a qualitative evaluation step that proposes optimizations to the previous generation. In this paper, we show that several of these concepts can be enhanced with self-reflection to build a persisting memory of self-reflective experiences which allows an agent to identify its own errors and self-suggest lessons to learn from its mistakes over time.

Programming 编程

Several past and recent works employ variations of test-driven development or code debugging practices. AlphaCode [14] evaluates a set of generations on hidden test cases. CodeT [5] uses self-generated unit tests that are used to score generated function implementations. Self-Debugging [7] employs a debugging component that is used to improve existing implementations given feedback from a code execution environment. CodeRL [12] sets the problem in an RL framework using an actor-critic setup to debug programs given feedback from an execution environment. AlphaCode, Self-Debugging and CodeRL are effective in fixing less-complex program bugs, but they rely upon ground truth test cases that invalidate pass@1 eligibility, and do not use self-reflection to bridge the gap between error identification and implementation improvement. CodeT does not access hidden test cases but does not implement a self-learning step to improve code writing.

过去和近期的一些工作采用了测试驱动开发或代码调试实践的不同变体。AlphaCode [14]利用隐藏测试用例评估一组生成结果。CodeT [5]使用自行生成的单元测试，对生成的函数实现评分。Self-Debugging [7]采用调试组件，根据代码执行环境提供的反馈，改进现有实现。CodeRL [12]将问题置于强化学习框架中，采用行动者—评判者结构，根据执行环境的反馈调试程序。AlphaCode、Self-Debugging与CodeRL能够有效修复复杂度较低的程序错误，但它们依赖真实测试用例，因而不具备按pass@1评估的资格；它们也不利用自我反思来弥合识别错误与改进实现之间的差距。CodeT不访问隐藏测试用例，但也没有实现用于改进代码编写的自我学习步骤。

3 Reflexion: reinforcement via verbal reflection 3 Reflexion：通过言语反思进行强化

We develop a modular formulation for Reflexion, utilizing three distinct models: an Actor, denoted as MaM_a, which generates text and actions; an Evaluator model, represented by MeM_e, that scores the outputs produced by MaM_a; and a Self-Reflection model, denoted as MsrM_{sr}, which generates verbal reinforcement cues to assist the Actor in self-improvement. We provide a detailed description of each of these models and subsequently elucidate their collaborative functioning within the Reflexion framework.

我们为Reflexion构建了一种模块化表述，使用三种不同的模型：行动者（Actor），记作MaM_a，生成文本和行动；评估器（Evaluator）模型，记作MeM_e，对MaM_a生成的输出评分；以及自我反思（Self-Reflection）模型，记作MsrM_{sr}，生成言语强化线索，帮助行动者自我改进。下面先详细介绍各个模型，再阐明它们在Reflexion框架中如何协同工作。

Actor 行动者

The Actor is built upon a large language model (LLM) that is specifically prompted to generate the necessary text and actions conditioned on the state observations. Analogous to traditional policy-based RL setups, we sample an action or generation, ata_t, from the current policy πθ\pi_{\theta} at time tt, receive an observation from the environment oto_t. We explore various Actor models, including Chain of Thought [26] and ReAct [30]. These diverse generation models allow us to explore different aspects of text and action generation within the Reflexion framework, providing valuable insights into their performance and effectiveness. In addition, we also add a memory component mem that provides additional context to this agent. This adaption was inspired by Brooks et al. [3], who suggest a policy iteration approach using in-context learning. Details on how this is populated are provided below.

行动者以大语言模型（LLM）为基础，借助专门设计的提示，根据状态观察生成所需文本和行动。类似于传统的基于策略的强化学习设置，我们在时间tt从当前策略πθ\pi_{\theta}采样一个行动或生成结果ata_t，并接收来自环境的观察oto_t。我们探索了不同的行动者模型，包括思维链 [26]与ReAct [30]。这些不同的生成模型使我们能够在Reflexion框架内探索文本和行动生成的不同方面，为理解它们的表现和有效性提供有价值的见解。此外，我们还加入记忆组件mem，为该智能体提供额外上下文。这一改动受到Brooks等人 [3]的启发，他们提出了利用上下文学习进行策略迭代的方法。下文将详细说明如何填充这一记忆组件。

Evaluator 评估器

The Evaluator component of the Reflexion framework plays a crucial role in assessing the quality of the generated outputs produced by the Actor. It takes as input a generated trajectory and computes a reward score that reflects its performance within the given task context. Defining effective value and reward functions that apply to semantic spaces is difficult, so we investigate several variants of the Evaluator model. For reasoning tasks, we explore reward functions based on exact match (EM) grading, ensuring that the generated output aligns closely with the expected solution. In decision-making tasks, we employ pre-defined heuristic functions that are tailored to specific evaluation criteria. Additionally, we experiment with using a different instantiation of an LLM itself as an Evaluator, generating rewards for decision-making and programming tasks. This multi-faceted approach to Evaluator design allows us to examine different strategies for scoring generated outputs, offering insights into their effectiveness and suitability across a range of tasks.

Reflexion框架中的评估器组件，对评判行动者生成输出的质量起着关键作用。它以生成的轨迹为输入，计算一个反映其在给定任务情境中表现的奖励分数。为语义空间定义有效的价值函数和奖励函数并不容易，因此我们考察了评估器模型的若干变体。在推理任务中，我们探索了基于精确匹配（EM）评分的奖励函数，以确保生成输出与预期解答紧密一致。在决策任务中，我们采用针对具体评估标准预先定义的启发式函数。此外，我们还尝试将LLM本身的另一个实例用作评估器，为决策和编程任务生成奖励。这样从多个方面设计评估器，使我们得以考察对生成输出评分的不同策略，了解它们在不同任务中的有效性与适用性。

Self-reflection 自我反思

The Self-Reflection model instantiated as an LLM, plays a crucial role in the Reflexion framework by generating verbal self-reflections to provide valuable feedback for future trials. Given a sparse reward signal, such as a binary success status (success/fail), the current trajectory, and its persistent memory mem, the self-reflection model generates nuanced and specific feedback. This feedback, which is more informative than scalar rewards, is then stored in the agent's memory (mem). For instance, in a multi-step decision-making task, when the agent receives a failure signal, it can infer that a specific action aia_i led to subsequent incorrect actions ai+1a_{i+1} and ai+2a_{i+2}. The agent can then verbally state that it should have taken a different action, ai′a_i', which would have resulted in ai+1′a_{i+1}' and ai+2′a_{i+2}', and store this experience in its memory. In subsequent trials, the agent can leverage its past experiences to adapt its decision-making approach at time tt by choosing action ai′a_i'. This iterative process of trial, error, self-reflection, and persisting memory enables the agent to rapidly improve its decision-making ability in various environments by utilizing informative feedback signals.

自我反思模型由LLM实现，通过生成言语形式的自我反思，为未来尝试提供有价值的反馈，在Reflexion框架中发挥关键作用。给定稀疏奖励信号，例如二元成功状态（成功／失败）、当前轨迹及持续保存的记忆mem，自我反思模型会生成细致而具体的反馈。这些反馈比标量奖励包含更多信息，随后被存入智能体的记忆（mem）。例如，在多步决策任务中，当智能体收到失败信号时，它可以推断某个特定行动aia_i导致了后续错误行动ai+1a_{i+1}与ai+2a_{i+2}。随后，智能体可以用语言说明，自己本应采取另一个行动ai′a_i'，那样就会产生ai+1′a_{i+1}'与ai+2′a_{i+2}'，并将这一经验存入记忆。在后续尝试中，智能体可以利用以往经验，选择行动ai′a_i'，从而调整时间tt的决策方式。这个由尝试、出错、自我反思及持续记忆构成的迭代过程，使智能体能够利用信息丰富的反馈信号，迅速提高在不同环境中的决策能力。

Memory 记忆

Core components of the Reflexion process are the notion of short-term and long-term memory. At inference time, the Actor conditions its decisions on short and long-term memory, similar 5 to the way that humans remember fine-grain recent details while also recalling distilled important experiences from long-term memory. In the RL setup, the trajectory history serves as the short-term memory while outputs from the Self-Reflection model are stored in long-term memory. These two memory components work together to provide context that is specific but also influenced by lessons learned over several trials, which is a key advantage of Reflexion agents over other LLM action choice works.

短期记忆与长期记忆的概念，是Reflexion过程的核心组成部分。在推断时，行动者依据短期和长期记忆作出决策，就像5人类既记住近期的细节，也从长期记忆中回想提炼后的重要经验一样。在强化学习设置中，轨迹历史充当短期记忆，而自我反思模型的输出则存入长期记忆。这两种记忆组件协同提供上下文：它既包含具体信息，也受到多次尝试中所学教训的影响。这是Reflexion智能体相较于其他LLM行动选择工作的一个主要优势。

The Reflexion process Reflexion过程

Reflexion is formalized as an iterative optimization process in 1. In the first trial, the Actor produces a trajectory τ0\tau_0 by interacting with the environment. The Evaluator then produces a score r0r_0 which is computed as rt=Me(τ0)r_t = M_e(\tau_0). rtr_t is only a scalar reward for trial tt that improves as task-specific performance increases. After the first trial, to amplify r0r_0 to a feedback form that can be used for improvement by an LLM, the Self-Reflection model analyzes the set of {τ0,r0}\{\tau_0, r_0\} to produce a summary sr0sr_0 which is stored in the memory mem. srtsr_t is a verbal experience feedback for trial tt. The Actor, Evaluator, and Self-Reflection models work together through trials in a loop until the Evaluator deems τt\tau_t to be correct. As mentioned in 3, the memory component of Reflexion is crucial to its effectiveness. After each trial tt, srtsr_t, is appended mem. In practice, we bound mem by a maximum number of stored experiences, Ω\Omega (usually set to 1-3) to adhere to max context LLM limitations.

算法1将Reflexion形式化为一个迭代优化过程。在第一次尝试中，行动者通过与环境交互生成轨迹τ0\tau_0。随后，评估器生成分数r0r_0，其计算式为rt=Me(τ0)r_t = M_e(\tau_0)。rtr_t仅是尝试tt的标量奖励，随具体任务表现的提升而提高。在第一次尝试之后，为将r0r_0扩展为LLM可据之改进的反馈形式，自我反思模型分析集合{τ0,r0}\{\tau_0, r_0\}，生成摘要sr0sr_0并存入记忆mem。srtsr_t是尝试tt的言语经验反馈。行动者、评估器与自我反思模型在多次尝试中循环协作，直到评估器判定τt\tau_t正确为止。如第3节所述，记忆组件对于Reflexion的有效性至关重要。每次尝试tt之后，都会将srtsr_t附加到mem中。在实践中，我们用最多保存的经验数量Ω\Omega（通常设为1-3）来限制mem，以适应LLM的最大上下文限制。

4.1 Sequential decision making: ALFWorld 4.1 序列决策：ALFWorld

AlfWorld is a suite of text-based environments that challenge an agent to solve multi-step tasks in a variety of interactive environments based on TextWorld [8]. Following Yao et al. [30], we run the agent in 134 AlfWorld environments across six different tasks, including finding hidden objects (e.g., finding a spatula in a drawer), moving objects (e.g., moving a knife to the cutting board), and manipulating objects with other objects (e.g., chilling a tomato in the fridge). We use ReAct [30] as the action generator as Yao et al. [30] has shown success in long trajectory decision-making using explicit intermediate thoughts. AlfWorld tasks naturally require a self-evaluation step as the environment can only signal if a task is complete. To achieve fully autonomous behavior, we implement two self-evaluation techniques: natural language classification using an LLM and a hand-written heuristic. The heuristic is simple: if the agent executes the same action and receives the same response for more than 3 cycles, or if the number of actions taken in the current environment exceeds 30 (inefficient planning), we self-reflect. In the baseline runs, if self-reflection is suggested, we skip the self-reflection process, reset the environment, and start a new trial. In the Reflexion runs, the agent uses self-reflection to find its mistake, update its memory, reset the environment, and start a new trial. To avoid very long prompt windows that may exceed the maximum limit, we truncate the agent's memory to the last 3 self-reflections (experiences).

AlfWorld是一套基于文本的环境，要求智能体在基于TextWorld [8]的多种交互环境中解决多步任务。遵循Yao等人 [30]的做法，我们让智能体在134个AlfWorld环境中运行，涵盖六种不同任务，包括寻找隐藏物品（如在抽屉里找铲子）、移动物品（如将刀移到砧板上），以及借助其他物品操作某物（如将番茄放入冰箱冷却）。我们使用ReAct [30]作为行动生成器，因为Yao等人 [30]已展示了借助显式中间思考进行长轨迹决策的成功。AlfWorld任务自然需要自我评估步骤，因为环境只能给出任务是否完成的信号。为了实现完全自主的行为，我们实现了两种自我评估技术：使用LLM进行自然语言分类，以及人工编写的启发式规则。该规则很简单：如果智能体执行相同行动并收到相同响应，连续超过3个循环，或者在当前环境中执行的行动数超过30（规划低效），便进行自我反思。在基线运行中，如果建议进行自我反思，我们就跳过反思过程，重置环境，开始新的尝试。在Reflexion运行中，智能体则通过自我反思找出错误、更新记忆、重置环境，再开始新的尝试。为避免提示窗口过长而超过上限，我们仅保留智能体最近3次自我反思（经验），截去更早的记忆。

To avoid syntactic errors, we provide two domain-specific few-shot trajectories to the agent. We use the same few-shot trajectory examples as Yao et al. [30] with GPT-3 for the LLM. AlfWorld tasks, ReAct few-shot prompts, and Reflexion examples are included in the appendix.

4.2 Reasoning: HotpotQA 4.2 推理：HotpotQA

HotPotQA [28] is a Wikipedia-based dataset with 113k question-and-answer pairs that challenge agents to parse content and reason over several supporting documents. To test improvement in reasoning only ability, we implement Reflexion + Chain-of-Thought (CoT) [26] for step-by-step Q→AQ \rightarrow A and QQ, Cgt→AC_{gt} \rightarrow A implementations, where QQ is the question, CgtC_{gt} is the ground truth context from the dataset, and AA is the final answer. Since CoT is not a multi-step decision-making technique, we give CgtC_{gt} to the agent so that we can isolate the reasoning behavior over large sections of the provided text. To test holistic question and answering ability, which requires reasoning and action choice, we implement a Reflexion + ReAct [30] agent that can retrieve relevant context using a Wikipedia API and infer answers using step-by-step explicit thinking. For CoT implementations, we use 6-shot prompting; for ReAct, we use 2-shot prompting, and for self-reflection, we use 2-shot prompting. All examples can be found in the appendix.

HotPotQA [28]是一个基于维基百科的数据集，包含113k个问答对，要求智能体解析内容，并依据若干支持文档进行推理。为仅测试推理能力的改进，我们实现了Reflexion + 思维链（CoT）[26]，分别采用逐步的Q→AQ \rightarrow A和QQ、Cgt→AC_{gt} \rightarrow A设置，其中QQ是问题，CgtC_{gt}是数据集中的真实上下文，AA是最终答案。由于CoT不是一种多步决策技术，我们将CgtC_{gt}提供给智能体，从而单独考察它针对所给大段文本的推理行为。为测试需要推理和行动选择的整体问答能力，我们实现了Reflexion + ReAct [30]智能体，借助维基百科API检索相关上下文，并通过逐步的显式思考推断答案。对于CoT实现，我们使用6样本提示；对于ReAct，使用2样本提示；对于自我反思，也使用2样本提示。全部示例均见附录。

Robustly evaluating natural language answers is a long-standing problem in NLP. Therefore, between trials, we use exact match answer grading using the environment to give a binary success signal to the agent. After each trial, the self-reflection loop is employed to amplify the binary signal, similar to the decision-making setup 4.1 in AlfWorld with a memory size of 3 experiences.

稳健评估自然语言答案，是自然语言处理领域长期存在的问题。因此，在两次尝试之间，我们利用环境进行答案精确匹配评分，为智能体提供二元成功信号。每次尝试之后，都会使用自我反思循环来扩展这一二元信号，类似于AlfWorld中第4.1节的决策设置，记忆容量为3条经验。

Results 结果

Reflexion outperforms all baseline approaches by significant margins over several learning steps. Furthermore, ReAct-only, CoT-only, and CoT (GT)-only implementations fail to probabilistically improve on any tasks, meaning that no failed tasks from the first trial from any of the baseline approaches were able to be solved in subsequent trials using a temperature of 0.7 In the Reflexion runs, we allowed the agent to gather experience and retry on failed tasks until it produced 3 consecutive failed attempts on the particular task. Naturally, the CoT (GT) achieved higher accuracy scores as it was given access to the ground truth context of the question. Still, the CoT (GT) agent is unable to correctly infer the correct answer for 39% of the questions, but Reflexion helps the agent to correct its mistakes without access to the ground truth answer to improve its accuracy by 14%.

经过若干学习步骤，Reflexion以显著幅度优于所有基线方法。此外，仅ReAct、仅CoT以及仅CoT（GT）的实现，都未能通过概率性的重试在任何任务上取得改进：也就是说，使用0.7的温度时，任何基线方法在第一次尝试中失败的任务，都未能在后续尝试中得到解决。在Reflexion运行中，我们允许智能体积累经验，并重试失败任务，直到它在该项任务上连续失败3次为止。CoT（GT）能够获得问题的真实上下文，因此自然取得更高的准确率。不过，CoT（GT）智能体仍无法对39%的问题正确推断出答案；Reflexion则在不访问真实答案的情况下，帮助智能体纠正错误，使其准确率提高14%。

Analysis 分析

We perform an ablation experiment to isolate the advantage of the self-reflective step for reasoning using CoT (GT) as the baseline approach 4. Recall that CoT (GT) uses Chain-of-Thought reasoning with provided ground truth context, which tests reasoning ability over long contexts. Next, we add an element of episodic memory (EPM) by including the most recent trajectory. For the Reflexion agent, we implement the standard self-reflection step as a final pass. Intuitively, we test if the agent is iteratively learning more effectively by using verbal explanation using language written in the first person. 4 shows that self-reflection improves learning by an 8% absolute boost over the episodic memory learning advantage. This result supports the argument that refinement-only approaches are not as effective as self-reflection-guided refinement approaches.

我们以CoT（GT）为基线方法开展消融实验，单独考察自我反思步骤对推理的优势，见图4。回顾前文，CoT（GT）利用给定的真实上下文进行思维链推理，测试针对长上下文的推理能力。接着，我们通过纳入最近一次轨迹，加入情景记忆（EPM）要素。对于Reflexion智能体，我们将标准自我反思步骤作为最后一轮处理。直观地说，我们测试的是：使用第一人称语言写出的言语解释，能否让智能体更有效地迭代学习。图4表明，在情景记忆所带来学习优势的基础上，自我反思又使表现绝对提高8个百分点。该结果支持这样的判断：仅做改进的方法，不如由自我反思引导改进的方法有效。

4.3 Programming 4.3 编程

We evaluate the baseline and Reflexion approaches on Python and Rust code writing on MBPP [2], HumanEval [6], and LeetcodeHardGym, our new dataset. MBPP and HumanEval measure function body generation accuracy given natural language descriptions. We use a benchmark language compiler, MultiPL-E [4], to translate subsets of HumanEval and MBPP to the Rust language. MultiPL-E is a collection of small compilers that can be used to translate Python benchmark questions to 18 other languages. We include experiments for Rust code generation to demonstrate that Reflexion implementations for code generation are language-agnostic and can be used for interpreted and compiled languages. Lastly, we introduce a new benchmark, LeetcodeHardGym, which is an interactive programming gym that contains 40 Leetcode hard-rated questions that have been released after October 8, 2022, which is the pre-training cutoff date of GPT-4 [18].

我们在MBPP [2]、HumanEval [6]以及我们的新数据集LeetcodeHardGym上，对基线方法与Reflexion方法进行Python和Rust代码编写评估。MBPP与HumanEval衡量根据自然语言描述生成函数体的准确率。我们使用基准语言编译器MultiPL-E [4]，将HumanEval与MBPP的子集转换为Rust语言。MultiPL-E是一组小型编译器，可将Python基准题目转换为另外18种语言。我们纳入Rust代码生成实验，以展示Reflexion的代码生成实现不依赖具体语言，既可用于解释型语言，也可用于编译型语言。最后，我们推出新基准LeetcodeHardGym，这是一个交互式编程gym，包含40道评级为hard的Leetcode题目；这些题目都发布于2022年10月8日之后，而该日期是GPT-4 [18]的预训练截止日期。

The task of programming presents a unique opportunity to use more grounded self-evaluation practices such as self-generated unit test suites. Thus, our Reflexion-based programming task implementation is eligible for pass@1 accuracy reporting. To generate a test suite, we use Chain-of-Thought prompting [26] to produce diverse, extensive tests with corresponding natural language descriptions. Then, we filter for syntactically valid test statements by attempting to construct a valid abstract syntax tree (AST) for each proposed test. Finally, we sample nn tests from the collection of generated unit tests to produce a test suite TT, denoted as {t0,t1,…,tn}\{t_0, t_1, …, t_n\}. We set nn to a maximum of 6 unit tests. Aside from the unit test suite component, the setup for the learning loop for a Reflexion programming agent is identical to the reasoning and decision-making agents with a max memory limit of 1 experience.

编程任务提供了独特机会，使我们能够采用更有实据的自我评估实践，例如自行生成单元测试套件。因此，我们基于Reflexion的编程任务实现，具备报告pass@1准确率的资格。为生成测试套件，我们使用思维链提示 [26]，产生多样而广泛的测试及相应的自然语言描述。接着，我们尝试为每个提出的测试构建有效的抽象语法树（AST），以筛选语法有效的测试语句。最后，从生成的单元测试集合中采样nn个测试，形成测试套件TT，记作{t0,t1,…,tn}\{t_0, t_1, …, t_n\}。我们将nn的最大值设为6个单元测试。除单元测试套件组件之外，Reflexion编程智能体的学习循环设置，与推理和决策智能体相同，记忆上限为1条经验。

Analysis 分析

We acknowledge that self-reflecting code-generation agents are bound to their ability to write diverse, comprehensive tests. Therefore, in the case in which the model generates a flaky test suite, it is possible that all tests pass on an incorrect solution and lead to a false positive label on a code completion [11]. On the other hand, if the model produces an incorrectly written test suite, it is possible for some of the tests to fail on a correct solution, leading to a self-reflection generation that is conditioned on a false negative code completion. Given the implementation of Reflexion, false negatives are preferred over false positives as the agent may be able to use self-reflection to identify the incorrect test(s) and prompt itself to keep the original code completion intact. On the other hand, if an invalid test suite returns a false positive completion (all internal test cases pass but the implementation is incorrect), the agent will prematurely report an invalid submission. In 2, various conditions are measured to analyze performance beyond pass@1 accuracy. Previously, we displayed the inferior performance of Reflexion to the baseline GPT-4 on MBPP Python. In 2, we observe a notable discrepancy between the false positive labels produced by internal test execution, P(not pass@1 generation correct | tests pass). That is, the probability that a submission will fail given that it passes all unit tests. For HumanEval and MBPP Python, the baseline pass@1 accuracies are relatively similar, 82% and 80%, respectively. However, the false positive test execution rate for MBPP Python is 16.3% while the rate for HumanEval Python is a mere 1.4%, leading to 91% overall accuracy 1.

我们承认，进行自我反思的代码生成智能体，受限于其编写多样而全面的测试的能力。因此，如果模型生成了不稳定的测试套件，便可能出现错误解答通过全部测试的情况，导致代码补全结果被标记为假阳性 [11]。另一方面，如果模型编写的测试套件有误，则可能出现正确解答未通过某些测试的情况，从而基于一个假阴性的代码补全结果生成自我反思。根据Reflexion的实现方式，假阴性优于假阳性，因为智能体可能通过自我反思识别错误测试，并提示自己保留原代码补全结果。相反，若无效测试套件返回假阳性的补全结果（所有内部测试用例均通过，但实现有误），智能体就会过早报告无效提交。表2测量了不同情形，以分析pass@1准确率之外的表现。此前，我们已展示Reflexion在MBPP Python上逊于基线GPT-4。表2中，内部测试执行产生的假阳性标记——P(not pass@1 generation correct | tests pass)——呈现明显差异，即提交通过全部单元测试时，该提交仍会失败的概率。对于HumanEval与MBPP Python，基线pass@1准确率相近，分别为82%与80%。然而，MBPP Python的测试执行假阳性率为16.3%，HumanEval Python则仅为1.4%，从而产生表1所示91%的总体准确率。

Ablation study 消融研究

We test the composite approach of Reflexion for test generation and self-reflection cooperation on a subset of the 50 hardest HumanEval Rust problems. Our Rust compiler environment provides verbose error logs and helpful debugging hints, therefore serving as a good playground for compromised approaches. First, we omit internal test generation and execution steps, which test the agent to self-reflect without guidance from current implementations. 3 shows an inferior 52% vs 60% (baseline) accuracy, which suggests that the agent is unable to determine if the current implementation is correct without unit tests. Therefore, the agent must participate in all iterations of the run without the option to return early, performing harmful edits to the implementation.

我们在HumanEval Rust中最难的50道题的一个子集上，测试Reflexion中测试生成与自我反思协作的组合方法。我们的Rust编译器环境提供详尽的错误日志与有用的调试提示，因此是检验组件删减方法的良好试验场。首先，我们省略内部测试生成和执行步骤，测试智能体在缺乏当前实现所提供指导时进行自我反思的能力。表3显示，其准确率较差，为52%，而基线为60%，这提示没有单元测试时，智能体无法判断当前实现是否正确。因此，智能体不得不参与整次运行的全部迭代，无法提前返回，进而对实现作出有害修改。

Next, we test self-reflection contribution by omitting the natural language explanation step following failed unit test suite evaluations. Intuitively, this challenges the agent to combine the tasks of error identification and implementation improvement across all failed unit tests. Interestingly, the compromised agent does not improve performance over the baseline run. We observe that the test generation and code compilation steps are able to catch syntax and logic errors, but the implementation fixes do not reflect these indications. These empirical results suggest that several recent works that 9 propose blind trial and error debugging techniques without self-reflection are ineffective on harder tasks such as writing complex programs in Rust.

接着，我们省略单元测试套件评估失败之后的自然语言解释步骤，以测试自我反思的贡献。直观地说，这要求智能体针对全部失败的单元测试，将识别错误与改进实现两项任务结合起来。有意思的是，删去该组件后的智能体相较基线运行并没有改善表现。我们观察到，测试生成和代码编译步骤能够发现语法与逻辑错误，但对实现所作的修正未能体现这些提示。这些实证结果提示，近期若干工作9提出的不使用自我反思的盲目试错调试技术，在编写复杂Rust程序等较难任务上并不奏效。

5 Limitations 5 局限

At its core, Reflexion is an optimization technique that uses natural language to do policy optimization. Policy optimization is a powerful approach to improve action choice through experience, but it may still succumb to non-optimal local minima solutions. In this study, we limit long-term memory to a sliding window with maximum capacity, but we encourage future work to extend the memory component of Reflexion with more advanced structures such as vector embedding databases or traditional SQL databases. Specific to code generation, there are many practical limitations to test-driven development in specifying accurate input-output mappings such as non-deterministic generator functions, impure functions that interact with APIs, functions that vary output according to hardware specifications, or functions that invoke parallel or concurrent behavior that may be difficult to predict.

从核心上说，Reflexion是一种利用自然语言进行策略优化的优化技术。策略优化能够通过经验有效改善行动选择，但仍可能陷入非最优的局部极小解。在本研究中，我们将长期记忆限制在具有最大容量的滑动窗口内，同时鼓励未来工作采用向量嵌入数据库或传统SQL数据库等更高级的结构，扩展Reflexion的记忆组件。具体到代码生成，测试驱动开发在准确规定输入—输出映射方面存在许多实际限制，例如非确定性的生成器函数、与API交互的非纯函数、随硬件规格改变输出的函数，以及调用难以预测的并行或并发行为的函数。

6 Broader impact 6 更广泛的影响

Large language models are increasingly used to interact with external environments (e.g. the Internet, software, robotics, etc.) and humans. Our work has the potential of reinforcing and empowering these agents toward greater automation and work efficiency, but it also amplifies the risks when these agents were put into misuse. We believe that this direction of research will need more effort in safety and ethical considerations.

大语言模型越来越多地被用于同外部环境（如互联网、软件、机器人等）及人类交互。我们的工作有潜力强化这些智能体的能力，提高自动化程度与工作效率；但当这些智能体被滥用时，它也会放大风险。我们认为，这一研究方向需要在安全与伦理考量方面作出更多努力。

On the other hand, reinforcement learning has suffered from its black-box policy and optimization setups in which interpretability and alignment have been challenging. Our proposed “verbal” reinforcement learning might address some of the issues and turn autonomous agents more interpretable and diagnosable. For example, in the case of tool-usage that may be too hard for humans to understand, self-reflections could be monitored to ensure proper intent before using the tool.

另一方面，强化学习受制于黑箱式的策略与优化设置，可解释性和对齐一直是难题。我们提出的“言语”强化学习，或许能解决其中部分问题，使自主智能体更容易解释和诊断。例如，当工具使用过于复杂、难以为人理解时，可以监控自我反思，以便在使用工具前确保意图恰当。

7 Conclusion 7 结论

In this work, we present Reflexion, an approach that leverages verbal reinforcement to teach agents to learn from past mistakes. We empirically show that Reflexion agents significantly outperform currently widely-used decision-making approaches by utilizing self-reflection. In future work, Reflexion could be used to employ more advanced techniques that have been thoroughly studied in traditional RL settings, such as value learning in natural language or off-policy exploration techniques.

本文提出Reflexion，一种利用言语强化来教导智能体从以往错误中学习的方法。我们通过实证表明，Reflexion智能体利用自我反思，显著优于目前广泛采用的决策方法。未来，Reflexion可用于采用传统强化学习中已得到深入研究的更高级技术，例如以自然语言进行价值学习，或采用离策略探索技术。

8 Reproducibility 8 可复现性

We highly advise others to use isolated execution environments when running autonomous code writing experiments as the generated code is not validated before execution.

在开展自主代码编写实验时，我们强烈建议使用隔离的执行环境，因为生成的代码在执行之前并未经过验证。

14 B.1 WebShop Limitation 14 B.1 在WebShop上的局限

In 5, we briefly state that Reflexion struggles to overcome local minima choices that require extremely creative behavior to escape. We observe this shortcoming in an experiment on WebShop [29]. WebShop is a web-based problem-solving benchmark that tests agents to navigate an e-commerce website to locate and purchase products given requests from clients. We test a two-shot ReAct + Reflexion agent in 100 environments. However, after only four trials, we terminate the runs as the agent does not show signs of improvement 6. Further, the agent does not generate helpful, intuitive self-reflections after failed attempts. We conclude that Reflexion is unable to solve tasks that require a significant amount of diversity and exploration. In AlfWorld, the agent is able to adequately explore new environments because the permissible actions can be seen in the observations. In HotPotQA, the agent faces a similar WebShop search query task but is more successful as the search space for Wikipedia articles is more diverse and requires less precise search queries. A common problem for e-commerce search engines is properly handling ambiguity in natural language search interpretations. Thus, WebShop presents a task that requires very diverse and unique behavior from a Reflexion agent.

在第5节中，我们简要指出，Reflexion难以克服需要极富创造性的行为才能摆脱的局部极小选择。我们在WebShop [29]实验中观察到了这一缺点。WebShop是一个基于网络的问题求解基准，测试智能体能否根据客户要求，浏览电子商务网站，找到并购买产品。我们在100个环境中测试了一个采用2样本提示的ReAct + Reflexion智能体。然而，仅经过四次尝试，我们便终止运行，因为智能体未显示出改进迹象，见图6。此外，智能体在尝试失败之后，也没有生成有用、直观的自我反思。我们据此得出结论，Reflexion无法解决需要大量多样性与探索的任务。在AlfWorld中，智能体能够充分探索新环境，因为观察中可以看到允许的行动。在HotPotQA中，智能体面对的是类似WebShop的搜索查询任务，却表现得更成功，因为维基百科文章的搜索空间更多样，所需查询的精确度也较低。电子商务搜索引擎的一个常见问题，是妥善处理自然语言搜索解释中的歧义。因此，WebShop提出了一项要求Reflexion智能体表现出高度多样且独特行为的任务。
