# 简介

Pac-Man是Namco于1980年推出的街机游戏。玩家用四方向操作引导黄色角色在迷宫中吃掉豆点，同时躲避四只彩色幽灵；吃到能量豆以后，追逐关系会暂时逆转，玩家能够反过来吞吃幽灵。作品把清楚的空间目标、可辨认的敌人行为和短暂的力量变化结合起来，使一块固定迷宫不断产生新的局面。

岩谷彻Toru Iwatani负责企划与视觉设计，官方年表另列甲斐敏夫Toshio Kai负责声音、舟木茂雄Shigeo Funaki负责程序。日本首次测试、正式公开发行与美国上市并非同一天：官方年表记载1980年5月22日首次测试、7月向日本公众发行、10月进入美国。通常所说的生日对应首次测试，不能不加说明地当成全部地区的商业发行日。[1]

# 从“吃”出发的街机设计

岩谷在1985年访谈中说明，设计起点是“吃”这个动作以及能让人愉快的视觉形象。缺一角的圆形成了容易辨认的角色，张合的嘴又直接表现基本行为。玩家不需要理解角色身世，便能从运动和豆点消失理解目标。概念、图形与操作在同一个动作上会合。[2]

他希望把女性和约会中的情侣带进当时偏向男性的游戏厅。这个目标关系到题材、色彩、敌人形象和直观控制，而不仅是后来市场宣传追加的说法。与此同时，岩谷也承认，设计时并没有投入大量时间征求女性意见。他的判断应理解为一位男性设计者对扩大受众的主动设想，不能直接当成所有女性的偏好研究。[3]

吃豆的行动需要有阻力才会形成游戏。幽灵使清理迷宫变成需要观察和绕行的任务；能量豆则让弱小角色获得反击窗口。这个循环把威胁与释放放在同一空间里，不需要切换成另一套战斗操作。玩家仍然只控制方向，但同样的追赶动作会随双方状态改变意义。

简单操作并不等于制作轻松。岩谷的复盘强调，团队对攻击波次、移动节奏和难度做了反复调整。看起来直接的规则，是不断删减与平衡的结果。设计者选择让复杂性存在于几种关系之间，而没有把它表现为大量按钮、装备或文字说明。[3]

# 固定迷宫里的持续变化

迷宫让玩家能够预先看到大部分路线，也让危险相互交汇。岔路提供选择，狭窄通道限制逃脱，转角则要求及时决定方向。角色没有惯常意义上的攻击按钮，生存主要依靠位置与时机。移动不仅把主角从一处送到另一处，也持续改变它与四个敌人的距离。

豆点把整张地图转化为需要逐步完成的任务。每个吃掉的点都会留下已经经过的痕迹，未清理区域因此变得可见。完成目标有时要求返回危险通道，而最安全的路线也未必最有效率。玩家在局部脱险与全局清场之间反复权衡，不能只沿着永远容易撤退的区域打转。

能量豆在地图中数量有限，并且处于特定位置。提前吃掉能够缓解眼前危险，却会消耗后来可能需要的反击机会；等待幽灵聚近又可能提高一次逆转的收益。资源的价值取决于局面，玩家必须判断现在使用还是保留。力量变化由空间对象触发，使路线规划与战术时机相连。

两侧通道让画面边缘成为连接关系。看似离开屏幕的动作会把角色送到另一边，玩家对距离的判断因此不能完全依靠平面直线。迷宫既是一张可读图形，也是有特殊连接规则的空间。理解这种连接并在追逐中使用它，是学习地图的一部分。

# 四个敌人为什么比一群同类更有性格

岩谷把四只幽灵的移动算法称为设计中最困难、也最核心的部分。它们颜色不同，并有不同的行动倾向，不只是同一敌人的四个外观复制。玩家反复面对这些差异，逐渐把路线选择读成性格：有的压力更直接，有的更像是在截断去路。可辨认行为使简单造型获得了角色感。[2][3]

这里的人工智能属于有限的游戏决策程序。幽灵根据既定规则和状态更新运动，不是通过每位玩家的长期资料训练出一个全新对手。颜色、追逐位置和状态反馈帮助玩家建立预期；能够学习这种预期，正是技巧不断增长的基础。若把它们笼统称为会自行学习的智能体，就会遗漏作品真正精细的设计。

四种倾向在同一迷宫里组合，比单独一种规则产生更丰富的压力。一个幽灵的行动可能迫使玩家转弯，而转弯后的道路又被另一个幽灵接近。玩家体验到的是相互作用的局面，不必在脑中计算全部内部参数。这种设计显示，敌人数量有限时，差异化的规则仍能产生有层次的协同威胁。

行为需要为玩家留下喘息。持续、毫无间隙的围堵会让局面既难理解又缺乏节奏；攻击波次与速度安排使紧张有所起伏。敌人的目标不是在每一瞬间以最高效率消灭玩家，而是维持一场值得继续投入的追逐。人工智能的效果因此应按体验与可读性评估，不能只按胜率排列。

# 力量逆转与身体反馈

吃到能量豆以后，幽灵的颜色和行为改变，玩家能够立刻看见规则已经切换。先前需要避开的对象变成值得追赶的目标，同一迷宫也短暂显得宽敞起来。变化不只是增加分数奖励，它重写了玩家对距离、风险与时间的判断。

这种力量并不永久存在。玩家需要估计剩余窗口，决定追多远、何时重新准备逃跑。此前追得越积极，逆转结束时越可能处于危险位置。能量豆因此制造了带后果的诱惑：它让玩家暂时强大，又要求玩家及时承认这种强大正在消退。

被吃掉的幽灵以眼睛形态返回中央，再恢复原来的追逐身份。这个过程让失败的敌人仍保留可见连续性，并以漫画式表现缓和暴力。作品没有依赖逼真的伤害细节，却能清楚传达谁现在占优势、角色处于什么状态。视觉简化与规则表达在这里相互支持。

豆点、幽灵、能量豆和主角共同形成一套紧凑的动作语汇。玩家的输入很少，反馈却有明确差异：食物消失、身体改变方向、敌人改变颜色或形态。学习不必首先经过长篇解释，而可以通过连续的感知与试验发生。这种易进入的表面，也容纳了需要长时间练习的路线技巧。

# 声音、短动画与可记忆形象

Pac-Man的角色是一个具有嘴部动作的圆形轮廓。它既能作为地图中的小像素被识别，也能脱离画面成为印刷品上的标识。角色造型与主要动作保持一致，使跨媒介辨认不完全依赖标题文字。这一形象为后来的传播与多种商品合作提供了辨识基础。

幽灵的圆滑外形、鲜明颜色与双眼方向，让它们同时具有威胁和滑稽感。岩谷复盘中提到公司内部曾有人建议统一改成红色，而团队最终保留了差异。不同颜色不仅增加装饰，也帮助人们在快速运动中区分敌人，把观察结果积累到特定角色身上。[3]

关间短动画让追逐关系进入一个暂时不受玩家控制的表演。角色可以在普通规则之外出现夸张笑料，玩家获得短暂休息，也进一步认识这组形象。岩谷把这部分动画列为开发中遇到的技术问题之一。它的作用并非补足宏大剧情，而是给高度重复的行动增加情绪和性格。[3]

声音同样承担状态与节奏提示。短促的进食声把连续移动切成可感知的动作，音乐和效果音又区分开局、危险和结束。玩家不只看着一颗图标移动，而是通过反复的视觉、听觉反馈体验一个有身体节奏的角色。分析它的审美，需要把声画的时序放在静态截图之外考虑。

# 固定难度与未实现的自适应构想

岩谷在2005年复盘中提出过一项没有完成的设想：依据玩家犯错所需的时间判断其水平，再即时调整人工智能难度。制作周期内没有足够时间实现它。这个说明非常重要，因为作品已实现的分阶段难度变化，与开发者想加入的实时适应系统，是不同层次的事实。[3]

固定规则给予玩家反复学习的机会，也让熟练者能够发展路线和时机知识。自适应设计则可能让同一操作在不同玩家或不同时间面对不同压力。两者各有目标，不能简单把没有自适应看作人工智能失败。Pac-Man的经典张力，很大程度上来自玩家与相对稳定系统之间可以逐渐深化的关系。

这种稳定也带来争论：若高手掌握了可重复模式，游戏是否仍然有变化？问题不能只用是否包含随机数回答。操作精度、实时判断和多个移动对象的相遇，仍会要求人实际执行知识；知道一条路线和在压力中准确完成它，并非同一能力。可学习性既可能减少惊喜，也能够支持精熟的满足。

街机环境还使难度涉及商业安排。一次投入之后能够游玩多久、失败是否愿意再来，都关系到运营者与玩家的目标。原始经营和维修手册所记录的机台设置，提醒人们游戏不是脱离场所的抽象规则。不同版本与设置形成了各自的难度条件。

# 性别目标、普及与版本边界

扩大女性受众的目标，促成了对暴力题材、控制复杂度和游戏厅氛围的反思；但把“女性喜欢吃东西”当成普遍结论，仍会重现设计年代的性别定型。更有解释力的读法，是考察团队怎样把一个受众假设转成可供更多人实际尝试的形式，再承认参与者能够超出设计者预设。

作品中的可爱也没有取消竞争。高速移动、追逐和清场仍要求持续集中注意，失误会终止一条生命。它把强度与亲近感放在一起，说明友善的形象不必对应松散的挑战。受众扩大可以通过规则表达与情绪风格发生，而不只是降低难度或减少可精熟的空间。

Pac-Man的后续移植、改作和衍生作品应当逐一识别。家用机版本会受到分辨率、颜色、声音和控制设备限制，迷宫及敌人表现也可能改变；Ms. Pac-Man与后来的重制作品更具有自己的开发史。1980年原作的作者与机制，不能自动覆盖所有带着黄色角色名字的游戏。

同样，官方历史网站的当代截图是对原作的展示材料，它可以说明迷宫和角色，但不是游戏创作当天留下的摄影证据。区分作品年代、所示版本和图像制作时间，才能避免把传播史压成一个时间点。保存原机资料与开发者回忆，也能解释为什么同样叫“吃豆人”的体验会存在差异。

# 路线为什么需要不断重估

清场接近结束时，地图上剩余的豆点通常更加分散。玩家不能只追求眼前最安全的连续区域，而需要把远处残留的目标重新纳入路线。已经走过的地面虽然不再提供同样的进度，却仍然可能是回避敌人或接近能量豆的必经之路。任务完成程度因此改变了空间的实际价值，同一条通道在开局与末段承担不同作用。

观察敌人也不是离开行动之后才做的推理。玩家在转弯、追赶和撤退中持续更新判断，必须把片刻前看见的位置与现在可能到达的地方联系起来。画面公开了许多信息，却没有替人安排下一步。它把可见性转化为需要及时使用的知识，解释了为何规则能够很快说明，熟练操作却仍需漫长积累。

分数目标又能改变同一局面的选择。单纯清理豆点与尽可能利用力量窗口，可能要求不同的移动路线。安全完成和冒险争取额外收益并存，使玩家能够在明确的基本目标内选择自己的风险程度。这种选择无需额外模式菜单，已经藏在追逐关系与地图资源之中。

迷宫的稳定还使观看别人游玩具有实际学习价值。旁观者能够认出同样的岔路和能量豆位置，把别人的逃脱与失败联系到自己的经历。技巧可以通过观察传递，但仍需亲自把方向和时机配合起来。作品因此能够围绕一套清楚可见的空间形成共同话题，个人操作与现场观看相互加强。

这样的可共享性与角色形象共同作用。人们既可以谈论哪只幽灵令人头疼，也可以指着某条通道解释刚才的错误。算法结果被压缩成大家都能辨认的场景，使复杂判断具有可以讲述的形式。这是一种与长篇情节不同的传播能力，却同样参与作品如何被记住。

# 在游戏人工智能史中的位置

Pac-Man展示了一种通过可读差异塑造角色的路线。四只幽灵不需要复杂背景故事，就能凭重复可察觉的行为让玩家产生期待；玩家又通过自己的选择把这些期待变成逃脱或包围的具体场面。叙事性在这里存在于追逐、逆转与再度受威胁的节奏之中，而不主要依靠文字情节。

它对设计的启示也相当具体：给相似敌人安排不同倾向，用清楚反馈公开状态变化，让有限控制支持多层判断，再通过波次和空间制造压力起伏。这些原则可以被其他游戏借鉴，但具体借鉴关系需要开发者说明才能确认。形式相似只能支持比较，不能凭相似就编造直接影响链。

把作品放回原始街机条件，还能看见人工智能与视觉设计共同工作的方式。算法决定敌人怎样移动，颜色和轮廓帮助玩家读出差异，地图把差异转为可操作的风险。它们合在一起形成了一场清楚又难以穷尽的游戏；单独抽出一个最聪明的敌人算法，反而不足以解释整部作品的魅力。

# 固定迷宫里的持续变化

迷宫让玩家能够预先看到大部分路线，也让危险相互交汇。岔路提供选择，狭窄通道限制逃脱，转角则要求及时决定方向。角色没有惯常意义上的攻击按钮，生存主要依靠位置与时机。移动不仅把主角从一处送到另一处，也持续改变它与四个敌人的距离。

豆点把整张地图转化为需要逐步完成的任务。每个吃掉的点都会留下已经经过的痕迹，未清理区域因此变得可见。完成目标有时要求返回危险通道，而最安全的路线也未必最有效率。玩家在局部脱险与全局清场之间反复权衡，不能只沿着永远容易撤退的区域打转。

能量豆在地图中数量有限，并且处于特定位置。提前吃掉能够缓解眼前危险，却会消耗后来可能需要的反击机会；等待幽灵聚近又可能提高一次逆转的收益。资源的价值取决于局面，玩家必须判断现在使用还是保留。力量变化由空间对象触发，使路线规划与战术时机相连。

两侧通道让画面边缘成为连接关系。看似离开屏幕的动作会把角色送到另一边，玩家对距离的判断因此不能完全依靠平面直线。迷宫既是一张可读图形，也是有特殊连接规则的空间。理解这种连接并在追逐中使用它，是学习地图的一部分。

# 四个敌人为什么比一群同类更有性格

岩谷把四只幽灵的移动算法称为设计中最困难、也最核心的部分。它们颜色不同，并有不同的行动倾向，不只是同一敌人的四个外观复制。玩家反复面对这些差异，逐渐把路线选择读成性格：有的压力更直接，有的更像是在截断去路。可辨认行为使简单造型获得了角色感。[2][3]

这里的人工智能属于有限的游戏决策程序。幽灵根据既定规则和状态更新运动，不是通过每位玩家的长期资料训练出一个全新对手。颜色、追逐位置和状态反馈帮助玩家建立预期；能够学习这种预期，正是技巧不断增长的基础。若把它们笼统称为会自行学习的智能体，就会遗漏作品真正精细的设计。

四种倾向在同一迷宫里组合，比单独一种规则产生更丰富的压力。一个幽灵的行动可能迫使玩家转弯，而转弯后的道路又被另一个幽灵接近。玩家体验到的是相互作用的局面，不必在脑中计算全部内部参数。这种设计显示，敌人数量有限时，差异化的规则仍能产生有层次的协同威胁。

行为需要为玩家留下喘息。持续、毫无间隙的围堵会让局面既难理解又缺乏节奏；攻击波次与速度安排使紧张有所起伏。敌人的目标不是在每一瞬间以最高效率消灭玩家，而是维持一场值得继续投入的追逐。人工智能的效果因此应按体验与可读性评估，不能只按胜率排列。

# 力量逆转与身体反馈

吃到能量豆以后，幽灵的颜色和行为改变，玩家能够立刻看见规则已经切换。先前需要避开的对象变成值得追赶的目标，同一迷宫也短暂显得宽敞起来。变化不只是增加分数奖励，它重写了玩家对距离、风险与时间的判断。

这种力量并不永久存在。玩家需要估计剩余窗口，决定追多远、何时重新准备逃跑。此前追得越积极，逆转结束时越可能处于危险位置。能量豆因此制造了带后果的诱惑：它让玩家暂时强大，又要求玩家及时承认这种强大正在消退。

被吃掉的幽灵以眼睛形态返回中央，再恢复原来的追逐身份。这个过程让失败的敌人仍保留可见连续性，并以漫画式表现缓和暴力。作品没有依赖逼真的伤害细节，却能清楚传达谁现在占优势、角色处于什么状态。视觉简化与规则表达在这里相互支持。

豆点、幽灵、能量豆和主角共同形成一套紧凑的动作语汇。玩家的输入很少，反馈却有明确差异：食物消失、身体改变方向、敌人改变颜色或形态。学习不必首先经过长篇解释，而可以通过连续的感知与试验发生。这种易进入的表面，也容纳了需要长时间练习的路线技巧。

# 声音、短动画与可记忆形象

Pac-Man的角色是一个具有嘴部动作的圆形轮廓。它既能作为地图中的小像素被识别，也能脱离画面成为印刷品上的标识。角色造型与主要动作保持一致，使跨媒介辨认不完全依赖标题文字。这一形象为后来的传播与多种商品合作提供了辨识基础。

幽灵的圆滑外形、鲜明颜色与双眼方向，让它们同时具有威胁和滑稽感。岩谷复盘中提到公司内部曾有人建议统一改成红色，而团队最终保留了差异。不同颜色不仅增加装饰，也帮助人们在快速运动中区分敌人，把观察结果积累到特定角色身上。[3]

关间短动画让追逐关系进入一个暂时不受玩家控制的表演。角色可以在普通规则之外出现夸张笑料，玩家获得短暂休息，也进一步认识这组形象。岩谷把这部分动画列为开发中遇到的技术问题之一。它的作用并非补足宏大剧情，而是给高度重复的行动增加情绪和性格。[3]

声音同样承担状态与节奏提示。短促的进食声把连续移动切成可感知的动作，音乐和效果音又区分开局、危险和结束。玩家不只看着一颗图标移动，而是通过反复的视觉、听觉反馈体验一个有身体节奏的角色。分析它的审美，需要把声画的时序放在静态截图之外考虑。

# 固定难度与未实现的自适应构想

岩谷在2005年复盘中提出过一项没有完成的设想：依据玩家犯错所需的时间判断其水平，再即时调整人工智能难度。制作周期内没有足够时间实现它。这个说明非常重要，因为作品已实现的分阶段难度变化，与开发者想加入的实时适应系统，是不同层次的事实。[3]

固定规则给予玩家反复学习的机会，也让熟练者能够发展路线和时机知识。自适应设计则可能让同一操作在不同玩家或不同时间面对不同压力。两者各有目标，不能简单把没有自适应看作人工智能失败。Pac-Man的经典张力，很大程度上来自玩家与相对稳定系统之间可以逐渐深化的关系。

这种稳定也带来争论：若高手掌握了可重复模式，游戏是否仍然有变化？问题不能只用是否包含随机数回答。操作精度、实时判断和多个移动对象的相遇，仍会要求人实际执行知识；知道一条路线和在压力中准确完成它，并非同一能力。可学习性既可能减少惊喜，也能够支持精熟的满足。

街机环境还使难度涉及商业安排。一次投入之后能够游玩多久、失败是否愿意再来，都关系到运营者与玩家的目标。原始经营和维修手册所记录的机台设置，提醒人们游戏不是脱离场所的抽象规则。不同版本与设置形成了各自的难度条件。

# 性别目标、普及与版本边界

扩大女性受众的目标，促成了对暴力题材、控制复杂度和游戏厅氛围的反思；但把“女性喜欢吃东西”当成普遍结论，仍会重现设计年代的性别定型。更有解释力的读法，是考察团队怎样把一个受众假设转成可供更多人实际尝试的形式，再承认参与者能够超出设计者预设。

作品中的可爱也没有取消竞争。高速移动、追逐和清场仍要求持续集中注意，失误会终止一条生命。它把强度与亲近感放在一起，说明友善的形象不必对应松散的挑战。受众扩大可以通过规则表达与情绪风格发生，而不只是降低难度或减少可精熟的空间。

Pac-Man的后续移植、改作和衍生作品应当逐一识别。家用机版本会受到分辨率、颜色、声音和控制设备限制，迷宫及敌人表现也可能改变；Ms. Pac-Man与后来的重制作品更具有自己的开发史。1980年原作的作者与机制，不能自动覆盖所有带着黄色角色名字的游戏。

同样，官方历史网站的当代截图是对原作的展示材料，它可以说明迷宫和角色，但不是游戏创作当天留下的摄影证据。区分作品年代、所示版本和图像制作时间，才能避免把传播史压成一个时间点。保存原机资料与开发者回忆，也能解释为什么同样叫“吃豆人”的体验会存在差异。

# 路线为什么需要不断重估

清场接近结束时，地图上剩余的豆点通常更加分散。玩家不能只追求眼前最安全的连续区域，而需要把远处残留的目标重新纳入路线。已经走过的地面虽然不再提供同样的进度，却仍然可能是回避敌人或接近能量豆的必经之路。任务完成程度因此改变了空间的实际价值，同一条通道在开局与末段承担不同作用。

观察敌人也不是离开行动之后才做的推理。玩家在转弯、追赶和撤退中持续更新判断，必须把片刻前看见的位置与现在可能到达的地方联系起来。画面公开了许多信息，却没有替人安排下一步。它把可见性转化为需要及时使用的知识，解释了为何规则能够很快说明，熟练操作却仍需漫长积累。

分数目标又能改变同一局面的选择。单纯清理豆点与尽可能利用力量窗口，可能要求不同的移动路线。安全完成和冒险争取额外收益并存，使玩家能够在明确的基本目标内选择自己的风险程度。这种选择无需额外模式菜单，已经藏在追逐关系与地图资源之中。

迷宫的稳定还使观看别人游玩具有实际学习价值。旁观者能够认出同样的岔路和能量豆位置，把别人的逃脱与失败联系到自己的经历。技巧可以通过观察传递，但仍需亲自把方向和时机配合起来。作品因此能够围绕一套清楚可见的空间形成共同话题，个人操作与现场观看相互加强。

这样的可共享性与角色形象共同作用。人们既可以谈论哪只幽灵令人头疼，也可以指着某条通道解释刚才的错误。算法结果被压缩成大家都能辨认的场景，使复杂判断具有可以讲述的形式。这是一种与长篇情节不同的传播能力，却同样参与作品如何被记住。

# 在游戏人工智能史中的位置

Pac-Man展示了一种通过可读差异塑造角色的路线。四只幽灵不需要复杂背景故事，就能凭重复可察觉的行为让玩家产生期待；玩家又通过自己的选择把这些期待变成逃脱或包围的具体场面。叙事性在这里存在于追逐、逆转与再度受威胁的节奏之中，而不主要依靠文字情节。

它对设计的启示也相当具体：给相似敌人安排不同倾向，用清楚反馈公开状态变化，让有限控制支持多层判断，再通过波次和空间制造压力起伏。这些原则可以被其他游戏借鉴，但具体借鉴关系需要开发者说明才能确认。形式相似只能支持比较，不能凭相似就编造直接影响链。

把作品放回原始街机条件，还能看见人工智能与视觉设计共同工作的方式。算法决定敌人怎样移动，颜色和轮廓帮助玩家读出差异，地图把差异转为可操作的风险。它们合在一起形成了一场清楚又难以穷尽的游戏；单独抽出一个最聪明的敌人算法，反而不足以解释整部作品的魅力。
