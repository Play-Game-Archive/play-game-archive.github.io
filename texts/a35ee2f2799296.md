# 简介

Voyager通过自动课程提出探索目标，把成功运行的程序存入技能库，再用环境反馈、执行错误和任务验证改进后续程序。作者在Minecraft中考察这些环节如何帮助智能体积累、组合和迁移行动技能。

<!-- pair:en:VOY00008:chapter -->
Abstract

<!-- translation -->
摘要

<!-- endpair -->

<!-- pair:en:VOY00009:paragraph -->
We introduce Voyager, the first LLM-powered embodied lifelong learning agent in Minecraft that continuously explores the world, acquires diverse skills, and makes novel discoveries without human intervention. Voyager consists of three key components: 1) an automatic curriculum that maximizes exploration, 2) an ever-growing skill library of executable code for storing and retrieving complex behaviors, and 3) a new iterative prompting mechanism that incorporates environment feedback, execution errors, and self-verification for program improvement. Voyager interacts with GPT-4 via blackbox queries, which bypasses the need for model parameter fine-tuning. The skills developed by Voyager are temporally extended, interpretable, and compositional, which compounds the agent’s abilities rapidly and alleviates catastrophic forgetting. Empirically, Voyager shows strong in-context lifelong learning capability and exhibits exceptional proficiency in playing Minecraft. It obtains 3.3× more unique items, travels 2.3× longer distances, and unlocks key tech tree milestones up to 15.3× faster than prior SOTA. Voyager is able to utilize the learned skill library in a new Minecraft world to solve novel tasks from scratch, while other techniques struggle to generalize.

<!-- translation -->
我们提出 Voyager，这是《我的世界》中首个由大语言模型驱动的具身终身学习智能体，能够在无需人工干预的情况下持续探索世界、获得多样技能并不断作出新发现。Voyager 包含三个关键组成部分：1）使探索最大化的自动课程；2）不断扩充的可执行代码技能库，用于存储和检索复杂行为；3）新的迭代提示机制，将环境反馈、执行错误和自我验证结合起来，以改进程序。Voyager 通过黑箱查询与 GPT-4 交互，无需微调模型参数。Voyager 学得的技能具有时间延展性、可解释性和可组合性，使智能体的能力迅速累积增强，并缓解灾难性遗忘。实验表明，Voyager 具有很强的上下文内终身学习能力，在《我的世界》中表现出出色的游戏能力。与此前最先进的方法相比，它获得的不同物品数量达到其 3.3 倍，行进距离达到其 2.3 倍，解锁关键科技树里程碑的速度最高达到其 15.3 倍。Voyager 能够在新的《我的世界》世界中利用学得的技能库，从零开始解决新任务，而其他方法难以泛化。

<!-- pair:en:VOY00044:chapter -->
1 Introduction

<!-- translation -->
1 引言

<!-- endpair -->

<!-- pair:en:VOY00045:paragraph -->
Building generally capable embodied agents that continuously explore, plan, and develop new skills in open-ended worlds is a grand challenge for the AI community (Kolve et al., 2017; Savva et al., 2019; Zhu et al., 2020; Xia et al., 2019; Shen et al., 2020). Classical approaches employ reinforcement learning (RL) (Kober et al., 2013; Arulkumaran et al., 2017) and imitation learning (Baker et al., 2022; Team et al., 2021; Vinyals et al., 2019) that operate on primitive actions, which could be challenging for systematic exploration (Ecoffet et al., 2019; Huizinga & Clune, 2022; Wang et al., 2020; Kanitscheider et al., 2021; Dennis et al., 2020), interpretability (Liang et al., 2022; Sun et al., 2020; Zhao et al., 2021), and generalization (Jiang et al., 2022; Shridhar et al., 2021; Fan et al., 2021). Recent advances in large language model (LLM) based agents harness the world knowledge encapsulated in pre-trained LLMs to generate consistent action plans or executable policies (Liang et al., 2022; Singh et al., 2022; Jiang et al., 2022). They are applied to embodied tasks like games and robotics (Fan et al., 2022; Zeng et al., 2022; Ahn et al., 2022; Huang et al., 2022b;a), as well as NLP tasks without embodiment (Richards, 2023; Yao et al., 2022; Shinn et al., 2023). However, these agents are not lifelong learners that can progressively acquire, update, accumulate, and transfer knowledge over extended time spans (Parisi et al., 2019; Wang et al., 2023a).

<!-- translation -->
构建能够持续探索、规划并在开放式世界中发展新技能的通用具身智能体，是人工智能社区面临的一项重大挑战（Kolve 等，2017；Savva 等，2019；Zhu 等，2020；Xia 等，2019；Shen 等，2020）。经典方法采用基于原始动作的强化学习（RL）（Kober 等，2013；Arulkumaran 等，2017）和模仿学习（Baker 等，2022；Team 等，2021；Vinyals 等，2019），这在系统性探索（Ecoffet 等，2019；Huizinga & Clune，2022；Wang 等，2020；Kanitscheider 等，2021；Dennis 等，2020）、可解释性（Liang 等，2022；Sun 等，2020；Zhao 等，2021）和泛化能力（Jiang 等，2022；Shridhar 等，2021；Fan 等，2021）方面可能面临挑战。基于大语言模型（LLM）的智能体的最新进展利用了预训练 LLM 中封装的世界知识来生成一致的动作计划或可执行策略（Liang 等，2022；Singh 等，2022；Jiang 等，2022）。它们被应用于具身任务（如游戏和机器人）（Fan 等，2022；Zeng 等，2022；Ahn 等，2022；Huang 等，2022b;a），以及无需具身的自然语言处理任务（Richards，2023；Yao 等，2022；Shinn 等，2023）。然而，这些智能体并非终身学习者，无法在长时间跨度内逐步获取、更新、积累和转移知识（Parisi 等，2019；Wang 等，2023a）。

<!-- endpair -->

<!-- pair:en:VOY00046:paragraph -->
Let us consider Minecraft as an example. Unlike most other games studied in AI (Mnih et al., 2013; OpenAI et al., 2019; Vinyals et al., 2019), Minecraft does not impose a predefined end goal or a fixed storyline but rather provides a unique playground with endless possibilities (Fan et al., 2022). Minecraft requires players to explore vast, procedurally generated 3D terrains and unlock a tech tree using gathered resources. Human players typically start by learning the basics, such as mining wood and cooking food, before advancing to more complex tasks like combating monsters and crafting diamond tools. We argue that an effective lifelong learning agent should have similar capabilities as human players: (1) propose suitable tasks based on its current skill level and world state, e.g., learn to harvest sand and cactus before iron if it finds itself in a desert rather than a forest; (2) refine skills based on environmental feedback and commit mastered skills to memory for future reuse in similar situations (e.g. fighting zombies is similar to fighting spiders); (3) continually explore the world and seek out new tasks in a self-driven manner.

<!-- translation -->
让我们以《我的世界》（Minecraft）为例。与人工智能研究中大多数其他游戏不同（Mnih 等，2013；OpenAI 等，2019；Vinyals 等，2019），《我的世界》并未设定预先设定的终极目标或固定的剧情，而是提供了一个拥有无限可能性的独特游乐场（Fan 等，2022）。在该游戏中，玩家需要探索广阔且程序化生成的 3D 地形，并利用收集到的资源解锁科技树。人类玩家通常从学习基础技能开始，例如采伐木材和烹饪食物，然后再进阶到更复杂的任务，如对抗怪物和打造钻石工具。我们认为，一个有效的终身学习智能体应具备与人类玩家相似的能力：(1) 根据其当前技能水平和世界状态提出合适的任务，例如若身处沙漠而非森林，则先学习采集沙子和仙人掌，再学习获取铁；(2) 根据环境反馈细化技能，并将已掌握的技能存入记忆以便在类似情境中复用（例如，对抗僵尸与对抗蜘蛛是相似的）；(3) 以自我驱动的方式持续探索世界并寻求新任务。

<!-- endpair -->

<!-- pair:en:VOY00047:paragraph -->
Towards these goals, we introduce Voyager, the first LLM-powered embodied lifelong learning agent to drive exploration, master a wide range of skills, and make new discoveries continually without human intervention in Minecraft. Voyager is made possible through three key modules (Fig. 2): 1) an automatic curriculum that maximizes exploration; 2) a skill library for storing and retrieving complex behaviors; and 3) a new [turn to page 3] iterative prompting mechanism that generates executable code for embodied control. We opt to use code as the action space instead of low-level motor commands because programs can naturally represent temporally extended and compositional actions (Liang et al., 2022; Singh et al., 2022), which are essential for many long-horizon tasks in Minecraft. Voyager interacts with a blackbox LLM (GPT-4 (OpenAI, 2023)) through prompting and in-context learning (Wei et al., 2022a; Brown et al., 2020; Raffel et al., 2020). Our approach bypasses the need for model parameter access and explicit gradient-based training or finetuning.

<!-- translation -->
为了实现这些目标，我们提出 Voyager。这是首个由大语言模型驱动的具身终身学习智能体，能够在《我的世界》中无需人工干预地推动探索、掌握广泛技能并持续作出新发现。Voyager 由三个关键模块实现（图 2）：1）使探索最大化的自动课程；2）存储和检索复杂行为的技能库；3）一种新的[turn to page 3]迭代提示机制，生成用于具身控制的可执行代码。我们选择代码而不是底层运动指令作为动作空间，因为程序能够自然地表示具有时间延展性和可组合性的动作（Liang 等，2022；Singh 等，2022），这些动作对《我的世界》中的许多长时程任务至关重要。Voyager 通过提示和上下文内学习（Wei 等，2022a；Brown 等，2020；Raffel 等，2020）与黑箱大语言模型 GPT-4（OpenAI，2023）交互。我们的方法无需访问模型参数，也无需显式进行基于梯度的训练或微调。

<!-- endpair -->

<!-- pair:en:VOY00048:paragraph -->
 More specifically, Voyager attempts to solve progressively harder tasks proposed by the automatic curriculum, which takes into account the exploration progress and the agent’s state. The curriculum is generated by GPT-4 based on the overarching goal of “discovering as many diverse things as possible”. This approach can be perceived as an in-context form of novelty search (Eysenbach et al., 2019; Conti et al., 2018). Voyager incrementally builds a skill library by storing the action programs that help solve a task successfully. Each program is indexed by the embedding of its description, which can be retrieved in similar situations in the future. Complex skills can be synthesized by composing simpler programs, which compounds Voyager’s capabilities rapidly over time and alleviates catastrophic forgetting in other continual learning methods (Parisi et al., 2019; Wang et al., 2023a).

<!-- translation -->
 更具体地说，Voyager 尝试解决自动课程提出的难度逐渐提高的任务；该课程考虑了探索进度和智能体状态。GPT-4 根据“发现尽可能多样的事物”这一总体目标生成课程。这种做法可以视为一种上下文内的新颖性搜索（Eysenbach 等，2019；Conti 等，2018）。Voyager 通过存储能够成功解决任务的动作程序，逐步建立技能库。每个程序都以其描述的嵌入向量作为索引，以便日后在相似情境中检索。通过组合较简单的程序，可以合成复杂技能，从而使 Voyager 的能力随时间迅速累积增强，并缓解其他持续学习方法中的灾难性遗忘（Parisi 等，2019；Wang 等，2023a）。

<!-- endpair -->

<!-- pair:en:VOY00049:paragraph -->
However, LLMs struggle to produce the correct action code consistently in one shot (Chen et al., 2021a). To address this challenge, we propose an iterative prompting mechanism that: (1) executes the generated program to obtain observations from the Minecraft simulation (such as inventory listing and nearby creatures) and error trace from the code interpreter (if any); (2) incorporates the feedback into GPT-4’s prompt for another round of code refinement; and (3) repeats the process until a self-verification module confirms the task completion, at which point we commit the program to the skill library (e.g., craftStoneShovel() and combatZombieWithSword()) and query the automatic curriculum for the next milestone (Fig. 2).

<!-- translation -->
然而，大语言模型难以始终在一次生成中给出正确的动作代码（Chen 等，2021a）。为应对这一挑战，我们提出一种迭代提示机制：（1）执行生成的程序，获取《我的世界》模拟环境中的观测信息，例如物品栏清单和附近生物，以及代码解释器产生的错误追踪信息（若有）；（2）将这些反馈纳入 GPT-4 的提示，进行下一轮代码改进；（3）重复上述过程，直到自我验证模块确认任务完成。此时，我们将程序存入技能库，例如 craftStoneShovel() 和 combatZombieWithSword()，再向自动课程查询下一个里程碑（图 2）。

<!-- endpair -->

<!-- pair:en:VOY00050:paragraph -->
Empirically, Voyager demonstrates strong in-context lifelong learning capabilities. It can construct an ever-growing skill library of action programs that are reusable, interpretable, and generalizable to novel tasks. We evaluate Voyager systematically against other LLM-based agent techniques (e.g., ReAct (Yao et al., 2022), Reflexion (Shinn et al., 2023), AutoGPT (Richards, 2023)) in MineDojo (Fan et al., 2022), an open-source Minecraft AI framework. Voyager outperforms prior SOTA by obtaining 3.3× more unique items, unlocking key tech tree milestones up to 15.3× faster, and traversing 2.3× longer distances. We further demonstrate that Voyager is able to utilize the learned skill library in a new Minecraft world to solve novel tasks from scratch, while other methods struggle to generalize.

In addition, if the task fails, it provides a critique by suggesting how to complete the task (Fig. 6). Hence, our self-verification is more comprehensive than self-reflection (Shinn et al., 2023) by both checking success and reflecting on mistakes.

     environment , # environment that uses code as action space
     curriculum_agent , # curriculum agent for proposing the next task
     action_agent , # action agent for code generation
     critic_agent , # critic agent for self - verification
     skill_manager , # skill manager for adding new skills and skill retrieval
):
     agent_state = environment . reset ()
     while True :
          exploration_progress = (
               curriculum_agent . get_exploration_progress (
                    curriculum_agent . get_completed_tasks () ,
                    curriculum_agent . get_failed_tasks () ,
               )
          )
          task = curriculum_agent . propose_next_task (
               agent_state , exploration_progress
          )
          code = None
          environment_feedback = None
          execution_errors = None
          critique = None
          success = False
          # try at most 4 rounds before moving on to the next task
          for i in range (4) :
               skills = skill_manager . retrieve_skills (
                    task , environment_feedback
               )
               code = action_agent . generate_code (
                    task ,
                    code ,
                    environment_feedback ,
                    execution_errors ,
                    critique ,
                    skills ,
               )

                    agent_state ,

<!-- pair:en:VOY00226:heading -->
3.4 Ablation Studies

<!-- translation -->
3.4 消融研究

<!-- endpair -->

<!-- pair:en:VOY00227:paragraph -->
We ablate 6 design choices (automatic curriculum, skill library, environment feedback, execution errors, self-verification, and GPT-4 for code generation) in Voyager and study their impact on exploration performance (see Appendix, Sec. B.3 for details of each ablated variant). Results are shown in Fig. 9. We highlight the key findings below:

<!-- translation -->
我们在 Voyager 中消融了 6 设计选择（自动课程、技能库、环境反馈、执行错误、自我验证以及用于代码生成的 GPT-4），并研究它们对探索性能的影响（详见附录 B.3，其中列出了每种消融变体的详细信息）。结果如图 9 所示。我们在此突出以下关键发现：

<!-- endpair -->

<!-- pair:en:VOY00228:paragraph -->
• Automatic curriculum is crucial for the agent’s consistent progress. The discovered item count drops by 93% if the curriculum is replaced with a random one, because certain tasks may be too challenging if attempted out of order. On the other hand, a manually designed curriculum requires significant Minecraft-specific expertise, and does not take into account the agent’s live situation. It falls short in the experimental results compared to our automatic curriculum.

<!-- translation -->
• 自动课程对智能体持续进步至关重要。如果将其替换为随机课程，发现的物品数量会下降 93%，因为某些任务若不按适当顺序尝试，可能过于困难。另一方面，手动设计课程需要大量《我的世界》专门知识，也没有考虑智能体的实时处境。实验中，它的表现不及我们的自动课程。

<!-- endpair -->

<!-- pair:en:VOY00229:paragraph -->
• Voyager w/o skill library exhibits a tendency to plateau in the later stages. This underscores the pivotal role that the skill library plays in Voyager. It helps create more complex actions and steadily pushes the agent’s boundaries by encouraging new skills to be built upon older ones.

<!-- translation -->
• 缺少技能库的 Voyager 在后期表现出趋于停滞的倾向。这凸显了技能库在 Voyager 中的关键作用。它有助于构建更复杂的动作，并通过鼓励新技能建立在旧技能之上，稳步拓展智能体的能力边界。

<!-- endpair -->

<!-- pair:en:VOY00230:paragraph -->
• Self-verification is the most important among all the feedback types. Removing the module leads to a significant drop (−73%) in the discovered item count. Self-verification serves as a critical mechanism to decide when to move on to a new task or reattempt a previously unsuccessful task.

<!-- translation -->
• 自我验证是所有反馈类型中最重要的。移除该模块会导致发现物品数量显著下降（−73%）。自我验证作为一种关键机制，用于决定何时转向新任务或重新尝试先前未成功的任务。

<!-- endpair -->

<!-- pair:en:VOY00231:paragraph -->
• GPT-4 significantly outperforms GPT-3.5 in code generation and obtains 5.7× more unique items, as GPT-4 exhibits a quantum leap in coding abilities. This finding corroborates recent studies in the literature (Bubeck et al., 2023; Liu et al., 2023b).

<!-- translation -->
• GPT-4 在代码生成方面显著优于 GPT-3.5，获得的不同物品数量达到其 5.7 倍，因为 GPT-4 的编程能力出现了质的飞跃。这一发现印证了近期文献中的研究（Bubeck 等，2023；Liu 等，2023b）。

Cost. The GPT-4 API incurs significant costs. It is 15× more expensive than GPT-3.5. Nevertheless, Voyager requires the quantum leap in code generation quality from GPT-4 (Fig. 9), which GPT-3.5 and open-source LLMs cannot provide (Touvron et al., 2023).

Occasionally, self-verification module may also fail, such as not recognizing spider string as a success signal of beating a spider.

<!-- translation -->
不准确之处。尽管采用了迭代提示机制，仍然存在智能体陷入困境、无法生成正确技能的情况。自动课程具备灵活性，可在稍后时间重新尝试该任务。偶尔，自我验证模块也可能失效，例如未能将蛛丝识别为击败蜘蛛的成功信号。

<!-- pair:en:VOY00244:chapter -->
5 Related work

<!-- translation -->
5 相关工作

<!-- endpair -->

<!-- pair:en:VOY00245:paragraph -->
Decision-making Agents in Minecraft. Minecraft is an open-ended 3D world with incredibly flexible game mechanics supporting a broad spectrum of activities. Built upon notable Minecraft benchmarks (Fan et al., 2022; Guss et al., 2019b;a; 2021; Kanervisto et al., 2022; Johnson et al., 2016), Minecraft learning algorithms can be divided into two categories: 1) Low-level controller: Many prior efforts leverage hierarchical reinforcement learning to learn from human demonstrations (Lin et al., 2021; Mao et al., 2021; Skrynnik et al., 2021). Kanitscheider et al. (2021) design a curriculum based on success rates, but its objectives are limited to curated items. MineDojo (Fan et al., 2022) and VPT (Baker et al., 2022) utilize YouTube videos for large-scale pre-training. DreamerV3 (Hafner et al., 2023), on the other hand, learns a world model to explore the environment and collect diamonds. 2) High-level planner: Volum et al. (2022) leverage few-shot prompting with Codex (Chen et al., 2021a) to generate executable policies, but they require additional human interaction. Recent works leverage LLMs as a high-level planner in Minecraft by decomposing a high-level task into several subgoals following Minecraft recipes (Wang et al., 2023b; Nottingham et al., 2023; Yuan et al., 2023), thus lacking full exploration flexibility. Like these latter works, Voyager also uses LLMs as a high-level planner by prompting GPT-4 and utilizes Mineflayer (PrismarineJS, 2013) as a low-level controller following Volum et al. (2022). Unlike prior works, Voyager employs an automatic curriculum that unfolds in a bottom-up manner, driven by curiosity, and therefore enables open-ended exploration.

<!-- translation -->
《我的世界》中的决策智能体。《我的世界》是一个开放式三维世界，游戏机制极其灵活，支持广泛的活动。在已有的重要《我的世界》基准之上（Fan 等，2022；Guss 等，2019b；a；2021；Kanervisto 等，2022；Johnson 等，2016），相关学习算法可以分为两类：1）底层控制器：许多既有工作使用分层强化学习，从人类示范中学习（Lin 等，2021；Mao 等，2021；Skrynnik 等，2021）。Kanitscheider 等（2021）根据成功率设计课程，但其目标局限于预先筛选的物品。MineDojo（Fan 等，2022）和 VPT（Baker 等，2022）利用 YouTube 视频进行大规模预训练。DreamerV3（Hafner 等，2023）则学习世界模型，以探索环境并收集钻石。2）高层规划器：Volum 等（2022）使用 Codex（Chen 等，2021a）的少样本提示来生成可执行策略，但需要额外的人类交互。近期工作将大语言模型用作《我的世界》的高层规划器，按照游戏中的合成配方，把高层任务分解成若干子目标（Wang 等，2023b；Nottingham 等，2023；Yuan 等，2023），因此缺乏充分的探索灵活性。与后一类工作相似，Voyager 也通过提示 GPT-4 将大语言模型用作高层规划器，并沿用 Volum 等（2022）的做法，将 Mineflayer（PrismarineJS，2013）用作底层控制器。与既有工作不同，Voyager 使用由好奇心驱动、自下而上展开的自动课程，从而实现开放式探索。

<!-- endpair -->

<!-- pair:en:VOY00246:paragraph -->
Large Language Models for Agent Planning. Inspired by the strong emergent capabilities of LLMs, such as zero-shot prompting and complex reasoning (Bommasani et al., 2021; Brown et al., 2020; Raffel et al., 2020; Wei et al., 2022a; Chowdhery et al., 2022; Chung et al., 2022), embodied agent research (Duan et al., 2022; Batra et al., 2020; Ravichandar et al., 2020; Collins et al., 2021) has witnessed a significant increase in the utilization of LLMs for planning purposes. Recent efforts can be roughly classified into two groups. 1) Large language models for robot learning: Many prior works apply LLMs to generate subgoals for robot planning (Huang et al., 2022a;a; Ahn et al., 2022; Min et al., 2021; Blukis et al., 2021). Inner Monologue (Huang et al., 2022b) incorporates environment feedback for robot planning with LLMs. Code as Policies (Liang et al., 2022) and ProgPrompt (Singh et al., 2022) directly leverage LLMs to generate executable robot policies. VIMA (Jiang et al., 2022) and PaLM-E (Driess et al., 2023) fine-tune pre-trained LLMs to support multimodal prompts. 2) Large language models for text agents: ReAct (Yao et al., 2022) leverages chain-of-thought prompting (Wei et al., 2022b) and generates both reasoning traces and task-specific actions with LLMs. Reflexion (Shinn et al., 2023) is built upon ReAct (Yao et al., 2022) with self-reflection to enhance reasoning. AutoGPT (Richards, 2023) is a popular tool that automates NLP tasks by crafting a curriculum of multiple subgoals for completing a high-level goal while incorporating ReAct (Yao et al., 2022)’s reasoning and acting loops. DERA (Nair et al., 2023) frames a task as a dialogue between two GPT-4 (OpenAI, 2023) agents. Generative Agents (Park et al., 2023) leverages ChatGPT (chatgpt) to simulate human behaviors by storing agents’ experiences as memories and retrieving those for planning, but its agent actions are not executable. SPRING (Wu et al., 2023) is a concurrent work that uses GPT-4 to extract game mechanics from game manuals, based on which it answers questions arranged in a directed acyclic graph and predicts the next action. All these works lack a skill library for developing more complex behaviors, which are crucial components for the success of Voyager in lifelong learning.

<!-- translation -->
面向智能体规划的大语言模型。受大语言模型（LLMs）强大的涌现能力启发，例如零样本提示和复杂推理（Bommasani 等，2021；Brown 等，2020；Raffel 等，2020；Wei 等，2022a；Chowdhery 等，2022；Chung 等，2022），具身智能体研究（Duan 等，2022；Batra 等，2020；Ravichandar 等，2020；Collins 等，2021）见证了利用大语言模型进行规划用途的显著增加。近期的努力大致可分为两类。1) 面向机器人学习的大语言模型：许多先前的工作应用大语言模型为机器人规划生成子目标（Huang 等，2022a;a；Ahn 等，2022；Min 等，2021；Blukis 等，2021）。Inner Monologue（Huang 等，2022b）结合环境反馈利用大语言模型进行机器人规划。Code as Policies（Liang 等，2022）和 ProgPrompt（Singh 等，2022）直接利用大语言模型生成可执行的机器人策略。VIMA（Jiang 等，2022）和 PaLM-E（Driess 等，2023）微调预训练的大语言模型以支持多模态提示。2) 面向文本智能体的大语言模型：ReAct（Yao 等，2022）利用思维链提示（Wei 等，2022b），并利用大语言模型生成推理轨迹和特定任务的动作。Reflexion（Shinn 等，2023）基于 ReAct（Yao 等，2022）构建，通过自我反思增强推理能力。AutoGPT（Richards，2023）是一种流行的工具，它通过为完成高级目标而制定多个子目标的课程来自动化 NLP 任务，同时结合了 ReAct（Yao 等，2022）的推理与行动循环。DERA（Nair 等，2023）将任务框定为两个 GPT-4（OpenAI，2023）智能体之间的对话。Generative Agents（Park 等，2023）利用 ChatGPT（chatgpt）通过存储智能体的体验作为记忆并检索这些记忆来进行规划来模拟人类行为，但其智能体动作不可执行。SPRING（Wu 等，2023）是一项同期研究，它使用 GPT-4 从游戏手册中提取游戏机制，在此基础上回答按有向无环图排列的问题并预测下一个动作。所有这些工作都缺乏用于开发更复杂行为的技能库，而技能库是 Voyager 在终身学习中取得成功的关键组成部分。

<!-- endpair -->

<!-- pair:en:VOY00247:paragraph -->
Code Generation with Execution. Code generation has been a longstanding challenge in NLP (Chen et al., 2021a; Nijkamp et al., 2022; Le et al., 2022; Chowdhery et al., 2022; Brown et al., 2020), with various works leveraging execution results to improve program synthesis. Execution-guided approaches leverage intermediate execution outcomes to guide program search (Chen et al., 2019; 2021b; Ellis et al., 2019). Another line of research utilizes majority voting to choose candidates based on their execution performance (Li et al., 2022; Cobbe et al., 2021). Additionally, LEVER (Ni et al., 2023) trains a verifier to distinguish and reject incorrect programs based on execution results. CLAIRIFY (Skreta et al., 2023), on the other hand, generates code for [turn to page 13] planning chemistry experiments and makes use of a rule-based verifier to iteratively provide error feedback to LLMs. Voyager distinguishes itself from these works by integrating environment feedback, execution errors, and self-verification (to assess task success) into an iterative prompting mechanism for embodied control.

<!-- translation -->
基于执行的代码生成。代码生成一直是自然语言处理领域长期面临的挑战（Chen 等，2021a；Nijkamp 等，2022；Le 等，2022；Chowdhery 等，2022；Brown 等，2020），诸多工作利用执行结果来改进程序合成。由执行引导的方法利用中间执行结果来指导程序搜索（Chen 等，2019；2021b；Ellis 等，2019）。另一类研究利用多数投票法，根据其执行表现来选择候选者（Li 等，2022；Cobbe 等，2021）。此外，LEVER（Ni 等，2023）训练了一个验证器，以根据执行结果区分并拒绝不正确的程序。相比之下，CLAIRIFY（Skreta 等，2023）为 [turn to page 13] 化学实验规划生成代码，并利用基于规则的验证器迭代地向大语言模型提供错误反馈。Voyager 通过将环境反馈、执行错误和自我验证（用于评估任务成功）整合进具身控制的迭代提示机制中，从而与这些工作区分开来。

<!-- pair:en:VOY00248:chapter -->
 6 Conclusion

<!-- translation -->
 6 结论

<!-- endpair -->

<!-- pair:en:VOY00249:paragraph -->
In this work, we introduce Voyager, the first LLM-powered embodied lifelong learning agent, which leverages GPT-4 to explore the world continuously, develop increasingly sophisticated skills, and make new discoveries consistently without human intervention. Voyager exhibits superior performance in discovering novel items, unlocking the Minecraft tech tree, traversing diverse terrains, and applying its learned skill library to unseen tasks in a newly instantiated world. Voyager serves as a starting point to develop powerful generalist agents without tuning the model parameters.

<!-- translation -->
在本研究中，我们介绍了 Voyager，这是首个由大语言模型驱动的具身终身学习智能体。它利用 GPT-4 持续探索世界、发展日益复杂的技能，并在无需人工干预的情况下不断做出新发现。Voyager 在发现新颖物品、解锁《我的世界》科技树、穿越多样地形以及将其习得的技能库应用于全新实例化世界中的未见任务方面表现出卓越性能。Voyager 为开发无需调整模型参数的强大通用智能体提供了一个起点。

7 Broader Impacts

7 更广泛的影响

Our research is conducted within Minecraft, a safe and harmless 3D video game environment. While Voyager is designed to be generally applicable to other domains, such as robotics, its application to physical robots would require additional attention and the implementation of safety constraints by humans to ensure responsible and secure deployment.

我们的研究在Minecraft这一安全、无害的3D电子游戏环境中进行。尽管Voyager被设计为可普遍适用于机器人等其他领域，将其用于实体机器人仍需要人类给予额外关注并施加安全约束，以确保负责任、安全地部署。

<!-- pair:en:VOY00553:heading -->
B.2 Baselines

<!-- translation -->
B.2 基线方法

<!-- endpair -->

<!-- pair:en:VOY00554:paragraph -->
ReAct (Yao et al., 2022) uses chain-of-thought prompting (Wei et al., 2022b) by generating both reasoning traces and action plans with LLMs. We provide it with our environment feedback and the agent states as observations. ReAct undergoes one round of code generation from scratch, followed by three rounds of code refinement. This process is then repeated until the maximum prompting iteration is reached.

<!-- translation -->
ReAct（Yao等，2022）使用思维链提示（Wei等，2022b），通过大语言模型同时生成推理轨迹和行动计划。我们向它提供环境反馈和智能体状态作为观测。ReAct先从零开始生成一轮代码，再进行三轮代码改进。重复这一过程，直到达到提示迭代次数上限。

<!-- endpair -->

<!-- pair:en:VOY00555:paragraph -->
Reflexion (Shinn et al., 2023) is built on top of ReAct (Yao et al., 2022) with self-reflection to infer more intuitive future actions. We provide it with environment feedback, the agent states, execution errors, and our self-verification module. Similar to ReAct, Reflexion undergoes one round of code generation from scratch, followed by three rounds of code refinement. This process is then repeated until the maximum prompting iteration is reached.

<!-- translation -->
Reflexion（Shinn等，2023）在ReAct（Yao等，2022）的基础上增加自我反思，以推断更直观的后续行动。我们向它提供环境反馈、智能体状态、执行错误以及我们的自我验证模块。与ReAct相似，Reflexion先从零开始生成一轮代码，再进行三轮代码改进。重复这一过程，直到达到提示迭代次数上限。

<!-- endpair -->

<!-- pair:en:VOY00556:paragraph -->
AutoGPT (Richards, 2023) is a popular software tool that automates NLP tasks by decomposing a high-level goal into multiple subgoals and executing them in a ReAct-style loop. We re-implement AutoGPT by using GPT-4 to do task decomposition and provide it with the agent states, environment feedback, and execution errors as observations for subgoal execution. Compared with Voyager, AutoGPT lacks the skill library for accumulating knowledge, self-verification for assessing task success, and automatic curriculum for open-ended exploration. During each subgoal execution, if no execution error occurs, we consider the subgoal completed and proceed to the next one. Otherwise, we refine the program until three rounds of code refinement (equivalent to four rounds of code generation) are completed, and then move on to the next subgoal. If three consecutive subgoals do not result in acquiring a new item, we replan by rerunning the task decomposition.

<!-- translation -->
AutoGPT（Richards，2023）是一款流行的软件工具，把高层目标分解为多个子目标，再在ReAct式循环中执行，从而自动完成自然语言处理任务。我们重新实现了AutoGPT，使用GPT-4分解任务，并提供智能体状态、环境反馈和执行错误，作为执行子目标时的观测。与Voyager相比，AutoGPT缺少用于积累知识的技能库、用于评估任务成功与否的自我验证，以及用于开放式探索的自动课程。执行每个子目标时，如果没有执行错误，我们就认为子目标已完成，并继续下一个。否则，我们会改进程序，直到完成三轮代码改进（等同于四轮代码生成），再继续下一个子目标。如果连续三个子目标都没有带来新物品，我们便重新运行任务分解，进行重新规划。
