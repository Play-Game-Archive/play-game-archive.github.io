# 简介

M.U.L.E.是Ozark Softscape制作、Electronic Arts于1983年发行的多人经济策略游戏。四位殖民者在外星球上选择土地，利用可以改装的机械骡生产食物、能源和矿物，再通过拍卖交换余缺。每个人都争取比别人富有，殖民地却需要足够的基础物资才能共同存续。私人收益与共同依赖之间的张力，构成作品最鲜明的特色。

核心团队由Dani Bunten Berry、Bill Bunten、Jim Rushing与Alan Watson组成；1983年署名与1984年开发文章使用Dan Bunten这一姓名。Joe Ybarra担任EA制作人。作品首先面向Atari八位电脑环境，这里以原版设计和手册为主要对象，另行看待Commodore 64移植及后来重制。[1][2]

# 以多人交往组织经济

Bunten在开发手记中把这部作品的来源追溯到自己早先的商业模拟与实时拍卖设计。团队希望保留经济决策的深度，同时增加图像和易玩性。他们还讨论了Monopoly为何适合家庭共同游玩，结论之一是规则为讨价还价、特殊交易和不同待人风格提供了框架。[1]

因此，M.U.L.E.的目标不只是让计算机正确结算经济账目。它要为几个人创造能够合作、勒索、救济或结盟的局面。一个缺粮者愿意付多少钱，既受系统数值影响，也受其他人在场时的态度影响。程序提供相同资源约束，社交关系则改变人们怎样使用它们。

四个席位可以由人和计算机角色共同占据。电脑补位使人手不足时仍能启动完整经济，不过Bunten自己把单人部分视为设计较弱的一环。这个评价指向作品的核心依赖：程序对手能够买卖，却不能完整取代朋友之间的承诺、埋怨和临时默契。它的多人性具有结构意义，并非在单人规则旁边附加一个联机选项。[1]

原版的共同游玩依靠同一场所的输入设备和屏幕。Atari机型是否拥有四个摇杆接口，会影响四位真人同时操作的条件；后来移植也需要重新处理控制问题。“四人游戏”描述了设计席位，不能省略具体硬件就推断任意家用机都能以同样方式提供四人体验。[2]

# 土地和机械骡的行动循环

每轮首先涉及土地取得。玩家观察河谷、平地和山地的位置，选择适合自己计划的地块，再进入个人行动时间。地图没有把全部土地做成同质格子，地形差异会影响产出，因而土地价值取决于生产用途。最便宜或最近的一块，不一定最符合当前需求。[1][3]

机械骡承担了设置生产的接口。玩家进入城镇领取机器，把它带到对应商店进行改装，再领到地块安装。抽象地说，这相当于给某块土地指定生产类型；作品却把操作表现为牵领一个会运动的对象。经济设置变成有路线、时间和动作反馈的小任务，而不只是一张数字表。[1]

有限行动时间使准备工作具有代价。玩家不能无限停留、反复比较所有组合再安全确认；走错路线、改装失误或未及时安装，都可能损失当轮机会。食物短缺又会削减可用行动时间，把上一轮的经济决定落实到下一轮的身体操作。这使稀缺不只表现为资产减少，还表现为能够做多少事。

地图与城镇之间的切换保留了空间连续性。开发者描述，城镇从地图上的一个地块展开为更详细的整屏区域，满足操作分辨率，又让它仍像殖民地的一部分。这种转换让玩家容易理解自己正在同一个世界里改变尺度，避免拍卖、改装和土地看起来像互不相关的菜单。

# 基础商品与锦标赛扩展

食物支撑殖民者活动，能源支持生产，Smithore关系到新机械骡的供应。锦标赛模式进一步加入了Crystite与共谋机制；以下四商品及私下交易的分析以锦标赛模式为范围。Crystite提供收益较高而有风险的外销机会。商品各自承担不同功能，不能简单按当下价格选一个永远最赚钱的产品。若太多人都转向高收益矿物，基础生产就可能断裂。[1][3]

这种依赖使一个人的经营选择改变别人的可能性。能源富余者可以从集体短缺中获利，短期看似最优；但若能源供应不足导致大家产不出矿石，整个后续市场也会受损。收益来自共同经济的循环，同时又诱使个人试图攫取循环中的有利位置。

土地还支持规模效应。相邻地块生产同种商品，以及拥有更多同类生产地块，会带来产量方面的优势。专门化因此有吸引力，却需要通过交换获得其他物资。多样化能减少依赖，专门化能提高某种产出，两种策略之间的取舍构成了经济决策，而不是预先固定的道德答案。[1]

Crystite储量需要勘探，地表不能直接显示全部价值。它的价格波动又使预期收入不完全确定。玩家既判断别人需要什么，也判断自己掌握的信息是否足够可靠。地下资源的信息差与公开拍卖的价格信号叠在一起，使经济世界具有有限却明确的不透明性。

# 拍卖让价格成为一场表演

商品阶段把买者和卖者放在同一屏幕，用角色位置表达报价。人们能够直接看见谁急需商品、谁有余量，以及双方愿意接近到什么价格。价格从账本中的一个结果变成大家同时参与的动作，计算机则负责执行成交和库存变化。[3]

这项界面选择极大降低了表达负担。玩家不需要先学复杂商业指令，只要移动自己的角色，就能在公开空间里改变要价。与此同时，选择何时坚持、何时退让仍然复杂。简单输入承载了对稀缺、竞争和他人意图的判断，易操作与策略深度由此相容。

拍卖的趣味尤其来自等待。买家想压价，卖家希望多赚；其他人的移动可能突然促成成交，也可能使一个人发现自己的条件过高。限时结束让拖延成为有成本的策略。即使人人面对同一组数字，集体行动的顺序仍会造成不同结局。

允许私下协作，则进一步改变公开市场。两位玩家可以试图互相帮助，也可能通过选择性交易针对领先者。Bunten把这种共谋列为最终加入、而且特别满意的机制。它为最初希望得到的社交弹性提供了接口，但也使公平不能只靠规则内部的对称性保证。[1]

# 市场理想怎样被测试修改

开发手记明确提到海因莱因的Time Enough for Love与The Moon Is a Harsh Mistress提供过场景和制度想象。边疆个人、相对简陋工具和自立的殖民地，帮助团队判断哪些规则适合这个世界。这些文学来源经由作者的具体阅读与制作进入作品。[1]

早期方案希望尽量取消外部干预，全部土地也曾通过竞价出售。测试却出现了清楚的优势滚动：有钱者取得更多土地，生产更多，又更容易买下后续土地。领先者的优势因此不断加强，游戏过早失去悬念。开发者最终引入每轮分配土地的机构，改变了最初制度设想。[1]

这个修改很能说明模拟游戏的创作过程。规则可以来自一种经济理想，但实际游玩会暴露它产生的反馈；作者必须决定保留、限制还是修正。最终作品并非关于完全自由市场的一张中立演示图，而是为了维持竞争和共同参与，经过多轮干预后的设计。

随机个人事件也承担平衡作用。开发手记说明领先者不会得到好事件，落后者不会得到坏事件；殖民地整体又可能遭遇地震、海盗或商店火灾等变化。个人运气和共同灾难具有不同对象，不能都笼统说成平均分配的随机性。它们分别调节排名与整体经济的压力。[1]

# 悬念来自怎样呈现计算

电脑能够迅速得出产量，作品却把结果逐步显示在地图上。开发者故意让生产看起来是一个展开的过程，等待中的玩家能够看到自己或别人的地块发生什么。这个安排不增加经济公式的精确度，却增加了结果揭晓的悬念。

库存条也通过消耗、损坏与新增生产的顺序动画解释变化。玩家看到资源为何减少，再看到新产出如何补上，比只收到一个最后数字更容易建立模型。界面因此承担教学工作，把机器已经知道的结果转换成适合人理解的时间过程。[1]

计时音在临近结束时变快，同样把抽象限制变成情绪压力。人会因为还差一次安装或一次成交而着急，旁观者也能理解紧张来自哪里。这种公开可见的时间使轮流操作仍然可以成为共同表演：暂时没有输入权的人，也参与观看和评论。

机械骡摇头的动作、外星种族和Roy Glover创作的主题音乐，又使经济行为具有轻松性格。Bunten曾感叹，玩家特别注意音乐，而不是他投入大量工作的程序；他后来接受了任何让人享受作品的元素都有价值。作品的整体效果因此包含常被技术分析忽略的情绪入口。[1]

# 竞争、合作与设计的取舍

个人财富排名与殖民地整体发展同时存在，使“赢”并不等于单纯毁掉所有对手。过度囤积基础商品可能让他人陷入困境，但也可能限制整个经济的增长。玩家要在比别人好与让系统继续运作之间判断，这种矛盾由规则产生，无须额外角色发表道德训诫。

不过，现实市场也不能从游戏中直接推导。时间、土地数量、商品用途、外部贸易和事件概率都由作者选择；缺少劳动制度、历史占有和许多现实约束。作品通过简化的相互依赖，让玩家体验资源、交易与共同生活之间的关系。

开发中被删去的贷款、资源耗竭、破产和其他机制，也说明简化是主动取舍。添加一种现实制度，可能增加表面逼真，却削弱核心交换的清楚程度。团队更看重少量规则相互作用的密度，让玩家能够读懂局面，再把精力放在人与人的选择上。[1]

随机补偿又会引起另一种公平争论。落后者获得较好机会，有助于保持参与；领先者可能觉得自己先前的努力被削弱。M.U.L.E.没有消除这个张力，而是在多人持续投入与完全按既有优势累积之间作出选择。这是它的竞争风格，不能当成对所有策略游戏都适用的唯一方案。

# 信息公开与共同决策

同屏使人们能够观察其他人的需要，却不保证大家拥有相同知识。公开的库存和报价，与尚未完全掌握的地下储量、生产计划和私人承诺并存。玩家可能从一个人突然抬价推断他缺少能源，也可能误把策略性等待看成真正短缺。信息的用途取决于解释，市场并没有自动消除误判。

这种结构让新手与熟手之间可以发生多种关系。熟手能够解释地形用途、提供临时交易，也能利用别人尚未理解的依赖获利。规则的共同可见性既支持教学，也支持竞争。作品是否形成愉快的聚会经验，因而还依赖在场者怎样对待能力差异，不能只靠电脑保证每个人平均拥有同样多钱。

共享屏幕也改变等待的感受。别人选择土地或牵领机械骡时，旁人能够看见机会、失误和时间压力；这些动作随后影响自己的市场。轮到自己之前的观看具有实际意义，并非完全中断参与。经济系统把不同操作阶段的后果互相传递，让个人回合仍然处在集体注意之中。

土地分配、基础供给和私人交易共同限定了玩家能采取的合作形式。人们可以许诺下一轮偿还帮助，也能通过当前成交表达善意，但程序没有替他们记住全部人情。规则之外的记忆因此进入规则之内的行动。一次看似不合算的出售，可能在参与者自己的关系叙事中具有清楚理由。

这也是机器对手难以完全替代真人的原因之一。人工智能可以遵守商品规则和价格计算，却未必让其他玩家相信它会记得一次让利或一句玩笑。Bunten对单人模式的保留意见，不只是对算法强弱的技术评价，更指向这部作品把多少意义寄托在共同在场的人身上。[1]

分级模式还让作品提供了逐步学习的入口。先理解土地、基本物资和拍卖，再加入勘探与共谋，玩家面对的规则负担有所变化。锦标赛中的策略分析不能直接充当初学模式的完整说明；不同复杂度各自安排了哪些关系需要被照看。这种递进也显示，团队并未把全部经济细节同时交给第一次坐在屏幕前的人。[3]

同一个家庭或朋友群体可以随着熟练程度改变模式，而不必更换整个虚构世界。人物、土地和机械骡提供连续的识别基础，新规则再重新分配注意。学习于是既保留熟悉感，也能让旧经验受到新的挑战，形成超过一局胜负的共同积累。

# 对模拟与程序创作的意义

M.U.L.E.的机器对手固然属于游戏人工智能，但作品更重要的程序组织还包括商品供给、生产条件、土地分配和价格变化。模拟把几个人的局部决定连接起来，产生任何一个人都不能单独控制的局面。研究它时，不能只寻找某个最复杂的决策算法，而忽略支持共同世界的规则。

它也给交互叙事提供了一种没有长篇剧本的形式。一次囤粮、一次临时救济和随后失约，就能成为参与者反复讲述的故事。叙述发生在系统许可的行为与人的关系之间，程序不需要预写每段对白。每局不同的故事仍有边界：它们依赖固定商品、时间和交易接口，并不来自无限内容生成。

作品的影响宜从具体设计关系理解。它把复杂计算留给机器，把可见的选择、动作和讨价还价交还给人；把私人目标嵌入公共依赖，又通过补偿避免竞争过早结束。这些特征使它持续适合与经济模拟、家庭桌游及当代多人合作作品比较。比较能提出问题，直接继承则仍需后继作者的明确说明。

因此，M.U.L.E.的目标不只是让计算机正确结算经济账目。它要为几个人创造能够合作、勒索、救济或结盟的局面。一个缺粮者愿意付多少钱，既受系统数值影响，也受其他人在场时的态度影响。程序提供相同资源约束，社交关系则改变人们怎样使用它们。

四个席位可以由人和计算机角色共同占据。电脑补位使人手不足时仍能启动完整经济，不过Bunten自己把单人部分视为设计较弱的一环。这个评价指向作品的核心依赖：程序对手能够买卖，却不能完整取代朋友之间的承诺、埋怨和临时默契。它的多人性具有结构意义，并非在单人规则旁边附加一个联机选项。[1]

原版的共同游玩依靠同一场所的输入设备和屏幕。Atari机型是否拥有四个摇杆接口，会影响四位真人同时操作的条件；后来移植也需要重新处理控制问题。“四人游戏”描述了设计席位，不能省略具体硬件就推断任意家用机都能以同样方式提供四人体验。[2]

# 土地和机械骡的行动循环

每轮首先涉及土地取得。玩家观察河谷、平地和山地的位置，选择适合自己计划的地块，再进入个人行动时间。地图没有把全部土地做成同质格子，地形差异会影响产出，因而土地价值取决于生产用途。最便宜或最近的一块，不一定最符合当前需求。[1][3]

机械骡承担了设置生产的接口。玩家进入城镇领取机器，把它带到对应商店进行改装，再领到地块安装。抽象地说，这相当于给某块土地指定生产类型；作品却把操作表现为牵领一个会运动的对象。经济设置变成有路线、时间和动作反馈的小任务，而不只是一张数字表。[1]

有限行动时间使准备工作具有代价。玩家不能无限停留、反复比较所有组合再安全确认；走错路线、改装失误或未及时安装，都可能损失当轮机会。食物短缺又会削减可用行动时间，把上一轮的经济决定落实到下一轮的身体操作。这使稀缺不只表现为资产减少，还表现为能够做多少事。

地图与城镇之间的切换保留了空间连续性。开发者描述，城镇从地图上的一个地块展开为更详细的整屏区域，满足操作分辨率，又让它仍像殖民地的一部分。这种转换让玩家容易理解自己正在同一个世界里改变尺度，避免拍卖、改装和土地看起来像互不相关的菜单。

# 基础商品与锦标赛扩展

食物支撑殖民者活动，能源支持生产，Smithore关系到新机械骡的供应。锦标赛模式进一步加入了Crystite与共谋机制；以下四商品及私下交易的分析以锦标赛模式为范围。Crystite提供收益较高而有风险的外销机会。商品各自承担不同功能，不能简单按当下价格选一个永远最赚钱的产品。若太多人都转向高收益矿物，基础生产就可能断裂。[1][3]

这种依赖使一个人的经营选择改变别人的可能性。能源富余者可以从集体短缺中获利，短期看似最优；但若能源供应不足导致大家产不出矿石，整个后续市场也会受损。收益来自共同经济的循环，同时又诱使个人试图攫取循环中的有利位置。

土地还支持规模效应。相邻地块生产同种商品，以及拥有更多同类生产地块，会带来产量方面的优势。专门化因此有吸引力，却需要通过交换获得其他物资。多样化能减少依赖，专门化能提高某种产出，两种策略之间的取舍构成了经济决策，而不是预先固定的道德答案。[1]

Crystite储量需要勘探，地表不能直接显示全部价值。它的价格波动又使预期收入不完全确定。玩家既判断别人需要什么，也判断自己掌握的信息是否足够可靠。地下资源的信息差与公开拍卖的价格信号叠在一起，使经济世界具有有限却明确的不透明性。

# 拍卖让价格成为一场表演

商品阶段把买者和卖者放在同一屏幕，用角色位置表达报价。人们能够直接看见谁急需商品、谁有余量，以及双方愿意接近到什么价格。价格从账本中的一个结果变成大家同时参与的动作，计算机则负责执行成交和库存变化。[3]

这项界面选择极大降低了表达负担。玩家不需要先学复杂商业指令，只要移动自己的角色，就能在公开空间里改变要价。与此同时，选择何时坚持、何时退让仍然复杂。简单输入承载了对稀缺、竞争和他人意图的判断，易操作与策略深度由此相容。

拍卖的趣味尤其来自等待。买家想压价，卖家希望多赚；其他人的移动可能突然促成成交，也可能使一个人发现自己的条件过高。限时结束让拖延成为有成本的策略。即使人人面对同一组数字，集体行动的顺序仍会造成不同结局。

允许私下协作，则进一步改变公开市场。两位玩家可以试图互相帮助，也可能通过选择性交易针对领先者。Bunten把这种共谋列为最终加入、而且特别满意的机制。它为最初希望得到的社交弹性提供了接口，但也使公平不能只靠规则内部的对称性保证。[1]

# 市场理想怎样被测试修改

开发手记明确提到海因莱因的Time Enough for Love与The Moon Is a Harsh Mistress提供过场景和制度想象。边疆个人、相对简陋工具和自立的殖民地，帮助团队判断哪些规则适合这个世界。这些文学来源经由作者的具体阅读与制作进入作品。[1]

早期方案希望尽量取消外部干预，全部土地也曾通过竞价出售。测试却出现了清楚的优势滚动：有钱者取得更多土地，生产更多，又更容易买下后续土地。领先者的优势因此不断加强，游戏过早失去悬念。开发者最终引入每轮分配土地的机构，改变了最初制度设想。[1]

这个修改很能说明模拟游戏的创作过程。规则可以来自一种经济理想，但实际游玩会暴露它产生的反馈；作者必须决定保留、限制还是修正。最终作品并非关于完全自由市场的一张中立演示图，而是为了维持竞争和共同参与，经过多轮干预后的设计。

随机个人事件也承担平衡作用。开发手记说明领先者不会得到好事件，落后者不会得到坏事件；殖民地整体又可能遭遇地震、海盗或商店火灾等变化。个人运气和共同灾难具有不同对象，不能都笼统说成平均分配的随机性。它们分别调节排名与整体经济的压力。[1]

# 悬念来自怎样呈现计算

电脑能够迅速得出产量，作品却把结果逐步显示在地图上。开发者故意让生产看起来是一个展开的过程，等待中的玩家能够看到自己或别人的地块发生什么。这个安排不增加经济公式的精确度，却增加了结果揭晓的悬念。

库存条也通过消耗、损坏与新增生产的顺序动画解释变化。玩家看到资源为何减少，再看到新产出如何补上，比只收到一个最后数字更容易建立模型。界面因此承担教学工作，把机器已经知道的结果转换成适合人理解的时间过程。[1]

计时音在临近结束时变快，同样把抽象限制变成情绪压力。人会因为还差一次安装或一次成交而着急，旁观者也能理解紧张来自哪里。这种公开可见的时间使轮流操作仍然可以成为共同表演：暂时没有输入权的人，也参与观看和评论。

机械骡摇头的动作、外星种族和Roy Glover创作的主题音乐，又使经济行为具有轻松性格。Bunten曾感叹，玩家特别注意音乐，而不是他投入大量工作的程序；他后来接受了任何让人享受作品的元素都有价值。作品的整体效果因此包含常被技术分析忽略的情绪入口。[1]

# 竞争、合作与设计的取舍

个人财富排名与殖民地整体发展同时存在，使“赢”并不等于单纯毁掉所有对手。过度囤积基础商品可能让他人陷入困境，但也可能限制整个经济的增长。玩家要在比别人好与让系统继续运作之间判断，这种矛盾由规则产生，无须额外角色发表道德训诫。

不过，现实市场也不能从游戏中直接推导。时间、土地数量、商品用途、外部贸易和事件概率都由作者选择；缺少劳动制度、历史占有和许多现实约束。作品通过简化的相互依赖，让玩家体验资源、交易与共同生活之间的关系。

开发中被删去的贷款、资源耗竭、破产和其他机制，也说明简化是主动取舍。添加一种现实制度，可能增加表面逼真，却削弱核心交换的清楚程度。团队更看重少量规则相互作用的密度，让玩家能够读懂局面，再把精力放在人与人的选择上。[1]

随机补偿又会引起另一种公平争论。落后者获得较好机会，有助于保持参与；领先者可能觉得自己先前的努力被削弱。M.U.L.E.没有消除这个张力，而是在多人持续投入与完全按既有优势累积之间作出选择。这是它的竞争风格，不能当成对所有策略游戏都适用的唯一方案。

# 信息公开与共同决策

同屏使人们能够观察其他人的需要，却不保证大家拥有相同知识。公开的库存和报价，与尚未完全掌握的地下储量、生产计划和私人承诺并存。玩家可能从一个人突然抬价推断他缺少能源，也可能误把策略性等待看成真正短缺。信息的用途取决于解释，市场并没有自动消除误判。

这种结构让新手与熟手之间可以发生多种关系。熟手能够解释地形用途、提供临时交易，也能利用别人尚未理解的依赖获利。规则的共同可见性既支持教学，也支持竞争。作品是否形成愉快的聚会经验，因而还依赖在场者怎样对待能力差异，不能只靠电脑保证每个人平均拥有同样多钱。

共享屏幕也改变等待的感受。别人选择土地或牵领机械骡时，旁人能够看见机会、失误和时间压力；这些动作随后影响自己的市场。轮到自己之前的观看具有实际意义，并非完全中断参与。经济系统把不同操作阶段的后果互相传递，让个人回合仍然处在集体注意之中。

土地分配、基础供给和私人交易共同限定了玩家能采取的合作形式。人们可以许诺下一轮偿还帮助，也能通过当前成交表达善意，但程序没有替他们记住全部人情。规则之外的记忆因此进入规则之内的行动。一次看似不合算的出售，可能在参与者自己的关系叙事中具有清楚理由。

这也是机器对手难以完全替代真人的原因之一。人工智能可以遵守商品规则和价格计算，却未必让其他玩家相信它会记得一次让利或一句玩笑。Bunten对单人模式的保留意见，不只是对算法强弱的技术评价，更指向这部作品把多少意义寄托在共同在场的人身上。[1]

分级模式还让作品提供了逐步学习的入口。先理解土地、基本物资和拍卖，再加入勘探与共谋，玩家面对的规则负担有所变化。锦标赛中的策略分析不能直接充当初学模式的完整说明；不同复杂度各自安排了哪些关系需要被照看。这种递进也显示，团队并未把全部经济细节同时交给第一次坐在屏幕前的人。[3]

同一个家庭或朋友群体可以随着熟练程度改变模式，而不必更换整个虚构世界。人物、土地和机械骡提供连续的识别基础，新规则再重新分配注意。学习于是既保留熟悉感，也能让旧经验受到新的挑战，形成超过一局胜负的共同积累。

# 对模拟与程序创作的意义

M.U.L.E.的机器对手固然属于游戏人工智能，但作品更重要的程序组织还包括商品供给、生产条件、土地分配和价格变化。模拟把几个人的局部决定连接起来，产生任何一个人都不能单独控制的局面。研究它时，不能只寻找某个最复杂的决策算法，而忽略支持共同世界的规则。

它也给交互叙事提供了一种没有长篇剧本的形式。一次囤粮、一次临时救济和随后失约，就能成为参与者反复讲述的故事。叙述发生在系统许可的行为与人的关系之间，程序不需要预写每段对白。每局不同的故事仍有边界：它们依赖固定商品、时间和交易接口，并不来自无限内容生成。

作品的影响宜从具体设计关系理解。它把复杂计算留给机器，把可见的选择、动作和讨价还价交还给人；把私人目标嵌入公共依赖，又通过补偿避免竞争过早结束。这些特征使它持续适合与经济模拟、家庭桌游及当代多人合作作品比较。比较能提出问题，直接继承则仍需后继作者的明确说明。
