# 简介

本文报告将一个小型人工神经网络移植到任天堂娱乐系统（NES）的实验。作者先在现代台式计算机上训练数字图像分类器，再把预训练权重和6502汇编程序装入32 KB程序ROM范围，通过手柄绘图界面在实体NES上执行分类。文章讨论输入图像二值化与裁剪、400—16—10网络结构、浮点运算和卡带存储预算，并将用于游戏AI的强化学习模型列为后续工作。

## Abstract

<!-- translation -->
## 摘要
<!-- endpair -->

<!-- pair:en:NN0009:abstract-->
Artificial Neural Networks (ANN) are used in a variety of machine learning tasks such as image classification and pattern recognition. Training ANN models on large datasets can be time consuming and require specialized hardware and processing power. Often, the training is performed on powerful systems, and the resultant final trained network can be utilized on small computers and mobile devices to perform tasks instantly. The Nintendo Entertainment System (NES) was released in 1985 and featured a 1.79 MHz CPU and 2 KB of RAM. The original program code for games for the NES fit within 32 KB of ROM on cartridges. In this work, we create an ANN and train it using the EMNIST hand-drawn digit dataset on a desktop computer. This ANN is then ported to the NES utilizing assembly language. The program code and pretrained weights are stored to a game cartridge fitting within the bounds of 32 KB. Additionally, a user interface is provided for drawing and loading test samples and executing the ANN classification of hand drawn digits on a physical NES device from 40 years ago.

<!-- translation -->
人工神经网络（ANN）用于图像分类、模式识别等多种机器学习任务。在大型数据集上训练ANN模型可能耗时较长，并需要专门的硬件和处理能力。训练通常在性能强大的系统上进行，而最终训练好的网络可以用于小型计算机和移动设备，即时执行任务。任天堂娱乐系统（NES）于1985年发布，配有1.79 MHz的CPU和2 KB的RAM。NES游戏最初的程序代码可容纳在卡带32 KB的ROM之内。在本项工作中，我们创建了一个ANN，使用EMNIST手绘数字数据集在台式计算机上对其进行训练，随后用汇编语言将这个ANN移植到NES。程序代码和预训练权重存放在一张游戏卡带中，总容量不超出32 KB。此外，我们提供了一个用户界面，用于绘制和加载测试样本，并在一台40年前的实体NES设备上运行ANN，对手绘数字进行分类。
<!-- endpair -->

<!-- pair:en:NN0012:heading-->
## 1. Introduction

<!-- translation -->
## 1. 引言
<!-- endpair -->

<!-- pair:en:NN0013:paragraph-->
Artificial Neural Networks (ANN) are a part of Machine Learning (ML) and are used for several different kinds of tasks such as classification and segmentation [1] as well as prediction [2]. The applications of ANN are numerous and are often used to solve problems in a wide range of fields including science, finance, engineering, agriculture, education, and energy [3].

<!-- translation -->
人工神经网络（ANN）属于机器学习（ML），可用于分类和分割[1]、预测[2]等多种不同任务。ANN的应用很多，经常用于解决科学、金融、工程、农业、教育和能源等众多领域的问题[3]。
<!-- endpair -->

<!-- pair:en:NN0014:paragraph-->
A simple architecture for an ANN may involve three layers known as the input, hidden, and output layers [4], though more advanced ANNs like those in Deep Learning (DL) will have several different layers [5]. These layers contain nodes with connections from previous layers, a bias and weights. Data will feed forward through the network producing an output. The learning process involves updating these weights. One of the most common algorithms for this is known as backpropagation [6].

<!-- translation -->
ANN的一种简单架构可以包含输入层、隐藏层和输出层这三层[4]，而深度学习（DL）中的ANN等更先进的网络会有多种不同的层[5]。这些层包含节点，节点具有来自前一层的连接、一个偏置和若干权重。数据沿网络前向传递，产生输出。学习过程涉及更新这些权重。其中一种最常用的算法称为反向传播[6]。
<!-- endpair -->

<!-- pair:en:NN0015:paragraph-->
ANNs typically use the IEEE-754 single or double-precision floating-point format [7]. To perform the math required, devices must have a floating-point unit (FPU) along with the usual CPU. Originally used for 2D and 3D graphics acceleration for games, Graphics Processing Units (GPU) are now commonly used for machine learning [8]. In 2015 Google introduced the Tensor Processing Unit (TPU) to increase performance for neural networks and use less power than GPUs [9].

<!-- translation -->
ANN通常使用IEEE-754单精度或双精度浮点格式[7]。为了执行所需的数学运算，设备除了通常的CPU之外，还必须具有浮点运算单元（FPU）。图形处理器（GPU）最初用于游戏的二维和三维图形加速，如今也常用于机器学习[8]。2015年，谷歌推出张量处理单元（TPU），以提高神经网络的性能，并使其功耗低于GPU[9]。
<!-- endpair -->

<!-- pair:en:NN0016:paragraph-->
The Nintendo Entertainment System (NES) was originally released in North America in 1985 [10]. The NES featured a Ricoh 2A03 chip that was based on the 8-bit 6502 processor operating at 1.79 MHz [11]. The NES also had only 2 KB of RAM available. The program (game) code is stored within ROM chips on the game cartridges. The original Super Mario Bros. fit within an original restriction of 32 KB of program ROM space [12] before the later creation of memory mapper chips.

<!-- translation -->
任天堂娱乐系统（NES）最初于1985年在北美发布[10]。NES配备Ricoh 2A03芯片，该芯片基于8位6502处理器，工作频率为1.79 MHz[11]。NES可用的RAM也只有2 KB。程序（游戏）代码存储在游戏卡带的ROM芯片中。在后来出现内存映射芯片之前，最初的《Super Mario Bros.》被容纳在最初32 KB程序ROM空间的限制之内[12]。
<!-- endpair -->

<!-- pair:en:NN0017:paragraph-->
In this experimental work, we demonstrate that an ANN is capable of running even with severe hardware constraints. We created a simple ANN in the C programming language and trained it on a dataset of small images on a modern computer. The program code for the ANN is ported to 6502 assembly language and includes the pretrained weights from the ANN model. By reducing dimensionality of the images and using a small number of hidden nodes we were able to fit within the 32 KB limit. The program code is placed onto a specialized game cartridge and loaded into the physical NES hardware. We also developed a user interface (UI) which allows the user to draw images as well as load sample dataset images using the NES gamepad. Pressing START executes the ANN and displays its classification of the image.

<!-- translation -->
在这项实验性工作中，我们展示了ANN即使在严格的硬件限制下也能够运行。我们使用C语言创建了一个简单的ANN，并在现代计算机上用一个小图像数据集进行训练。ANN的程序代码被移植到6502汇编语言，并包含ANN模型的预训练权重。通过降低图像维度并使用少量隐藏节点，我们使其容纳在32 KB的限制之内。程序代码被写入一张专用游戏卡带，并加载到实体NES硬件中。我们还开发了一个用户界面（UI），让用户可以使用NES手柄绘制图像，也可以加载数据集中的样本图像。按下START键即可运行ANN，并显示它对图像的分类结果。
<!-- endpair -->

## 2. 材料与方法

<!-- pair:en:NN0019:heading-->
### 2.1. Dataset

<!-- translation -->
### 2.1. 数据集
<!-- endpair -->

<!-- pair:en:NN0020:paragraph-->
The MNIST dataset [13] consists of hand drawn digit (0 – 9) images and is often referred to as the “hello world” of neural networks and deep learning [14]. The dimensions of the images are 28x28 and contain grayscale values ranging from 0 - 255. Examples of the dataset images can be seen in Figure 1. The training set contains 60,000 images with the testing set having 10,000. These sets are balanced with 6,000 of each digit in the training set and 1,000 of each digit in the testing set. Given we are pretraining the neural network on a modern computer, we opted to use the larger EMNIST dataset [15] which is an extension of MNIST containing four times the number of images of MNIST. This dataset has 240,000 images in the training set and 40,000 in the testing set. These sets are also balanced.

<!-- translation -->
MNIST数据集[13]由手绘数字（0—9）的图像组成，常被称为神经网络和深度学习的“hello world”[14]。图像尺寸为28x28，灰度值范围为0—255。图1展示了数据集图像的例子。训练集包含60,000幅图像，测试集包含10,000幅。两个集合中的类别均衡，训练集中每个数字各有6,000幅图像，测试集中每个数字各有1,000幅。由于我们在现代计算机上预训练神经网络，因此选择使用规模更大的EMNIST数据集[15]；它是MNIST的扩展，图像数量为MNIST的四倍。这个数据集的训练集有240,000幅图像，测试集有40,000幅，两个集合中的类别也都均衡。
<!-- endpair -->

<!-- pair:en:NN0022:heading-->
### 2.2. Preparing the Data

<!-- translation -->
### 2.2. 数据准备
<!-- endpair -->

<!-- pair:en:NN0023:paragraph-->
We took multiple steps to reduce the dimensionality of the images to work within memory constraints. First, we changed pixel values from a range of 0 - 255 to be just binary values of 0 or 1. Any pixel value less than 128 was changed to 0 with 128 or greater becoming a 1. Figure 2 shows an image with grayscale values and then changed to binary values. Reducing the values to bits allowed for 8 pixels to be packed into a single byte. This reduced storage requirements by almost ⅛ for our input weight data and loadable test samples.

<!-- translation -->
为了在内存限制内工作，我们采取了多个步骤来降低图像维度。首先，将像素值从0—255的范围改为仅有0或1的二值。任何小于128的像素值都改为0，而大于或等于128的值改为1。图2展示了一幅灰度图像及其转换为二值后的图像。将数值缩减为比特之后，便可以把8个像素打包到一个字节中。对于我们的输入权重数据和可加载测试样本，这使存储需求减少了近⅛。
<!-- endpair -->

<!-- pair:en:NN0024:caption-->
Figure 2: Left: Original 256 grayscale image. Right: 1-bit binary image.

<!-- translation -->
图2：左：原始的256级灰度图像。右：1位二值图像。
<!-- endpair -->

<!-- pair:en:NN0025:paragraph-->
Our goal was to reduce the image resolution to 20×20 with minimal scaling required. Given that the images in the dataset are centered, columns of pixels on the left and right, as well as rows on the top and bottom of the image, can be discarded as they contain no information about the digit. This can be seen in Figure 3. We discarded rows and columns with 2 or fewer pixels of a value of 1.

<!-- translation -->
我们的目标是将图像分辨率降低到20×20，并尽可能减少所需的缩放。由于数据集中的图像居中，图像左右两侧的像素列以及上下两侧的像素行不包含关于数字的信息，因此可以丢弃。图3展示了这一点。我们丢弃了那些值为1的像素数量不超过2个的行和列。
<!-- endpair -->

<!-- pair:en:NN0026:caption-->
Figure 3: Pixel grid indicating candidate rows/columns to be removed.

<!-- translation -->
图3：标示候选待删除行／列的像素网格。

<!-- pair:en:NN0027:heading-->
### 2.3. Neural Network

<!-- translation -->
### 2.3. 神经网络
<!-- endpair -->

<!-- pair:en:NN0028:paragraph-->
Figure 4 shows the configuration of our ANN. The input layer contains the pixel information of the current image. With our input images having dimensions 20×20, there will be 400 input nodes. As in most neural networks, every input node is connected to every hidden node [16]. Our model uses 16 hidden nodes. Here, we introduce an optimization. Given our pixel input values are either 0 or 1, and these values are multiplied by the weights, input values of 0 can simply be skipped. Additionally, with an input value of 1, we can skip the multiplication and just add the weight to the node’s total. Every hidden node connects to every output node. There are 10 output nodes, one for each digit (0 – 9). All of our nodes also have a bias. Originally, the Sigmoid activation function [17] was popular for neural networks however we opted to use the Leaky ReLU function [18] as it provided better performance.

<!-- translation -->
图4展示了我们ANN的配置。输入层包含当前图像的像素信息。由于输入图像的尺寸为20×20，输入节点将有400个。与大多数神经网络一样，每个输入节点都连接到每个隐藏节点[16]。我们的模型使用16个隐藏节点。在这里，我们引入了一项优化。像素输入值只有0或1，而这些值要与权重相乘，因此可以直接跳过输入值为0的情况。此外，当输入值为1时，可以跳过乘法，直接将权重加到节点的总和中。每个隐藏节点都连接到每个输出节点。输出节点共有10个，分别对应每个数字（0—9）。我们所有的节点也都有一个偏置。Sigmoid激活函数[17]最初曾广泛用于神经网络，不过我们选择使用Leaky ReLU函数[18]，因为它提供了更好的性能。
<!-- endpair -->

<!-- pair:en:NN0029:caption-->
Figure 4: Diagram of our ANN.

<!-- translation -->
图4：我们的ANN示意图。
<!-- endpair -->

<!-- pair:en:NN0030:figure_text-->
Input 1; Input 2; Input 400
Hidden 1; Hidden 16
Output 1; Output 10

<!-- translation -->
输入1；输入2；输入400

<!-- pair:en:NN0031:paragraph-->
With 20×20 input nodes each connected to 16 hidden nodes at 4-bytes per floating-point weight, this would use (20×20×16×4) 25,600 bytes of space. Additionally, the 16 hidden nodes connected to the 10 output nodes is (16×10×4) 640 bytes. Each of the 16 hidden nodes and 10 nodes have a bias input for (16×4 + 10×4) 104 bytes. The stored pretrained weights occupy 26,344 of our total 32,768 program ROM space leaving 6,424 bytes for our code that runs the user interface and executes the ANN to perform the classification.

<!-- translation -->
20×20个输入节点各自连接到16个隐藏节点，每个浮点权重占4字节，这将使用（20×20×16×4）25,600字节的空间。此外，16个隐藏节点与10个输出节点相连，占用（16×10×4）640字节。16个隐藏节点和10个节点各自都有一个偏置输入，共占（16×4＋10×4）104字节。存储的预训练权重占总计32,768字节程序ROM空间中的26,344字节，余下6,424字节留给运行用户界面、执行ANN分类的代码。
<!-- endpair -->

<!-- pair:en:NN0032:heading-->
### 2.4. Hardware and Tools

<!-- translation -->
### 2.4. 硬件与工具
<!-- endpair -->

<!-- pair:en:NN0033:paragraph-->
While modern machine learning research is typically developed in the Python programming language using libraries such as PyTorch, Keras, and TensorFlow [19], our ANN is coded from scratch in the C programming language without any of these types of libraries. This allowed for a more direct port to the 6502 assembly language required for developing for the NES. After training, the weights were exported to a format that could be included by a 6502 assembly compiler. Given the NES is an 8-bit processor with no floating point support, in order to port our neural network, we used a floating point library developed by Roy Rankin and Steve Wozniak [20]. To run our program on a physical NES device, we loaded our program onto an SD card and placed it into a Krikzz Everdrive N8 Pro cartridge which can be seen in the left of Figure 5. This cartridge was then placed into an original NES from 1985 seen on the right in Figure 5.

<!-- translation -->
现代机器学习研究通常用Python语言，借助PyTorch、Keras和TensorFlow等库开展[19]；而我们的ANN使用C语言从零编写，没有使用任何这类库。这使它更便于直接移植到开发NES程序所需的6502汇编语言。训练完成后，权重被导出为一种可由6502汇编编译器纳入程序的格式。由于NES使用的是不支持浮点运算的8位处理器，为了移植神经网络，我们采用了Roy Rankin和Steve Wozniak开发的浮点运算库[20]。为了在实体NES设备上运行程序，我们将程序载入一张SD卡，再将其放入Krikzz Everdrive N8 Pro卡带中，如图5左侧所示。随后，将该卡带插入一台1985年的原版NES，如图5右侧所示。

## 3. Experiments and Discussion

<!-- translation -->
## 3. 实验与讨论
<!-- endpair -->

<!-- pair:en:NN0037:paragraph-->
We trained our ANN on the EMNIST dataset on a desktop computer. We used a learning rate of 0.01, an alpha value of 0.01 for LeakyReLU and 5 epochs. The training completed in 21 seconds. Our simple ANN achieved a 93.11% accuracy on the EMNIST test set. This number could be higher with a larger neural network however for this experiment we needed to stay within the 32 KB limit. The pretrained weights along with our program code for the UI and executing the ANN were loaded onto the cartridge and NES seen in Figure 5. Our program begins with a basic startup/menu screen seen in the left of Figure 6. Pressing START enters the main drawing screen seen on the right in Figure 6.

我们在台式计算机上用EMNIST数据集训练ANN。学习率设为0.01，LeakyReLU的alpha值设为0.01，共训练5轮。训练耗时21秒。这个简单的ANN在EMNIST测试集上取得了93.11%的准确率。若使用更大的神经网络，这个数字还可以更高，但本次实验需要保持在32 KB的限制以内。预训练权重连同用户界面以及执行ANN的程序代码，被载入图5所示的卡带和NES。程序首先显示一个基本的启动／菜单界面，如图6左侧所示。按下START键后，便进入主绘图界面，如图6右侧所示。

<!-- pair:en:NN0047:heading-->
## 4. Conclusion

<!-- translation -->
## 4. 结论
<!-- endpair -->

<!-- pair:en:NN0048:paragraph-->
In this experimental work, we created a basic ANN image classifier which was trained on a modern computer and then exported the weights from the various layers. We greatly reduced the dimensionality of the input images and used a small set of hidden nodes in order to fit within a 32 KB limit. The ANN was ported to assembly language and using the UI, a user can draw or load testing images and execute the ANN. This demonstrates the 1985 NES is capable of using a basic ANN with pretrained weights to successfully classify digit images.

<!-- translation -->
在这项实验性工作中，我们创建了一个基础的ANN图像分类器，在现代计算机上对其进行训练，随后导出各层的权重。为了容纳在32 KB的限制之内，我们大幅降低了输入图像的维度，并使用了少量隐藏节点。ANN被移植到汇编语言；用户可通过UI绘制或加载测试图像，并运行ANN。这表明，1985年的NES能够利用具有预训练权重的基础ANN，成功对数字图像进行分类。
<!-- endpair -->

<!-- pair:en:NN0049:paragraph-->
Future work includes using memory mapper (bank swapping) chips to enable more ROM and therefore larger models to be stored. Additional future work includes building a Reinforcement Learning model that could be used for game AI on the NES.

<!-- translation -->
未来的工作包括使用内存映射（存储体切换）芯片，提供更多ROM空间，从而存储更大的模型。其他未来工作还包括构建一种可用于NES游戏AI的强化学习模型。
<!-- endpair -->
