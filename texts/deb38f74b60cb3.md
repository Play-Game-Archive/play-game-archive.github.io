# 简介

Dungeon Keeper是Bullfrog Productions制作、Electronic Arts于1997年发行的地下城经营与即时策略游戏。玩家成为地下城守护者，挖掘通道、布置房间、采金、吸引怪物，为它们提供食物、巢穴和工资，并抵御进入地下城的英雄或其他守护者。传统冒险中等待被攻克的迷宫，在这里变成玩家需要亲自建设和维持的组织。

Peter Molyneux担任项目负责人，Simon Carter为首席程序员，Mark Healey为首席美术。原手册的游戏设计名单还包括Dene Carter、Jonty Barnes与Alex Peters等人。本文讨论1997年电脑原作，另行区分扩展包The Deeper Dungeons、1999年续作与后来的同名移动游戏。[1]

# 把地牢从背景变成工作场所

开局的土地大多需要挖掘，玩家用标记向小鬼分配任务。小鬼实际移动到可到达的位置，开出空间，再认领地面、加固墙壁和搬运物资。鼠标划定一片区域以后，工作不会无条件瞬间完成；距离、通路与劳动力都影响实际进度。[1]

地下城之心是整个据点的关键，遭到摧毁便会失败。它把扩张重新拉回防守：一条通道既能让工人接近资源，也可能让敌人接近核心。玩家不能只按房间面积判断发展，更要理解开掘怎样改变可通行网络。

黄金需要被开采并送入宝库，才能成为可用财富。地面上已经出现的金块与财政上能够支付的资金，并非完全相同状态。这个运输环节使宝库位置、小鬼安全和通路长度具有经营意义。钱并不只是界面里自动增长的数字，也暂时作为世界里的对象存在。[1]

认领土地还决定房间能建在哪里。玩家标记、挖开、铺地与建设之间存在步骤，敌人占有的空间则需要争夺。地下城因此既是形状，也是持续工作的领土。把它画成漂亮平面，只完成了规划的一部分；还需要一个能实际执行规划的组织。

# 房间是吸引力，也是劳动条件

巢穴和孵化场提供休息与食物，宝库支撑发薪，训练室增强战斗能力，图书馆用于研究，工坊制造门和陷阱。它们不是统一生产军队的换皮建筑，而是进入不同循环的设施。缺少某种条件，可能使整个生物群体无法发挥预期作用。[1]

不同房间和面积还影响能够吸引的怪物。手册具体列出若干设施、大小与生物之间的关系，例如图书馆与术士、宝库与龙。玩家需要先准备环境，再等待怪物通过入口加入。招募因而带有间接性：不是任何时候按一下按钮，就能按数量制造所需部队。

入口本身需要被发现与打通。控制更多入口可能改变招募机会，也意味着新的空间联系和防守负担。土地、设施和兵力不是三张互不相关的列表，它们通过怪物抵达、生活和工作的过程联系起来。

房间布局又涉及效率。足够完整、便于到达的工作空间，与被通道切碎的同样面积，未必产生相同效果。大面积建设会消耗资金，也可能占掉珍贵的未挖掘屏障。玩家要在当前用途与未来扩展之间作出安排，地下城逐渐形成自己的功能分区。

# 怪物具有需要与脾气

怪物会吃饭、睡觉、训练、工作和领工资，也可能因为不满而生气或离开。玩家的权力很大，却必须回应它们的需要。把生物放进某个房间只能改变眼前安排，不能永久取消饥饿、疲劳和情绪。[1]

手册提供查询界面，显示生命、经验、工资和愤怒等状态。玩家需要观察这些差异，判断问题来自受伤、缺食、拥挤还是工作安排。怪物由此超出一个只有战斗数值的单位：它们也是需要被组织和维持的成员。

不同种类还具有偏好与不相容关系。强大的生物不一定容易管理，能够提供特殊能力的成员也可能带来额外麻烦。战斗实力、工资和稳定性之间需要取舍。地下城越复杂，玩家就越需要理解自己招来的究竟是什么，而不是只追求单位数量。

愤怒的角魔收割者把这项风险表现得格外鲜明。手册说明它生气后可能进入破坏状态，强力成员于是可能成为内部威胁。经营的困难不全来自外部英雄，也来自玩家自己创造的组织条件。这种可反噬的力量，让招募和照料都具有后果。

# 邪恶之手怎样表现统治

鼠标在生物上变成一只手，玩家可以拿起怪物，再把它放到工作或战斗位置。操作把抽象命令变成直接身体接触，仿佛管理者真的能够越过地牢把成员抓走。即时重新部署带来便利，也以夸张形式表现了权力的不对等。[1]

玩家还能拍打生物，使其暂时更快、更听话，同时损伤生命。短期效率与伤害在同一动作里出现。这个机制并不需要一段旁白解释压迫，因为收益和代价已经嵌入反馈；玩家的取舍是主动参与它，而不只是观看一个坏人实施暴力。

这种直接干预与大部分日常自主行动并存。玩家可以把工人扔到任务旁边，却仍要等待它们完成路径、搬运与施工。控制因此有不同层级：标记任务改变集体工作，拿起生物处理局部急事，改变房间则调整较长期的行为条件。

这组层级使作品兼有经营与即时策略的节奏。战斗发生时，人可以迅速介入，平时则观察组织自行运转。若始终逐只搬运，操作会变得繁重；若完全不看，又可能忽略内部问题。游戏持续要求玩家选择何时信任系统、何时亲手接管。

# 防线、陷阱与可改变的地图

门能够阻挡敌人，同时允许己方通行；锁门又可以限制己方进入某一区域。它既是防御建筑，也是管理内部流动的工具。狭窄通道、房间位置与门的组合，让同一片地下空间可以通过重新组织交通产生不同用途。[1]

陷阱需要制造、运送和安装，并非只要界面上选择了就立即拥有。它们对己方可见，对敌人则通常在触发前隐藏。玩家知道自己布置的危险，却必须谨慎面对对方空间；信息差由领土和行动历史产生。

挖掘使地图持续改变。连接资源的捷径，也可能打开入侵方向；加固墙壁提供安全，却会限制普通开掘。地图的战略价值不是关卡开始时完全确定的，而随各方工程发生变化。人工智能与路径安排必须在这个变化环境中工作，不能只沿一张永远固定的通行图移动。

对这种智能的讨论应停留在可核对范围。手册能够证明生物自主工作、战斗与移动的行为结构，但不能单凭观察就确定内部使用了哪一种完整搜索算法。游戏表现出聪明或迟钝，与研究者是否已掌握实现细节，是两项不同判断。

# 战斗与经营共享同一批身体

训练、生存和战斗没有被分成独立的角色库存。受伤成员需要恢复，死去的熟练怪物无法立即用一组同等级单位无成本替代。玩家在和平时期投入的工资与训练，会在冲突中承担风险，因此战斗损失具有经营历史。[1]

战场不只考验人数。怪物等级、位置、法术与正在发生的其他任务共同影响局面。直接把所有成员扔进一场战斗，可能暂时集中力量，也会使研究、生产或恢复停顿。战略判断需要把地下城整体工作纳入，而不是只看屏幕上的交战区域。

捕获敌人又使胜利有多种后续。监狱和拷问室可以处理俘虏，手册说明拷问可能揭示信息、转化阵营，也可能使被折磨者死亡。胜利因此不是简单清除一个对象，而是把对方身体带进己方的资源和权力体系。[1]

墓地则把死亡接入另一种生产：尸体被搬去分解，积累到一定程度能够产生吸血鬼。怪诞题材在这里获得系统性，死亡不仅作为剧情事件出现，也改变劳动、心情和可用成员。作品的黑色幽默由规则关系支撑，不能只从美术装饰理解。

# 附身让规划者进入自己的建筑

附身法术把俯视管理者放进一个生物的第一人称视角。玩家沿自己挖出的通道行动，使用这个生物具有的能力；附身小鬼还能进行开掘或夺取空间。俯瞰时的房间结构，由此变成身体尺度的路径和视线。[1]

Molyneux在1997年的访谈中说明，他希望人能够作为怪物体验自己建成的地下城。他还谈到让其他真人扮演地下城怪物的进一步想法，但没有时间实现。附身功能进入了已发行作品，多人方案则记录了开发者更远的构想。[2]

视角变化也改变了控制范围。管理时可以跨区域调动资源，附身时则需要通过局部身体行动。玩家得到更贴近战斗和空间的体验，同时暂时放弃部分全局注意。两种视角不是同一信息的缩放，而是对身份和能力的重新安排。

这个设计让建筑具有双重审美。通道既要从上方看便于经营，也能在内部感到连贯；怪物既是可拿取的单位，又是能够暂时成为玩家的身体。地下城不只是地图，也成为一种可以从不同位置经历的场所。

# 反派喜剧与管理想象

作品把英雄写成进入地盘、威胁财产和成员的敌人，把地下城主人放到需要安排食堂、睡眠和工资的位置。善恶角色的翻转制造了喜剧，也让传统冒险中被略去的维持工作浮现。迷宫不会天然有怪物和陷阱，它们需要资源和劳动。

旁白的夸张语气、怪物行为和阴暗空间形成黑色幽默。英雄的高尚与玩家的邪恶都被推到漫画程度，降低了写实再现的要求。游戏由此可以让暴力管理显得滑稽，但这种风格并不自动消除其中的权力结构。

玩家既要照料又能惩罚，同一只手提供食物、移动身体并施加伤害。作品没有把关怀与支配分配给完全不同角色，而使它们成为同一经营逻辑中的手段。这种混合是值得分析的核心：成员被承认为有需要的生命，同时也被计入生产和作战效率。

把怪物看作拟人化员工，可以解释工资和不满的幽默；但完全用现实劳动制度替换它们，又会抹去奇幻规则和荒诞性。更合适的批评需要来回对照具体机制：哪里模拟了组织依赖，哪里允许超常强制，哪里把强制的后果化为可笑或可计算的反馈。

# 管理界面如何让个体可见

地下城越大，单靠镜头寻找一个受伤或闲置成员就越费力。手册中的生物面板把闲置、工作和战斗分别统计，并允许从列表定位和拿取成员。这个界面把全局人数与具体身体联系起来，玩家可以从“哪里缺少劳动力”的判断，转到一次直接干预，而不必放弃对整个组织的观察。[1]

战斗提示也把分散冲突汇集到同一处。玩家能够查看双方等级与生命，再决定治疗、移动或继续等待。危险因而不只是地牢远处的动画，而成为可以检查和处理的信息。界面让管理者获得超越普通怪物视野的权力，也让玩家更容易把复杂局势理解为一组需要分配注意的事件。

这种可见性并不消除不确定性。地图尚未探明的区域、敌人的陷阱和怪物接下来的行为，仍会限制预测。作品让玩家在若干方面近似全知，同时在另一些方面必须冒险。强控制与有限信息的搭配，使经营不至于成为纯粹执行已知最优方案的工作。

从审美上说，面板和怪物的日常动画共同维持了这种双重身份。数字把成员变成可比较的劳动力，走路、吃鸡和睡眠又把它们恢复成有习惯的身体。玩家的照料或粗暴，都是在这两种观看方式之间作出。地下城的黑色幽默由此深入到界面，而不只是停留在怪物名称上。

发薪日使军队规模定期转化为财政压力。新成员不只是加入时需要一间房，留在地下城以后仍要从同一套资源中得到维持。扩军过快可能在战斗前就消耗稳定性，而暂时富足也不保证下一次支付顺利。经营者必须把未来开支放进当前决定，这让采金、招募和训练成为彼此牵制的时间安排。[1]

工资和食物还使等待具有不同含义。未参战的生物仍持续占用设施与资源。保留实力有准备价值，也有维持代价。地牢里看似平静的时刻，依旧充满工作与分配；这正是作品将经营和战争连接得如此紧密的原因。

# 关卡设计、版本与作品影响

原作通过关卡逐步开放设施、怪物和问题。玩家建立的地牢各不相同，但目标、资源与可用工具受场景安排约束。它结合了自由布局与预先设计的挑战，不是一套完全不需要作者关卡工作的自动世界生成器。

Deeper Dungeons扩展、Dungeon Keeper 2和后来采用同一名称的移动游戏，在关卡、系统与商业形式上均有自己的历史。重发行也可能调整显示与运行方式。讨论1997年作品的叙事与控制关系，需要保持这个对象边界，而不以系列后来的争议代替对初作的说明。

手册署名还提醒人们保留集体劳动。Ian Shaw负责导航系统，Russell Shaw负责音乐与音效，Richard Ridings等人参与配音，关卡、文本和测试也有各自人员。玩家感受到的一个整体地下城，由许多不同专业共同制造。[1]

它对游戏模拟的贡献，在于让有需求的自主生物、可改变的空间和即时战斗共用同一套经营世界。玩家不断在环境设计、直接干预与身体附身之间切换。作品既能作为策略挑战被理解，也能作为关于统治、依赖和照料的荒诞实验被阅读，二者都来自可具体指出的操作结构。

# 房间是吸引力，也是劳动条件

巢穴和孵化场提供休息与食物，宝库支撑发薪，训练室增强战斗能力，图书馆用于研究，工坊制造门和陷阱。它们不是统一生产军队的换皮建筑，而是进入不同循环的设施。缺少某种条件，可能使整个生物群体无法发挥预期作用。[1]

不同房间和面积还影响能够吸引的怪物。手册具体列出若干设施、大小与生物之间的关系，例如图书馆与术士、宝库与龙。玩家需要先准备环境，再等待怪物通过入口加入。招募因而带有间接性：不是任何时候按一下按钮，就能按数量制造所需部队。

入口本身需要被发现与打通。控制更多入口可能改变招募机会，也意味着新的空间联系和防守负担。土地、设施和兵力不是三张互不相关的列表，它们通过怪物抵达、生活和工作的过程联系起来。

房间布局又涉及效率。足够完整、便于到达的工作空间，与被通道切碎的同样面积，未必产生相同效果。大面积建设会消耗资金，也可能占掉珍贵的未挖掘屏障。玩家要在当前用途与未来扩展之间作出安排，地下城逐渐形成自己的功能分区。

# 怪物具有需要与脾气

怪物会吃饭、睡觉、训练、工作和领工资，也可能因为不满而生气或离开。玩家的权力很大，却必须回应它们的需要。把生物放进某个房间只能改变眼前安排，不能永久取消饥饿、疲劳和情绪。[1]

手册提供查询界面，显示生命、经验、工资和愤怒等状态。玩家需要观察这些差异，判断问题来自受伤、缺食、拥挤还是工作安排。怪物由此超出一个只有战斗数值的单位：它们也是需要被组织和维持的成员。

不同种类还具有偏好与不相容关系。强大的生物不一定容易管理，能够提供特殊能力的成员也可能带来额外麻烦。战斗实力、工资和稳定性之间需要取舍。地下城越复杂，玩家就越需要理解自己招来的究竟是什么，而不是只追求单位数量。

愤怒的角魔收割者把这项风险表现得格外鲜明。手册说明它生气后可能进入破坏状态，强力成员于是可能成为内部威胁。经营的困难不全来自外部英雄，也来自玩家自己创造的组织条件。这种可反噬的力量，让招募和照料都具有后果。

# 邪恶之手怎样表现统治

鼠标在生物上变成一只手，玩家可以拿起怪物，再把它放到工作或战斗位置。操作把抽象命令变成直接身体接触，仿佛管理者真的能够越过地牢把成员抓走。即时重新部署带来便利，也以夸张形式表现了权力的不对等。[1]

玩家还能拍打生物，使其暂时更快、更听话，同时损伤生命。短期效率与伤害在同一动作里出现。这个机制并不需要一段旁白解释压迫，因为收益和代价已经嵌入反馈；玩家的取舍是主动参与它，而不只是观看一个坏人实施暴力。

这种直接干预与大部分日常自主行动并存。玩家可以把工人扔到任务旁边，却仍要等待它们完成路径、搬运与施工。控制因此有不同层级：标记任务改变集体工作，拿起生物处理局部急事，改变房间则调整较长期的行为条件。

这组层级使作品兼有经营与即时策略的节奏。战斗发生时，人可以迅速介入，平时则观察组织自行运转。若始终逐只搬运，操作会变得繁重；若完全不看，又可能忽略内部问题。游戏持续要求玩家选择何时信任系统、何时亲手接管。

# 防线、陷阱与可改变的地图

门能够阻挡敌人，同时允许己方通行；锁门又可以限制己方进入某一区域。它既是防御建筑，也是管理内部流动的工具。狭窄通道、房间位置与门的组合，让同一片地下空间可以通过重新组织交通产生不同用途。[1]

陷阱需要制造、运送和安装，并非只要界面上选择了就立即拥有。它们对己方可见，对敌人则通常在触发前隐藏。玩家知道自己布置的危险，却必须谨慎面对对方空间；信息差由领土和行动历史产生。

挖掘使地图持续改变。连接资源的捷径，也可能打开入侵方向；加固墙壁提供安全，却会限制普通开掘。地图的战略价值不是关卡开始时完全确定的，而随各方工程发生变化。人工智能与路径安排必须在这个变化环境中工作，不能只沿一张永远固定的通行图移动。

对这种智能的讨论应停留在可核对范围。手册能够证明生物自主工作、战斗与移动的行为结构，但不能单凭观察就确定内部使用了哪一种完整搜索算法。游戏表现出聪明或迟钝，与研究者是否已掌握实现细节，是两项不同判断。

# 战斗与经营共享同一批身体

训练、生存和战斗没有被分成独立的角色库存。受伤成员需要恢复，死去的熟练怪物无法立即用一组同等级单位无成本替代。玩家在和平时期投入的工资与训练，会在冲突中承担风险，因此战斗损失具有经营历史。[1]

战场不只考验人数。怪物等级、位置、法术与正在发生的其他任务共同影响局面。直接把所有成员扔进一场战斗，可能暂时集中力量，也会使研究、生产或恢复停顿。战略判断需要把地下城整体工作纳入，而不是只看屏幕上的交战区域。

捕获敌人又使胜利有多种后续。监狱和拷问室可以处理俘虏，手册说明拷问可能揭示信息、转化阵营，也可能使被折磨者死亡。胜利因此不是简单清除一个对象，而是把对方身体带进己方的资源和权力体系。[1]

墓地则把死亡接入另一种生产：尸体被搬去分解，积累到一定程度能够产生吸血鬼。怪诞题材在这里获得系统性，死亡不仅作为剧情事件出现，也改变劳动、心情和可用成员。作品的黑色幽默由规则关系支撑，不能只从美术装饰理解。

# 附身让规划者进入自己的建筑

附身法术把俯视管理者放进一个生物的第一人称视角。玩家沿自己挖出的通道行动，使用这个生物具有的能力；附身小鬼还能进行开掘或夺取空间。俯瞰时的房间结构，由此变成身体尺度的路径和视线。[1]

Molyneux在1997年的访谈中说明，他希望人能够作为怪物体验自己建成的地下城。他还谈到让其他真人扮演地下城怪物的进一步想法，但没有时间实现。附身功能进入了已发行作品，多人方案则记录了开发者更远的构想。[2]

视角变化也改变了控制范围。管理时可以跨区域调动资源，附身时则需要通过局部身体行动。玩家得到更贴近战斗和空间的体验，同时暂时放弃部分全局注意。两种视角不是同一信息的缩放，而是对身份和能力的重新安排。

这个设计让建筑具有双重审美。通道既要从上方看便于经营，也能在内部感到连贯；怪物既是可拿取的单位，又是能够暂时成为玩家的身体。地下城不只是地图，也成为一种可以从不同位置经历的场所。

# 反派喜剧与管理想象

作品把英雄写成进入地盘、威胁财产和成员的敌人，把地下城主人放到需要安排食堂、睡眠和工资的位置。善恶角色的翻转制造了喜剧，也让传统冒险中被略去的维持工作浮现。迷宫不会天然有怪物和陷阱，它们需要资源和劳动。

旁白的夸张语气、怪物行为和阴暗空间形成黑色幽默。英雄的高尚与玩家的邪恶都被推到漫画程度，降低了写实再现的要求。游戏由此可以让暴力管理显得滑稽，但这种风格并不自动消除其中的权力结构。

玩家既要照料又能惩罚，同一只手提供食物、移动身体并施加伤害。作品没有把关怀与支配分配给完全不同角色，而使它们成为同一经营逻辑中的手段。这种混合是值得分析的核心：成员被承认为有需要的生命，同时也被计入生产和作战效率。

把怪物看作拟人化员工，可以解释工资和不满的幽默；但完全用现实劳动制度替换它们，又会抹去奇幻规则和荒诞性。更合适的批评需要来回对照具体机制：哪里模拟了组织依赖，哪里允许超常强制，哪里把强制的后果化为可笑或可计算的反馈。

# 管理界面如何让个体可见

地下城越大，单靠镜头寻找一个受伤或闲置成员就越费力。手册中的生物面板把闲置、工作和战斗分别统计，并允许从列表定位和拿取成员。这个界面把全局人数与具体身体联系起来，玩家可以从“哪里缺少劳动力”的判断，转到一次直接干预，而不必放弃对整个组织的观察。[1]

战斗提示也把分散冲突汇集到同一处。玩家能够查看双方等级与生命，再决定治疗、移动或继续等待。危险因而不只是地牢远处的动画，而成为可以检查和处理的信息。界面让管理者获得超越普通怪物视野的权力，也让玩家更容易把复杂局势理解为一组需要分配注意的事件。

这种可见性并不消除不确定性。地图尚未探明的区域、敌人的陷阱和怪物接下来的行为，仍会限制预测。作品让玩家在若干方面近似全知，同时在另一些方面必须冒险。强控制与有限信息的搭配，使经营不至于成为纯粹执行已知最优方案的工作。

从审美上说，面板和怪物的日常动画共同维持了这种双重身份。数字把成员变成可比较的劳动力，走路、吃鸡和睡眠又把它们恢复成有习惯的身体。玩家的照料或粗暴，都是在这两种观看方式之间作出。地下城的黑色幽默由此深入到界面，而不只是停留在怪物名称上。

发薪日使军队规模定期转化为财政压力。新成员不只是加入时需要一间房，留在地下城以后仍要从同一套资源中得到维持。扩军过快可能在战斗前就消耗稳定性，而暂时富足也不保证下一次支付顺利。经营者必须把未来开支放进当前决定，这让采金、招募和训练成为彼此牵制的时间安排。[1]

工资和食物还使等待具有不同含义。未参战的生物仍持续占用设施与资源。保留实力有准备价值，也有维持代价。地牢里看似平静的时刻，依旧充满工作与分配；这正是作品将经营和战争连接得如此紧密的原因。

# 关卡设计、版本与作品影响

原作通过关卡逐步开放设施、怪物和问题。玩家建立的地牢各不相同，但目标、资源与可用工具受场景安排约束。它结合了自由布局与预先设计的挑战，不是一套完全不需要作者关卡工作的自动世界生成器。

Deeper Dungeons扩展、Dungeon Keeper 2和后来采用同一名称的移动游戏，在关卡、系统与商业形式上均有自己的历史。重发行也可能调整显示与运行方式。讨论1997年作品的叙事与控制关系，需要保持这个对象边界，而不以系列后来的争议代替对初作的说明。

手册署名还提醒人们保留集体劳动。Ian Shaw负责导航系统，Russell Shaw负责音乐与音效，Richard Ridings等人参与配音，关卡、文本和测试也有各自人员。玩家感受到的一个整体地下城，由许多不同专业共同制造。[1]

它对游戏模拟的贡献，在于让有需求的自主生物、可改变的空间和即时战斗共用同一套经营世界。玩家不断在环境设计、直接干预与身体附身之间切换。作品既能作为策略挑战被理解，也能作为关于统治、依赖和照料的荒诞实验被阅读，二者都来自可具体指出的操作结构。
