# 简介

The Sims 3是Electronic Arts的The Sims工作室于2009年推出的生活模拟游戏。玩家创建具有外貌、特征与人生愿望的模拟市民，安排住宅、工作、交往和日常活动，也可以观察他们在自主行为中发生的冲突与意外。相较前作，它把主要生活空间扩展为能够连续游历的城镇，并用离散特征取代原来以几个连续刻度为核心的人格设置。

这里以2009年电脑基础版及2010年Richard Evans的开发说明为中心，另行区分资料片、主机改编和后续补丁。现行EA官方手册同时记录了后来加入的功能。作品的开发是团队工作，Ray Mazza等人参与设计，Evans负责重要的人工智能架构；Will Wright创立系列的贡献不能代替本作具体团队署名。[1][2][3]

# 一个能够连续游历的城镇

基础版让玩家控制的市民离开住宅，前往公园、图书馆、海滩或朋友家。住宅不再是绝大部分行动唯一持续显示的舞台，日常安排需要考虑城镇的地点关系。工作、购物、社交和收集活动可以把同一个人带往不同地区，使生活具有超过单一地块的时间与空间尺度。[1]

这种连续性不表示每栋楼内部都被完整表现。部分场所提供可以观看和控制的活动区域，工作或服务建筑则可能只让人选择进入后的行动方式。建筑入口、可见内部与抽象处理的活动并存，共同控制了作品的计算与内容规模。

一个存档包含整个城镇的状态，也改变了玩家对家庭的理解。正在控制的人会与邻居共享时间，其他家庭不只在被切换选中时才具有历史。玩家选择一个家庭，等于从一个较大的社会环境中挑选观察位置，而不是把其余居民都当作静止背景。[1]

城镇的连续运转还需要处理注意力差异。镜头附近的人物能够详细表演，远离玩家关注的家庭则不必每一刻都以同样精度运行。Evans明确把较低细节等级下的长期生活行动列为故事推进的一部分。可见动画与后台进程共同维持城镇，不能只根据当前镜头判断世界是否在继续。[2]

# 特征把人格变成可辨认的行为

玩家通常可以为成年模拟市民选择最多五项人格特征，儿童等年龄阶段拥有较少特征。爱好户外、书虫、笨拙、邪恶或善于接吻等标签，会改变可做的行动、倾向和表现。它们既是规则参数，也是玩家想象人物的语言。[1][3]

Mazza回忆，前两作连续刻度的人格，往往只有接近极端时才拥有明显特殊行为，中间几档的区别不易看见。第三作于是把鲜明内容集中成离散组合，试图让每个被选中的特征都能被日常观察辨认。[3]

五项上限也来自原型试验。开发者曾尝试用点数购买正面和负面特征，又尝试不设数量限制；最后认为过多特征会稀释身份，并使玩家难以记住自己创造的人物。少量清楚特征既方便算法调用，也帮助玩家在游玩中主动维持角色设想。

例如，一个人被设为音乐爱好者，玩家可能因此决定今天去公园演奏，即使系统没有强迫。这说明人格并非只通过机器自主行动发生作用。标签先激活了玩家的想象，再影响玩家安排；作品把计算行为和人的角色解释放进同一创作循环。

# 行为选择如何显出差异

Evans把自主行为解释为对可用行动的评价与选择。不同需要、状态和人格会改变某个行动的吸引力，再通过一定的选择方式产生行动。它不是每次都机械挑选一个最高分，也不是完全随机；设计者讨论了如何在连贯与变化之间调整。[2]

特征能够增加独特动机。刻薄的人更容易产生讥讽他人的倾向，喜欢躺着的人更愿意看电视或打盹。差异由选择过程持续表现，而不只是人物信息卡上的一句文字。玩家能够从多次行动推测性格，角色识别因此依赖一段时间里的稳定倾向。

特征还改变动作的方式。走路、等待、对某件事的反应以及额外动画，都可以透露人物身份。同样是等待，某个人的姿态可能更紧张，另一个人则以滑稽动作打发时间。性格既影响“做什么”，也影响“怎样做”，两种层次共同支持可读性。[2]

这种人格模型有明确边界。游戏不是对现实心理进行临床测量，也没有证明标签能够充分预测真实个体。它选择那些容易表现、容易组合且能产生戏剧关系的差异。把它视为人物创作工具，比把它当成人类心智的完整科学复制更符合开发者的目标。

# 城镇规模要求怎样的人工智能

如果每次选择都穷举所有地块、所有人物和所有交往动作，计算量会迅速扩大。Evans的讲稿提出分层处理：先选择去哪里，再选择与谁交往，最后决定具体社交动作。这种分解减少同时考虑的组合，使一个较大城镇能够被实际运转。[2]

讲稿还讨论从需要到相关行动的映射。已经吃饱的人不必反复评估所有进食机会，系统可以优先查看能满足当前需要的行动。工程优化在这里服务于更大的生活空间，但也影响人物会考虑什么、多久重新判断一次。计算效率与行为风格并不是完全分离的问题。

故事推进则处理未被充分模拟的人的长期事件，如结婚、就业、升职、孩子与搬家。它让城镇保持人口和社会活动，而不要求玩家逐户批准每个决定。对玩家来说，这是背景有生命的来源，也可能造成失去控制的感觉：自己暂时离开的家庭仍然会变化。[1][2]

Evans还把城镇解释为具有某些总体需求的系统，借生活行动调节人口与就业等状态。人物的个人需要与城镇层面的后台调节，共同推动着生活变化。所谓“活着的城镇”由不同尺度的模型拼合而成。

# 社交情境让同一特征产生不同后果

拜访不是一串互不相关的动作。主人需要注意客人，客人也受到关于何时离开、能否擅自使用物品的规范。Evans说明系统会在情境中临时增加动机，让人物对正在发生的社会关系作出反应。情境结束以后，相应要求又可以消退。[2]

不同特征对这些规范的回应不同。一个不合时宜的人可能在别人觉得应当保持距离的时刻继续打扰，结果引来警告或驱赶。角色的戏剧性不仅来自某个奇怪动作，而来自这个动作出现在不被接受的场合，并改变了别人接下来怎样对待他。

社交互动也比笼统的“聊天”更细。赞美房屋、担忧关系、嘲弄或谈论具体对象，提供了表现性格的语义空间。Evans强调，细致人格需要同样细致的社交系统支持；如果所有人都只能做完全相同、没有语境的动作，再多标签也很难显现差异。

响应规则依据情境和人物状态选择结果。重复笑话可能变无聊，对方的性格和双方关系又可能让同样话语被理解成有趣或冒犯。这里的对白主要通过动作、气泡和表演呈现，内部却需要更具体的条件组合。社会含义并非只由一段动画的固定意思决定。[2]

# 愿望、心情与玩家的共同写作

长期愿望给一个人较长的生活方向，日常愿望则提出较近的机会。玩家可以承诺、完成或放弃某些愿望，获得相应奖励。系统由此在开放生活中提供引导，又不完全代替玩家决定人物应该如何生活。[1]

心情状态把睡眠、食物、社交与近期事件压缩成可辨认反馈。短期心情图标记录某件事怎样影响人物，使幸福或不适不只来自几条生理需求。玩家能够据此理解一次糟糕工作表现，也能利用环境和活动改善接下来的状态。

生活因此在长、短目标之间切换。准备升职需要技能、关系和状态，照料家庭又可能打断学习计划；追求一项个人愿望，也可能改变与其他人的共同时间。玩家创造故事时，面对的是会争夺行动机会的多种倾向，而不是一条总能无阻执行的任务队列。

玩家还能够调节自主程度和寿命等选项。自主性较高时，人物更常在未被安排的时刻行动；较低时，玩家承担更多具体管理。不同设置支持不同创作关系，有人偏向导演，有人更愿意旁观。它们不是完全不同作品，却会明显改变体验中谁在提出下一步。

# 建造和样式编辑怎样参与人物塑造

住宅不仅是装饰背景。物品提供满足需要、学习技能和进行交往的机会，路线与空间安排又影响日常行动。玩家为某个人布置书房、花园或练习区，既表现想象中的身份，也实际改变他能够接近的活动。

Create A Style允许修改物件和衣服的颜色、材质图案，给人物与住宅建立连续的视觉风格。与只能整套选购固定外观的方式相比，它扩大了对细节的控制。创造性由此不仅存在于角色故事，也存在于对日常环境进行反复微调的过程。[1]

建筑与模拟之间仍有区别。一个漂亮房间可能缺少顺畅通路，视觉上适合社交的空间也未必提供足够活动机会。玩家需要同时作为布置者和使用者理解它。模拟让建筑承担后果，编辑工具则让问题保持可以修正。

截图、影片和分享功能把私人生活转成可以讲给别人的作品。玩家可以选取事件、安排镜头、添加解释，形成超出程序即时反馈的叙事。共享内容既来自机器的意外，也来自人的取景与剪辑。玩家通过解释、取舍与讲述，将系统事件组织成自己的故事。

# 戏剧特征的争论与简化代价

Mazza对笨拙、易激动等特征的讨论，说明团队曾质疑没有明显策略收益的选项为何值得保留。最终，一些特征凭幽默、身份认同和讲故事的价值进入作品。它们为创作服务，未必需要用更快赚钱或更强技能证明合理性。[3]

顺手牵羊特征则涉及另一个判断：给予玩家偷窃能力，是否符合系列的情绪风格？开发者为此限制了具体控制，并加入归还物品等安排。这个例子显示，特征的选择不是中性的心理目录，而是关于什么行为可以成为游戏乐趣的编辑决定。

负面标签可以制造冲突，也可能把真实身体、精神状态或社会差异化为笑料。分析作品时，需要区分游戏内特征的规则作用与现实群体，不把某个夸张人物当作对真实人的解释。简化提高了可读性，却也有刻板化的代价。

同样，愿望与奖励把生活中的部分成就变成可累计目标，工作、消费和自我改善很容易得到清楚反馈。照料、等待或拒绝某种成功道路的价值，可能更多依赖玩家自己的叙述。作品允许多种生活，但其指标仍然对哪些进展容易被看见作出选择。

# 角色知识也有发现过程

玩家在创建家庭时可以知道自己设置的特征，人物之间却未必一开始就了解对方。Evans的讲稿把通过具体社交结果学习性格列为设计的一部分。人与人之间的了解因此能够随着互动累积，社交动作既改变关系，也提供关于对方的信息。[2]

这一安排让观察和试探具有叙事价值。一次不受欢迎的笑话不只是损失关系数值，也可能解释此前觉得奇怪的反应；下一次交往于是有了新背景。角色的可读性不是把所有资料一次铺在屏幕上，而是在部分已知、部分仍需发现的条件下逐渐形成。

不同开发资料中的特征数量也需要保留语境。Mazza回顾的是自己所述发行设计集合，Evans的技术讲稿则讨论一个约数及当时系统；再加上隐藏特征与后续扩展，不能随意挑出一个总数当作所有版本、年龄和创建界面的统一上限。更稳定的核心事实，是玩家通过有限组合建立可辨认人物，而不同特征通过多种行为通道发挥作用。[2][3]

人物编辑与长期游玩之间还存在距离。创建时觉得有趣的组合，可能在共同生活中产生不便；玩家需要决定继续维持角色设定，还是为了效率改变安排。这个选择让人格不只是开始前的一道配置题，也成为后来如何对待人物的持续承诺。

# 从人工智能行为到涌现故事

Evans以Robin Burkinshaw的Alice and Kev为例，说明人物差异与城镇关系能够支持玩家叙事。一个粗鲁的父亲和善良的女儿面对同一生活困难，会因为行为和他人的回应走出不同路径。故事在系统事件与作者的持续观察、解释和编排之间形成。[2]

设计通过角色、规则与事件条件组织这种涌现。特征、访问规范、职业、关系和奖励都由团队事先写定；玩家又决定起始人物、家庭安排和记录方式。作品没有预写每次事件的完整顺序，却精心限定了什么差异能够产生后果。

它也不是任意生成对白的语言模型。开发讲稿讨论的是需要、效用、分层选择和条件规则；社会表现的可信度来自这些系统如何连接到动画、场景和玩家已经形成的预期。若以今天的生成式对话能力作为唯一标准，就会忽视本作通过行为关系创造人物的特殊路线。

The Sims 3的贡献在于把城镇规模、个体差异和社交规范放进同一生活模拟。玩家既能主动安排，也能因人物的偏离而重新理解自己的计划。它提供了一套可被居住、观察和讲述的社会玩具，其丰富性与局限都能从这些具体模型与创作工具中找到。

# 特征把人格变成可辨认的行为

玩家通常可以为成年模拟市民选择最多五项人格特征，儿童等年龄阶段拥有较少特征。爱好户外、书虫、笨拙、邪恶或善于接吻等标签，会改变可做的行动、倾向和表现。它们既是规则参数，也是玩家想象人物的语言。[1][3]

Mazza回忆，前两作连续刻度的人格，往往只有接近极端时才拥有明显特殊行为，中间几档的区别不易看见。第三作于是把鲜明内容集中成离散组合，试图让每个被选中的特征都能被日常观察辨认。[3]

五项上限也来自原型试验。开发者曾尝试用点数购买正面和负面特征，又尝试不设数量限制；最后认为过多特征会稀释身份，并使玩家难以记住自己创造的人物。少量清楚特征既方便算法调用，也帮助玩家在游玩中主动维持角色设想。

例如，一个人被设为音乐爱好者，玩家可能因此决定今天去公园演奏，即使系统没有强迫。这说明人格并非只通过机器自主行动发生作用。标签先激活了玩家的想象，再影响玩家安排；作品把计算行为和人的角色解释放进同一创作循环。

# 行为选择如何显出差异

Evans把自主行为解释为对可用行动的评价与选择。不同需要、状态和人格会改变某个行动的吸引力，再通过一定的选择方式产生行动。它不是每次都机械挑选一个最高分，也不是完全随机；设计者讨论了如何在连贯与变化之间调整。[2]

特征能够增加独特动机。刻薄的人更容易产生讥讽他人的倾向，喜欢躺着的人更愿意看电视或打盹。差异由选择过程持续表现，而不只是人物信息卡上的一句文字。玩家能够从多次行动推测性格，角色识别因此依赖一段时间里的稳定倾向。

特征还改变动作的方式。走路、等待、对某件事的反应以及额外动画，都可以透露人物身份。同样是等待，某个人的姿态可能更紧张，另一个人则以滑稽动作打发时间。性格既影响“做什么”，也影响“怎样做”，两种层次共同支持可读性。[2]

这种人格模型有明确边界。游戏不是对现实心理进行临床测量，也没有证明标签能够充分预测真实个体。它选择那些容易表现、容易组合且能产生戏剧关系的差异。把它视为人物创作工具，比把它当成人类心智的完整科学复制更符合开发者的目标。

# 城镇规模要求怎样的人工智能

如果每次选择都穷举所有地块、所有人物和所有交往动作，计算量会迅速扩大。Evans的讲稿提出分层处理：先选择去哪里，再选择与谁交往，最后决定具体社交动作。这种分解减少同时考虑的组合，使一个较大城镇能够被实际运转。[2]

讲稿还讨论从需要到相关行动的映射。已经吃饱的人不必反复评估所有进食机会，系统可以优先查看能满足当前需要的行动。工程优化在这里服务于更大的生活空间，但也影响人物会考虑什么、多久重新判断一次。计算效率与行为风格并不是完全分离的问题。

故事推进则处理未被充分模拟的人的长期事件，如结婚、就业、升职、孩子与搬家。它让城镇保持人口和社会活动，而不要求玩家逐户批准每个决定。对玩家来说，这是背景有生命的来源，也可能造成失去控制的感觉：自己暂时离开的家庭仍然会变化。[1][2]

Evans还把城镇解释为具有某些总体需求的系统，借生活行动调节人口与就业等状态。人物的个人需要与城镇层面的后台调节，共同推动着生活变化。所谓“活着的城镇”由不同尺度的模型拼合而成。

# 社交情境让同一特征产生不同后果

拜访不是一串互不相关的动作。主人需要注意客人，客人也受到关于何时离开、能否擅自使用物品的规范。Evans说明系统会在情境中临时增加动机，让人物对正在发生的社会关系作出反应。情境结束以后，相应要求又可以消退。[2]

不同特征对这些规范的回应不同。一个不合时宜的人可能在别人觉得应当保持距离的时刻继续打扰，结果引来警告或驱赶。角色的戏剧性不仅来自某个奇怪动作，而来自这个动作出现在不被接受的场合，并改变了别人接下来怎样对待他。

社交互动也比笼统的“聊天”更细。赞美房屋、担忧关系、嘲弄或谈论具体对象，提供了表现性格的语义空间。Evans强调，细致人格需要同样细致的社交系统支持；如果所有人都只能做完全相同、没有语境的动作，再多标签也很难显现差异。

响应规则依据情境和人物状态选择结果。重复笑话可能变无聊，对方的性格和双方关系又可能让同样话语被理解成有趣或冒犯。这里的对白主要通过动作、气泡和表演呈现，内部却需要更具体的条件组合。社会含义并非只由一段动画的固定意思决定。[2]

# 愿望、心情与玩家的共同写作

长期愿望给一个人较长的生活方向，日常愿望则提出较近的机会。玩家可以承诺、完成或放弃某些愿望，获得相应奖励。系统由此在开放生活中提供引导，又不完全代替玩家决定人物应该如何生活。[1]

心情状态把睡眠、食物、社交与近期事件压缩成可辨认反馈。短期心情图标记录某件事怎样影响人物，使幸福或不适不只来自几条生理需求。玩家能够据此理解一次糟糕工作表现，也能利用环境和活动改善接下来的状态。

生活因此在长、短目标之间切换。准备升职需要技能、关系和状态，照料家庭又可能打断学习计划；追求一项个人愿望，也可能改变与其他人的共同时间。玩家创造故事时，面对的是会争夺行动机会的多种倾向，而不是一条总能无阻执行的任务队列。

玩家还能够调节自主程度和寿命等选项。自主性较高时，人物更常在未被安排的时刻行动；较低时，玩家承担更多具体管理。不同设置支持不同创作关系，有人偏向导演，有人更愿意旁观。它们不是完全不同作品，却会明显改变体验中谁在提出下一步。

# 建造和样式编辑怎样参与人物塑造

住宅不仅是装饰背景。物品提供满足需要、学习技能和进行交往的机会，路线与空间安排又影响日常行动。玩家为某个人布置书房、花园或练习区，既表现想象中的身份，也实际改变他能够接近的活动。

Create A Style允许修改物件和衣服的颜色、材质图案，给人物与住宅建立连续的视觉风格。与只能整套选购固定外观的方式相比，它扩大了对细节的控制。创造性由此不仅存在于角色故事，也存在于对日常环境进行反复微调的过程。[1]

建筑与模拟之间仍有区别。一个漂亮房间可能缺少顺畅通路，视觉上适合社交的空间也未必提供足够活动机会。玩家需要同时作为布置者和使用者理解它。模拟让建筑承担后果，编辑工具则让问题保持可以修正。

截图、影片和分享功能把私人生活转成可以讲给别人的作品。玩家可以选取事件、安排镜头、添加解释，形成超出程序即时反馈的叙事。共享内容既来自机器的意外，也来自人的取景与剪辑。玩家通过解释、取舍与讲述，将系统事件组织成自己的故事。

# 戏剧特征的争论与简化代价

Mazza对笨拙、易激动等特征的讨论，说明团队曾质疑没有明显策略收益的选项为何值得保留。最终，一些特征凭幽默、身份认同和讲故事的价值进入作品。它们为创作服务，未必需要用更快赚钱或更强技能证明合理性。[3]

顺手牵羊特征则涉及另一个判断：给予玩家偷窃能力，是否符合系列的情绪风格？开发者为此限制了具体控制，并加入归还物品等安排。这个例子显示，特征的选择不是中性的心理目录，而是关于什么行为可以成为游戏乐趣的编辑决定。

负面标签可以制造冲突，也可能把真实身体、精神状态或社会差异化为笑料。分析作品时，需要区分游戏内特征的规则作用与现实群体，不把某个夸张人物当作对真实人的解释。简化提高了可读性，却也有刻板化的代价。

同样，愿望与奖励把生活中的部分成就变成可累计目标，工作、消费和自我改善很容易得到清楚反馈。照料、等待或拒绝某种成功道路的价值，可能更多依赖玩家自己的叙述。作品允许多种生活，但其指标仍然对哪些进展容易被看见作出选择。

# 角色知识也有发现过程

玩家在创建家庭时可以知道自己设置的特征，人物之间却未必一开始就了解对方。Evans的讲稿把通过具体社交结果学习性格列为设计的一部分。人与人之间的了解因此能够随着互动累积，社交动作既改变关系，也提供关于对方的信息。[2]

这一安排让观察和试探具有叙事价值。一次不受欢迎的笑话不只是损失关系数值，也可能解释此前觉得奇怪的反应；下一次交往于是有了新背景。角色的可读性不是把所有资料一次铺在屏幕上，而是在部分已知、部分仍需发现的条件下逐渐形成。

不同开发资料中的特征数量也需要保留语境。Mazza回顾的是自己所述发行设计集合，Evans的技术讲稿则讨论一个约数及当时系统；再加上隐藏特征与后续扩展，不能随意挑出一个总数当作所有版本、年龄和创建界面的统一上限。更稳定的核心事实，是玩家通过有限组合建立可辨认人物，而不同特征通过多种行为通道发挥作用。[2][3]

人物编辑与长期游玩之间还存在距离。创建时觉得有趣的组合，可能在共同生活中产生不便；玩家需要决定继续维持角色设定，还是为了效率改变安排。这个选择让人格不只是开始前的一道配置题，也成为后来如何对待人物的持续承诺。

# 从人工智能行为到涌现故事

Evans以Robin Burkinshaw的Alice and Kev为例，说明人物差异与城镇关系能够支持玩家叙事。一个粗鲁的父亲和善良的女儿面对同一生活困难，会因为行为和他人的回应走出不同路径。故事在系统事件与作者的持续观察、解释和编排之间形成。[2]

设计通过角色、规则与事件条件组织这种涌现。特征、访问规范、职业、关系和奖励都由团队事先写定；玩家又决定起始人物、家庭安排和记录方式。作品没有预写每次事件的完整顺序，却精心限定了什么差异能够产生后果。

它也不是任意生成对白的语言模型。开发讲稿讨论的是需要、效用、分层选择和条件规则；社会表现的可信度来自这些系统如何连接到动画、场景和玩家已经形成的预期。若以今天的生成式对话能力作为唯一标准，就会忽视本作通过行为关系创造人物的特殊路线。

The Sims 3的贡献在于把城镇规模、个体差异和社交规范放进同一生活模拟。玩家既能主动安排，也能因人物的偏离而重新理解自己的计划。它提供了一套可被居住、观察和讲述的社会玩具，其丰富性与局限都能从这些具体模型与创作工具中找到。
